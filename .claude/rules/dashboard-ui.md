# 대시보드 UI

## 숫자를 부르는 말

이 사이트에는 성격이 다른 숫자가 나란히 놓인다. **같은 크기의 % 세 개를 라벨 없이 두면
독자는 같은 종류로 읽는다.** 그래서 각 숫자는 자기가 무엇을 센 값인지 말해야 한다.

- **시나리오(GBM) 경로 비율**은 `모의 경로 비율` 로 부르고 **'확률'로 승격하지 않는다.**
  `probability_space: scenario_conditional` 이고 모델 조건부 값이다.
- **`quantile_table.prob_above_anchor` 의 임계는 anchor(=asof 종가)** 이지 S2 의 고정
  기준가(`REFERENCE_PRICE`)가 아니다. 둘을 같은 '기준가'로 부르면, anchor 가 기준가
  아래로 내려가는 순간 문장이 반대를 가리킨다.
- **`S1` 은 `hit_ath`** — 연말 종가 조건이 아니라 **연중 한 번이라도 전고점을 찍은** 경로다.
  "연말에 …로 끝난" 이라고 쓰면 사실과 다르다. 그래서 S1+S2 합(upProb)이 연말 종가가
  현재가를 넘는 비율(prob_above_anchor)보다 **클 수 있다.**
- **서로 다른 probability_space 는 산술 결합하지 않는다.** V8 시계열
  (`research_timeseries_v8_conditional`)과 시나리오(`scenario_conditional`)를 평균 내거나
  견주지 않는다. 페이로드가 스스로 결합을 금지하고 있다.
- 모든 출력은 **참고 의견**이며 매매 신호가 아니다.

## 게이트는 화면에서도 같아야 한다

홈 카드가 탭보다 먼저 숫자를 흘리면 게이트가 있으나 마나다. 홈에 지표를 실을 때는 그
지표의 탭이 쓰는 **공개 게이트를 그대로** 건다. 원점이 계약의 hold 임계를 넘기면 마지막
값으로 버티지 말고 보류 표면으로 닫는다(fail-closed).

## SVG

- **viewBox 안에 글자를 넣어 크기를 키우지 않는다.** viewBox 글꼴은 컨테이너 폭을 따라
  확대돼 겹치고 잘린다(실측: 확대 시 겹침 69·잘림 31, DECISIONS 2026-09-02). 설명이
  필요하면 SVG 밖 HTML 로 쓴다. 미니 그림은 **도형만** 그린다.
- 격자 안에 들어가는 차트 컨테이너에는 `min-width:0` 을 준다. 없으면 격자가 밀린다.
