## 1. 근본 원인 — 수학적 진단

CRPS 평균의 분해: **CRPS̄ = Uncertainty − Resolution + Reliability**.
- E0(exact empirical anchor): Reliability ≈ 0 (경험분포는 표본 자체에 보정), Resolution = 0 (무조건부).
- 챌린저가 이기는 유일한 길: **Resolution 이득 > Reliability 비용**.
- R4의 5개 성분(stress/tail·방향확률)은 Resolution 기여가 스트레스 구간(표본의 ~2–5%)에
  국한 → 평시 구간의 미세 Reliability 비용이 이를 상쇄 → 무조건부 CRPS advantage가 정확히
  0 이하 → 볼록 스태킹의 전역해가 w=0. **성분 가족 선택 오류이지 파이프라인 오류가 아니다.**
- 부차 원인(검정력): fit 634행·1,025 origins에서 1–3%p CRPS 효과의 단일 holdout 탐지는
  한계 검정력. §5에서 추정량 효율화(기준 완화 아님)로 대응.

**지수 수익률에서 Resolution의 최대 원천은 조건부 분산(변동성 군집)이다** — |r|의 자기상관은
가장 강건한 정형화 사실. 조건부 평균은 EMH상 거의 무신호(F-tier로 강등).

## 2. R5 챌린저 가족 — 전원이 E0를 내포(nest)한다

핵심 설계 원리: **λ=0(또는 상수 스케일)일 때 E0와 정확히 일치하는 가족만 후보로 한다.**
그러면 in-family 최악이 E0 = no-regret 자동 충족이고, 조건부 신호가 실재하면 λ>0이 선택된다.

기호: origin t, 지평 h, E0 표본 {r_i}_{i=1..n_t} (성숙 h-라벨, available_at ≤ t),
r̄=평균, σ̄=표준편차. σ̂_{t,h}=조건부 스케일 예측(§3).

| ID | 가족 | 예측 표본 생성식 | E0 내포 조건 |
|---|---|---|---|
| E1' | **FHS-HAR** (최우선) | z_i=(r_i−r̄)/σ_i^{fit} 표준화 풀 → r̃_j = r̄ + σ̂_{t,h}·z_j | σ_i^{fit}≡σ̄, σ̂=σ̄ |
| E2' | E0-rescale(λ) | r̃_i = r̄ + (r_i−r̄)·(σ̂_{t,h}/σ̄)^λ, λ∈[0,1.5] | λ=0 |
| E3' | 이벤트 승수 | σ̂ ← σ̂·√(1+γ_e·1{이벤트∈(t,t+h]}), e∈{FOMC,CPI,고용} (캘린더는 사전 공지 — PIT 안전) | γ_e=0 |
| E4' | t-테일 블렌드 | 분위수 q_τ = (1−π)·q_τ^{E0-rescale} + π·[r̄+σ̂·T⁻¹_ν(τ)·c_ν], ν 학습(§S-2 R4 문서), c_ν=√((ν−2)/ν) | π=0 |
| F | 위치항(선택) | r̄ ← r̄ + δ·shrink(모멘텀/AR1), δ≤0.2 고정 상한 | δ=0 |

전 가족 산출은 분위수 그리드 τ∈{0.01,…,0.99} 또는 e0_sample_matrices와 동일 표본행렬
포맷으로 직렬화(기존 quarantine 규칙 준수).

## 3. 조건부 스케일 σ̂_{t,h} — 3원 추정 후 selection에서 택1/스태킹

일간 로그수익 r_d, 실현분산 RV^{(k)}_t = (252/k)·Σ_{d=t−k+1..t} r_d².

**(a) HAR 직접투영(지평별)**: 성숙 라벨의 실현 h-변동 y_{t,h}=Σ_{d∈(t,t+h]} r_d² 에 대해
```
log y_{t,h} = β0 + βd·log RV^{(1)}_t + βw·log RV^{(5)}_t + βm·log RV^{(21)}_t + ε
```
research_train에서 OLS(Ridge λ_r 후보 {0,1e-4,1e-3}), σ̂²_{t,h}=exp(예측+s²ε/2) (log-정규 보정).
**(b) EWMA**: σ̂²_t = (1−α)Σ_{k≥0} α^k r²_{t−k}, α∈{0.94, 0.97}; h-스케일링 σ̂_{t,h}=σ̂_t·√h.
**(c) GARCH(1,1)-t**: σ²_{t+1}=ω+a·r²_t+b·σ²_t, t-혁신 MLE; h-집계는 관용 점화식
Σ_{j=1..h} E[σ²_{t+j}] = h·σ̄²_LR + (σ²_{t+1}−σ̄²_LR)·(1−(a+b)^h)/(1−(a+b)).

PIT: 모든 입력은 t 시점 available_at 충족 가격만. 표준화 잔차 풀 z는 research_train
구간에서만 축적, 이후 역할에는 동결 스냅샷 전달(lineage 기록).

## 4. 스태킹·보정 (R4 구현 재사용 — 변경 금지)

Vincentization 볼록가중(지평별), w_E0 하한은 R4 계약값 유지, SLSQP.
cross-fit calibration(기존 calibration_cross_fit_holdout 경로 그대로).
**기대 형태**: h=1·5·21에서 w_{E1'}>0, h=63은 w_E0→1 수렴 가능(변동성 예측력 감쇠) —

## 5. 자격 통계 — 기준 불변, 추정량만 효율화

동일 좌표 쌍대차 Δ_i = CRPS_i^{E0} − CRPS_i^{cand} (control variates — 이미 exact 그리드).
- stationary block bootstrap (블록길 ℓ=2h, B=2,000) 으로 Δ̄ CI. 판정은 **기존 게이트
  구현 호출** — 본 설계는 입력만 공급.
- 보조(참고): DM = Δ̄/√(V̂_HAC/n), HAC lag=h.
- **MDE 보고 의무**: 실측 CV(Δ)로 최소탐지효과 MDE = (z_{0.95}+z_{0.8})·sd(Δ̄) 를 지평별
  산출·직렬화. MDE > 기대효과이면 "검정력 부족" 사실을 보고 — 표본 확장(origin 밀도·기간)은
  **사용자 결정 D-2**로만.
- 다중성: 후보 가족 5개 사전 등록(본 문서가 등록부). 사후 추가 금지, 실패 성분 은폐 금지.

## 6. 왜 이것이 "빨리"인가

E1'(FHS-HAR)는 신규 데이터 0 — dualdb의 ^IXIC 일간 종가만 필요. 구현 ≈ RV 계산 + HAR 회귀
+ 표준화 풀 + 표본행렬 직렬화 ≈ 소규모 모듈 1개. **R5-M1 단독으로 first-light**(전 파이프라인
관통)를 먼저 달성한 뒤 E2'~E4'를 병렬 추가한다. V8 open-data(VIX 등)는 PROPOSED_NOT_APPROVED
상태 유지 — R5는 기존 허용 데이터만 사용, V8 승인은 사용자 결정 D-1.
