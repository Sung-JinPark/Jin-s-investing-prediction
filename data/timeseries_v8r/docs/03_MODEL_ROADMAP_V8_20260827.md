# [상세 설계] V8 모델 고도화 로드맵 — 다변량·기반모델·conformal (2026-08-27)

> 전제: R5(E0-내포 조건부 스케일 가족)가 선행. V8은 그 위에 **정보 채널 확장(데이터)**과
> **모델 계층 확장(다변량·TSFM)**을 얹는다. 게이트·E0·outer 1회·볼록 스태킹 w_E0 하한은
> 전부 불변. 모든 성분은 "E0 내포" 또는 "E0-anchor 스태킹 멤버" 둘 중 하나로만 편입.

## Stage 1 — 정보 채널 틸트 (R5 가족의 피처 확장, 최우선)
R5의 σ̂ 회귀에 §01 피처를 공변량으로 추가하는 것뿐 — 새 모델 아님.
```
log σ̂²_{t,h} = HAR항 + γ₁·VRP_t + γ₂·TS_t + γ₃·VVIX_z + γ₄·COT_x + ...  (예산 8개 이내)
```
- E4' t-테일의 ν·π도 SKEW_z 조건부 허용: ν_t = 2+softplus(a+b·SKEW_z_t).
- 각 γ 단독 사전등록 + ablation. 전부 0이면 Stage 1 기여 없음으로 정직 기록.

## Stage 2 — 다변량 조건부 구조 (교차자산)
문헌 교훈(채널독립 우선)에 따라 2단 접근:
1. **채널독립 전역학습**: 동일 파이프라인을 {IXIC, SPX, RUT, 금리, 신용} 각각에 적용하되
   σ̂ 회귀 계수를 **부분 풀링**(계층 베이즈 축소: β_asset = β_global + u, u~N(0,τ²)) —
   M5/cross-learning의 전역 이득을 취하며 자산별 특이성 보존.
2. **DCC-GARCH-t 공동표본**: 시나리오 정합 joint 샘플이 필요할 때만.
   Q_t = (1−a−b)Q̄ + a·z_{t−1}z'_{t−1} + b·Q_{t−1}, R_t = diag(Q_t)^{-1/2}Q_t diag(Q_t)^{-1/2}.
   IXIC 주변분포는 E1'(FHS)로 유지 — 결합만 DCC. 게이트 대상 아님(참고 산출).

## Stage 3 — TSFM 성분화 (오염 검증 필수)
- 후보: Chronos-2(공변량 지원), Moirai-2(any-variate), TimesFM-2.5. 편입 규칙:
  ① 사전학습 코퍼스-평가구간 중첩 점검서 작성(§00의 47~184% 과대평가 경고 대응)
  ② zero-shot이 아니라 **역할 규율 하 파인튜닝**(research_train만)
  ③ 산출은 분위수 → 볼록 스태킹 멤버로만(w_E0 하한 유지 = anchor 보장)
  ④ 기존 Chronos-T5 성분과의 중복 기여 점검(층 2 상관 규칙 준용).
- 추가 대조군: Nixtla statsforecast Auto-Theta/AutoETS — "고전 기준선도 못 이기면
  기각"의 내부 정직성 장치(게이트 비교자는 여전히 E0).

## Stage 4 — 커버리지 보증 (분포 신뢰성)
- CQR(기존 R4 설계) + **적응 conformal(Gibbs-Candès ACI)**: 커버리지 오차의 온라인
  보정 α_{t+1} = α_t + γ(α − err_t) — 레짐 전환기 커버리지 방어. calibration 역할
  cross-fit로만 적합, 사전등록 1방법 원칙 유지.

## 지평별 기대 (정직 범위)
h=1: +2~5% (VRP·기간구조 기여 문헌 근거) / h=5: +1~3% / h=21: 0~+2% / h=63: ≈0.
전 지평 요건 미충족 시 HOLD가 정답 — 반복 명시.
