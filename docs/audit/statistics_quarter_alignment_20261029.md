# 분기 잔액·월간 주가 정렬 수정 — 동일 입력 그림자 검증

검수일: 2026-10-29. **이 문서는 배포 전 로컬 검증 기록이다. 운영 배포 완료를 뜻하지 않는다.**

## 수정 범위

기존 코드는 FRED가 분기 시작일로 표시한 잔액을 같은 날짜 키의 월간 주가와 결합했다.
따라서 Q2 말 잔액과 4월 주가가 결합되었다. 수정안은 **같은 분기의 마지막 달 주가와
그 분기 말 잔액**을 결합한다. 원천 행의 날짜·값·빈티지·수집 영수증은 바꾸지 않는다.

- `nasdaq_per_household_liquid_assets`: 분기 마지막 달의 마지막 실제 NASDAQ 종가 ÷ 가계 현금성 자산 잔액.
- `spx_per_federal_debt`: 분기 마지막 달 OECD 미국 주가지수 월평균 ÷ 연방부채 잔액.
- `spx_per_federal_debt_full_history`: 같은 수정 비율의 1966년 이후 경로. 정규화·고점·저항 참고선도 다시 계산한다.

파생 날짜 `2026-06-01`은 **6월 관측기간**을 뜻한다. 6월 1일에 분기 잔액을 알았다는
뜻이 아니다. 실제 종료일이 수집 기준일을 지난 분기만 사용하고, 내부 구간의 필요한
주가 월이 빠지면 거부한다. 임의 보간·다른 달 대체·미래 연장은 하지 않는다.
NASDAQ는 마지막 거래 종가, OECD 계열은 월평균이라는 기존 원천 정의를 유지한다.

## 비교 방법과 보존 증거

검증 도구: `tools/verify_statistics_quarter_alignment.py`.

```powershell
python tools/verify_statistics_quarter_alignment.py `
  --baseline-ref 258a3c5e1dd4441f5f92ec146953de0aabe6c55a `
  --out-dir outputs/statistics_quarter_alignment/20261029
```

1. 기준 구현은 고정 커밋 `258a3c5e1dd4441f5f92ec146953de0aabe6c55a`의 코드를 Git 객체에서 읽는다.
   후보 구현과 같은 실행 환경에서 각각 독립 모듈로 실행한다.
2. 누적 공식 관측 원장의 현재 뷰에서 **49개 원천 시계열을 한 번만 재구성**한다.
   운영 스냅샷의 실제 원천 선택, 영수증 메타데이터, IPO 참고·월별 입력을 두 구현에 똑같이 넣는다.
   생성 시각은 기존 스냅샷의 `2026-10-29T02:29:31+00:00`으로 고정한다.
3. 공통 입력 SHA256은 `fb3e2cb670d82bbc1a306111db74a206d608587081c1b4ac73a84b1eea027f1a`이다.
   전체 입력을 `shadow_inputs.json`으로 별도 보존한다.
4. HTTP·네트워크 연결을 막은 상태로 두 전체 통계 산출물과 실제 과열도 계산 함수를 실행한다.
   과열도와 화면 축약 산출물은 임시 폴더에서만 계산한다.
5. 공식 스냅샷·통계 원장/원문/보관본/워크북·IPO 입력·예측·교정 원장·질문·계약 등
   **661개 보호 파일의 실행 전후 SHA256이 모두 같다.** 후보 코드도 실행 전후 같은 해시로 확인한다.

그림자 검증 **통과**: 예상한 세 차트만 변경되며, 나머지 **25개 차트의 전체 필드와 관측점은
절대·상대 허용오차 0으로 일치**한다. 전체 산출물의 다른 필드도 일치한다.
예외로 명시적으로 검토한 변경은 `GFDEBTN.native_frequency`의
`quarterly` → `quarterly_end_of_period` 의미 명료화 한 필드뿐이다.
원천 관측 행·값·날짜와 출처 해시는 그대로다.

기존 운영 스냅샷을 기준 구현으로 재현할 때 별도 플랫폼 수치 오차가 한 곳 있었다.
`$.charts[27].series[1].points[44].value`의 저장값 `10.052512380722312`와 재현값
`10.05251238072229` 사이 차이는 `-2.3092638912203256e-14`이다.
이 기존 가계 추세선 재현에만 절대 `1e-12`, 상대 `1e-12`를 적용했다.
구조·문자열 차이는 허용하지 않았으며 원래 정확 차이를 보고서에서 보존했다.
**후보와 재현 기준 사이의 미수정 필드 비교에는 이 허용오차를 적용하지 않았다.**

## 과거·현재 경로 변경

비교용 두 사이클은 각각 처음 사용 가능한 분기 말 관측을 100으로 정규화한다.
따라서 기존 1월=100에서 수정 후 3월=100으로 기준도 함께 옮겨진다.

| 차트 | 닷컴 점 수 | 현재 점 수 | 현재 마지막 파생 날짜 | 현재 값 이전 → 이후 |

| 가계 현금성 자산 대비 NASDAQ | 20 → 20 | 14 → 14 | 2026-04-01 → 2026-06-01 | 189.6066463864 → 189.2592432311 |
| 연방부채 대비 미국 주가 | 20 → 20 | 14 → 14 | 2026-04-01 → 2026-06-01 | 115.6852141589 → 124.3057708288 |
| 연방부채 대비 미국 주가 전체 역사 | 해당 없음 | 242 → 242 | 2026-04-01 → 2026-06-01 | 34.66 → 37.44 |

가계 현금성 자산 비율의 닷컴 마지막 값은 `299.0797297569 → 379.1420549059`,
연방부채 비율은 `198.9486441206 → 201.4219424275`이다.
참조창도 같은 원칙으로 다시 계산하므로 현재 값의 작은 변화와 과열도 변화가 비례하지 않을 수 있다.

전체 역사 경로는 첫 관측을 `1966-01 → 1966-03`으로 바꾸고 첫 관측=100을 유지한다.
1968년 고점은 `103.41 → 112.00`, 현재 저항 참고선은 `48.46 → 50.81`,
참고선 접근 비율은 `71.5% → 73.7%`로 다시 계산된다.
두 점의 저항 참고선 및 사건 라벨·축·범위·결론의 변경도 전체 필드 차이 보고서에 포함한다.
