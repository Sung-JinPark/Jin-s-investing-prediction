# 시계열 예측 뷰 — 초보자 우선 언어층 재설계 (2026-09-08)

소유자 지시: "전망 요약을 초보자가 봐도 읽기 쉽게, 기간별 범위 표·1/5/21/63 통계표·기여 요인·
검증 성적 전부 사용자 관점으로 전면 수정. 증권사 리포트·다변량 시계열 표기 벤치마킹 후 설계도 작성."

## 0. 진단 — 무엇이 어려운가

260903 재설계(4탭·공유 호버·봉인/전체창 분리)는 **정보 정직성**은 완성했지만, 화면의 1차 언어가
전문가 어휘다: 분위수·CRPS·DM p·봉인창·공칭 대비 편차. 쉬운 뜻은 툴팁·abbr·캡션 속 2차 층에
숨어 있다. 초보자는 1차 층에서 튕겨 나간다. **고칠 것은 데이터·차트 구조가 아니라 언어의 순서다.**

## 1. 벤치마킹 결과 → 채택 원칙

| 출처 | 관행 | 채택 |
|---|---|---|
| BoE 팬차트 계열 (1990s~, IMF·ECB 표준) | 중앙값 아닌 **중첩 구간(50/80%)의 부채꼴**로 분포 자체를 보게 함 — 비전문가 전달의 정론. "불확실성 소통이 기대를 더 현실적으로 만든다"(BoE WP 2026) | 현 대역 차트 유지 — 구조는 이미 표준. 언어층만 추가 |
| NIESR 리스크 소통 개선 | 확률을 **문장·도수(frequency)로 병기** | "80% 구간" → **"10번 중 8번은 이 안"** 도수 표현을 1차 라벨로, 분위수 용어는 2차로 강등 |
| 위험소통 정론 (natural frequencies) | %보다 "100번 중 64번"이 이해 오류를 줄임 | 상승 가능성 64% → "**100번 중 64번은 상승**" 병기 |
| 국내 증권사 리포트 관행 (와이즈리포트·한경컨센서스 요약 형식) | 최상단 **요약 박스**(의견·목표가·3줄 요약) 먼저, 근거 표는 뒤 (BLUF) | 요약 탭 최상단에 **3줄 요약 박스** 신설: 전망 한 줄·범위 한 줄·신뢰 한 줄 |
| 동 관행 | 목표주가는 항상 "무엇 대비·언제까지"가 붙음 | 모든 기간 라벨에 **달력 환산**: 1거래일=다음 거래일, 5≈1주, 21≈1개월, 63≈3개월 |
| IPCC 보정 언어 | 확신 수준을 고정된 등급 문장으로 | 검증 성적을 **성적표 3문항**(정확했나/약속만큼 담았나/실전 검증)으로 등급화, 지표는 그 아래 |

비채택: 단일 목표가 헤드라인(증권사 관행이지만 이 시스템의 "범위 전망" 원칙과 충돌 —
분포 우선이라는 BoE 원칙을 상위에 둠).

## 2. 설계 — 탭별 변경

언어 3층 규칙: **1층 = 도수·달력 문장 / 2층 = 통계 용어(괄호·small) / 3층 = 툴팁·용어사전(유지)**.
데이터·확률 파생 0건 — 표시 재라벨만 (계약 테스트의 금지 패턴 준수: 임계 확률 문장 금지,
probability_up 외 확률 표시 금지).

### 2-1. 전망 요약
1. **3줄 요약 박스 신설** (`.ts-brief`, 카드·범위 차트 위):
   - 전망: "약 3개월 뒤(63거래일) 가운데 예상값은 N (지금보다 +r%)."
   - 범위: "10번 중 8번은 A ~ B 사이에 들도록 설계된 **범위 전망**입니다 — 한 값을 맞히는 예측이 아닙니다."
   - 신뢰: 게이트·전진 실적에서 도출 — "2019년 이후 N개 시점 검증 통과 / 2008년급 위기 검증 없음 /
     실전 확정 성적 M건" (전부 기존 필드, 문장화만).
2. 기간 카드 재작성: `약 1주 뒤 · 5거래일` / `중앙 N` / `+r% · 100번 중 u번 상승` /
   `10번 중 8번 범위 A–B` (+만기 실측 병기 유지).
3. 범위 막대 y라벨을 달력 2줄(tspan)로: "약 1개월 / 21거래일".
4. 방법 박스는 계약대로 summary 패널 마지막 자식 유지.

### 2-2. 경로 분포
- 소유자 의도 확인: **이미 구현돼 있음** — 검은 선=원점 이전 실제 63세션, 붉은 선=예측 중앙 경로,
  **굵은 회색 실선=원점 이후 실제로 걸어온 길**(대역 밖 이탈도 그대로 노출). 헤더 문구를 이
  세 선의 뜻으로 교체해 1층으로 끌어올린다: "회색 선과 붉은 선의 간격 = 지금까지의 오차".
- 분위수 사다리표: 캡션 평문화 + 열 머리 2층화 —
  "비관 쪽 끝 <small>10번 중 1번은 이 아래</small>" / "가운데 값 <small>절반은 위·절반은 아래</small>" /
  "낙관 쪽 끝 <small>10번 중 1번은 이 위</small>" (25/75는 "중심 범위 경계"). 행 머리에 달력 병기.

### 2-3. 기여 요인
- 리드 앞에 평문 한 줄: "이 모델은 나스닥 하나가 아니라 금리·달러·변동성을 함께 보고 계산합니다.
  아래는 그 재료 목록과, 각 재료가 얼마나 최신인지입니다." (기존 "기여도가 아닙니다" 정직성
  리드는 그대로 유지 — 계약 문구).
- 카드 제목 보강: "입력 신호 신선도" → 부제 "재료가 오래되면 예측을 멈춥니다".

### 2-4. 검증 성적
- **성적표 3문항 박스 신설** (`.ts-scorecard`, 최상단): 각 문항 = 질문 + 등급 칩(양호/주의/보류) + 한 문장.
  1. "단순한 예측 방법보다 정확했나" — 봉인창 CRPS 개선(21·63일)과 유의성 → "오차가 x% 작았고,
     우연이라 보기 어렵습니다 / 우연일 여지가 남습니다".
  2. "'10번 중 8번' 약속만큼 담겼나" — 80% 적중률 vs 허용대역 → "실제 10번 중 y번 — 약속과 z pp 차이".
  3. "실전에서 검증됐나" — 전진 확정 건수 → "배포 후 확정 M건 — 아직 실력을 말할 단계가 아닙니다"
     (0건이면 그대로 0건 표기 — 기존 정직성 규율).
  등급은 기존 게이트 판정·유의성·허용대역의 재표현일 뿐 새 판정 아님. 상세 차트·KPI·판정문은
  그 아래 순서 유지 (봉인/전체창 분리·자료 없음·GFC 문구 등 계약 문자열 전부 보존).
- 성적표 박스는 hover 바인딩 의무 표면이 아니므로 `data-ts-chart` 부여하지 않음.

### 2-5. 공통
- `TS_H_CAL={1:'다음 거래일',5:'약 1주 뒤',21:'약 1개월 뒤',63:'약 3개월 뒤'}` 헬퍼 — 카드·범위·사다리·
  대역 노드 라벨·성적 표 행머리에 일괄 적용 (거래일 수는 2층 병기).
- 금지: "~아래/이하 …확률" 형태 문장(임계 확률 금지 패턴), 새 확률 계산, 분위수·게이트 값 변경.
