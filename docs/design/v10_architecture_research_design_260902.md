## 1. 불변 헌법 (승계)

- V8·V2 봉인 파일 0바이트, V8 봉인 run 4핀 벤치마크, retune 금지.
- 게이트 산술 무변경 (publication [0.76,0.84]/[0.45,0.55]/regime ≥0.70/장기 ≥+2%/CI≤0;
  dev proxy ≥+2.5%/se ≤0.001/투영 CI ≤−0.0004/coverage 밴드) — 전부 계약 대조 검증 완료.
- 정지점 2 (홀드아웃 = 명시 승인 문자열, 봉인 = 사인오프 후 별도 세션), 예산 유한,
  append-only 원장, E0 내포(비트 동일), 챔피언 = E0 대비 쌍대 개선, DL·학습 가중 금지.
- 3중 반청정 caveat: V2·V8의 2019+ 성적 공개 + V9 판정문 공개 상태에서의 개발임을 계약 명기.

## 2. 기준선의 기계 (검증 완료 — 정정 2건 반영)

V8 챔피언(E10): V2 비트동일 엔진(잔차 stationary bootstrap × EWMA devol/revol) → h21·63만
FHS 창합 재구성으로 한계분포 **통째 교체**(backtest.py:158~172) → historical_simulation과
w=.75 정적 혼합(backtest.py:179) → 전 지평 PIT 재보정 u*=(1−s)Q̂(q)+s·q, s=.5(성숙 104
필요 — 2007~09 사실상 비활성). h1·h5 = 엔진+B4만. B1(φ=None)·B2(ω=0)·tilt(0) 미사용.

**정정 반영**: ① 챔피언 런타임 CRPS는 재보정 활성 후 **경험 CRPS**(sample_crps on remapped
mixture) — Cramér 정확식은 재보정 비활성 분기 전용(설계 예측용으로는 유효, 런타임 서술로는
부정확했음). ② E0 항등은 성립 확인 — phi=None이면 RNG 소비 순서까지 V2 동일.

## 5. 연구 그리드 W1~W5 (정정 반영·정밀화)

**공통 아키텍처 전제 (정정 C-V10-3)**: W1~W4 전부 동결 루프 내부를 건드리므로 **단일
V10 평가 루프 포크**가 전제다 — `src/ai_fc/timeseries_v10/backtest_fork.py`(+필요 시
model_fork.py)에 V8 원본을 사본으로 두고, ① 원본 파일 sha256을 V10 계약에 핀 ② E0
비트동일 테스트(퇴화 파라미터 → V8 챔피언과 scores 완전 일치)가 사본 드리프트를 상시
차단 ③ 모든 W 변형은 사본의 **파라미터 분기**로만(원본 경로 보존). read-only import로
끝나는 후보는 없다.

### W1 — 국면조건부 재표집 [1순위]
- 표적: 2020형 과잉폭(강도 조건화). 상태 = **(a) EWMA(λ=.97) 분산비 v_now/v̄** (실측 선정:
  위기/평시 분리 6.4배·평온기 오탐 0.4%·1달 자기상관 .881·발화 감지 +0~3일). 민감도 대조군
  (c) RV63/RV504. (b) λ=.94 탈락. 1996~2004는 선언된 중립 워밍업(2520일 기준선 요건).
- 구현 경로 (정정 C-V10-10): **B5 z-풀 가중 quantile**(keep-마스크 지점 — RNG 무접촉·
  결정론이라 κ=0 산술 퇴화가 깨끗) 1차. 엔진 bootstrap 인덱스 가중은 RNG 순서·블록 구조를
  깨므로 2차(분기식 항등)로 강등.
- 격자: κ∈{0, .5, 1} × 상태 (a) 고정 = 실험 2회(+민감도 1).

### W2 — K성분 발생기 혼합
- {FHS, historical, block_bootstrap} 3성분 (엔진 성분은 FHS 교체와 중복이라 제외 검토).
  pairwise Cramér 정확식 ΣwᵢCRPSᵢ − Σᵢ<ⱼwᵢwⱼd(Fᵢ,Fⱼ)로 **설계-예측 사전 계산**(재보정
  전 단계 기준 — C-V10-6 반영: 최종 채점은 경험 CRPS) 후 밴드 위반 예상 세트는 등록 제외.
- 격자: 사전등록 고정 가중 3세트 = 실험 ≤3회.

### W3 — 상태의존 블렌드 w(state)
- w(state)=clip(w₀+γ·(state−1), [.5,.9]), state = W1과 동일 (a). 포크 내 1줄 분기.
- 격자: γ ±1단계 = 실험 2회. 표적: 국면별 폭 재배분(2020 과잉↓·평시 유지).

### W4 — 재보정 맵 고도화 (국면 층화 필수)
- isotonic(PAV) 맵 + 상태 2층(고/저변동) 분리 PIT 이력. 무층화 강화 세트는 등록 금지
  (E9 교훈). 워밍업 공허성(성숙 104 → 2007~09 비활성 → GFC 검정 공허) 계약 명기.
- 격자: {isotonic 무층화 s=.5(맵만 교체), isotonic+2층} = 실험 2회.

### W5 — 단기 h1·h5 FHS 확장 [저기대 명시]
- 정정 C-V10-3: config 한 줄이 아니라 **V10 계약 grid 사전등록** 필요(V8 계약이 [21,63]
  핀·pipeline 거부 확인). 격자: {h5만, h1+h5} = 실험 2회. 기대 중립 — 기록 가치 위주.

**음성 목록(불변)**: tilt류·대칭 기간구조·무층화 재보정 강화·exog 추가·DL·first_touch
전용 경로 모델(V11).

## 7. 평가 창 구조 — 권고 재작성 (정정 C-V10-1·5)

초안의 옵션 C(대리 국면 하이브리드)는 **실측 반박으로 폐기**: "2013 테이퍼 ≈ 2022 긴축"은
변동성 비 0.39·드로다운 비 0.15·DGS2 상승 비 0.04·주식 방향 반대로 불성립. "2008 ≈ 2020"은
강도 차원만 부분 성립(경로 형태 불가).

**최종 권고: 옵션 A′ — V8 창 구조 승계 + 정직한 한계 명기 + B를 봉인 시점 재결정으로.**
- design 2007–14 / holdout 2015–18 / sealed 2019+ 승계. W1·W3의 강도 조건화는 GFC(설계창
  내)로 개발 검증 가능 — 2020형 과잉폭 표적과 강도 차원에서 연결된다(부분 성립 실측).
- **2022형(완만 긴축·과소폭) 약점은 설계창에 대리가 없다** — 이 표적은 개발 중 검증 불가
  이며, 통과 여부는 봉인에서만 드러난다는 사실을 계약 disclosure_caveat에 명기.
- 옵션 B(창 전진)는 holdout se 0.00184(MDE50 6.3%)의 검정력 비용 + 봉인 2027-10 유예가
  대가 — **봉인 직전 시점의 별도 사용자 결정(V10-D2′)으로 이월**: 그때까지 축적된 V8/V10
  shadow와 2023+ 원점 수(250 도달 ≈ 2027-10)를 보고 A′ 봉인 vs B 전환을 다시 정한다.
