## 0. 실측 재검증 — 결정적 발견 3건

### 0.1 E0(=V8 챔피언 항등)는 design 창에서 dev proxy 10조건을 **이미 전부 통과**한다
`v9_development_experiments.jsonl` V9_E0_identity(417원점, 2007–14) 실측:

| 조건 | 임계 | E0 실측 | 여유 |
|---|---|---|---|
| long_horizon_mean_improvement | ≥ +2.5% | **+3.230%** | +0.73pp |
| paired_se | ≤ 0.001 | 0.000777 | 22% |
| projected_full_window_ci90_upper | ≤ −0.0004 | **−0.000609** | −0.000209 |
| gfc_regime_coverage | ≥ 0.72 | 0.7692 | +0.049 |
| coverage h1/h5/h21/h63 p10–p90 | [0.76,0.84] | .799/.811/.827/.832 | h63 상단 여유 0.008 |
| coverage p25–p75 | [0.45,0.55] | .528/.525/.525/.523 | 상단 여유 ~0.025 |

**귀결(설계 프레임 전환)**: V10의 과제는 "게이트를 통과시키기"가 아니라 **"이미 통과한 E0 위에서
쌍대 개선을 얹으면서 통과 상태를 절대 잃지 않는 것"**이다. 따라서 모든 W 변형은 E0 항등을
내포(퇴화 파라미터 = E0)해야 하고, 게이트 조건 중 여유가 가장 작은 두 축 — **h63 p10–p90 상단
(0.832 vs 0.84, 여유 0.008)**과 **투영 CI 상단(여유 0.0002)** — 이 V10의 실질 제약이다.
W1(폭 축소)은 첫 축을 오히려 개선하고, 후보의 CRPS 악화는 둘째 축을 위협한다.

### 0.2 봉인창 hold의 유일 사유는 "GFC 국면 누락" — 성적이 아니다
`v8_sealed_run_summaries.json`: sealed_summary(385원점, 2019+) `status=hold`,
`reasons=['필수 위기 국면 누락: great_financial_crisis_2008']`. 성적은 오히려 우수 —
h63 개선 **+4.87%**(전체창 +4.21%), long CI90 상단 −0.000265(≤0 통과), coverage 전 밴드 내.
**귀결**: 최종 설계서 §7 A′(창 승계) 권고가 실측으로 확증된다 — 2019+ 단독 봉인은 계약상 GFC
필수 국면 규칙 때문에 구조적으로 hold다. 창 전진(B)은 이 규칙의 개정 없이는 불가하며, 규칙 개정은
게이트 산술 변경 = 헌법 위반. 따라서 **A′는 권고가 아니라 유일한 합법 경로**다.

### 0.3 V9 exog 5종 소진은 완전 재현된다

## 1. 표적 재정밀화 — 어디서 쌍대 개선이 나오는가

E0 결함 좌표(전체창 1,011): **2020 pandemic cov 0.917**(과잉폭 — 이상적 0.80 대비 +0.117),
**2022 tightening cov 0.750**(과소폭 −0.05), **p25–p75 0.517~0.520**(중심 과잉폭 +0.02).
CRPS 분해(Uncertainty − Resolution + Reliability)로 보면 E0의 Reliability 비용은 **국면 조건부
폭 오배분**에 집중 — 평시엔 정확, 위기 초기에 과잉(2020), 완만 긴축에 과소(2022). 국면조건부
폭 재배분(W1·W3)이 Reliability를 줄이면 CRPS는 **동일 Resolution에서 직접 개선**된다.

**정량 기대(원장 재분석 근거)**: 2020 국면 48원점의 cov 0.917→0.80 교정은 h63 CRPS를
그 국면에서 ~5~8% 개선(과잉폭 분포의 CRPS 폭 항 ∝ 대역폭). 전체창 가중 1,011원점 중 48 =
4.7% → **전체 쌍대 개선 기대 +0.2~0.4%p**. 2022형은 설계창에 대리 없음(§7) → 개발 중 검증 불가.
**정직한 결론: V10 단독 격자의 기대 개선은 소폭(+0.2~0.5%p)이고, 게이트 통과선(+2.5%)은 E0가
이미 +3.23%로 넘어 있으므로 위험은 "개선 실패"가 아니라 "coverage 밴드 이탈에 의한 통과 상실"이다.**

**포크 규율**: ① 사본은 `cp` 후 diff 최소(W 분기만) ② 계약 `source_pins: {backtest.py: <sha>,
model.py: <sha>}` 핀 — 원본이 바뀌면 V10 계약 검증 실패(원본 무변경 감시) ③ `identity_test`가

**전 원점·전 지평 CRPS 절대차 0**(부동소수 비트 동일 — RNG 소비 순서까지 동일해야 하므로 B5
keep-마스크 경로만 허용, 인덱스 가중 금지).

## 3. W1~W5 정밀 파라미터 (사전등록 — 이 표가 등록부)

### W1 국면조건부 재표집 [1순위, 3회]
- 상태 s_t = v_now/v̄, v_now = EWMA(λ=.97) 분산, v̄ = 2520일 롤링 평균분산. 1996~2004 워밍업 = s≡1.
- 재표집: B5 z-풀에 **keep-마스크 가중 quantile** — 가중 w_i = exp(−κ·|s_t − s_i|)/Σ, 표본 i의
  상태 s_i와 현재 s_t 근접도. κ=0 → 균등 = E0 항등(산술 퇴화, RNG 무접촉).
- 격자: **κ ∈ {0.5, 1.0}** (κ=0은 E0 항등 실험으로 별도 1회). 민감도 1회: κ=1.0 × 상태 (c) RV63/RV504.
- 기대: 2020 cov 0.917→0.80~0.85, h63 p10–p90 상단 여유 확대(0.832↓). 위험: 평시 과소폭
  → p25–p75 하단(0.45) 접근 시 κ 상한 고정.

### W3 상태의존 블렌드 [1순위와 병렬, 2회]
- w(s) = clip(0.75 + γ·(s−1), 0.5, 0.9). γ=0 → 정적 .75 = E0.
- 격자: **γ ∈ {−0.10, −0.20}** (고변동 시 FHS 비중↓·historical↑ — historical이 위기 초기에
  더 넓은 꼬리를 주므로 2020 과잉폭 완화 방향은 γ<0). 1줄 분기(backtest_fork.py:179 대응).
- 기대: 국면별 폭 재배분, 평시 무변화. W1과 독립 경로라 조합 후보.

### W2 K성분 혼합 [3회]
- 성분 {FHS, historical, block_bootstrap}, 가중 세트 사전등록:
  S1 (.60/.30/.10) · S2 (.50/.30/.20) · S3 (.70/.20/.10). (.75/.25/0)이 E0.
- 사전 계산: pairwise Cramér ΣwᵢCRPSᵢ − Σwᵢwⱼd(Fᵢ,Fⱼ) — 재보정 전 기준으로 밴드 위반 예상 세트는
  등록 제외(최종 채점은 경험 CRPS). 기대: 중립~소폭. E8(블렌드 확대 단독 cov 이탈) 교훈으로 상한 .70.

### W4 재보정 맵 고도화 [2회]
- W4a: isotonic(PAV) 맵, 무층화, s=.5 유지(맵만 교체). W4b: isotonic + **2층**(s_t 중앙값 기준
  고/저변동 분리 PIT 이력). 성숙 104 요건으로 2007~09 비활성 → GFC 검정 공허 명기.
- 기대: 중심 과잉폭(p25–p75 .52→.50) 교정. 위험: 층별 표본 반감 → 노이즈. 강화 s<.5 금지(E9).

### W5 단기 FHS 확장 [2회, 저기대]
- 계약 grid horizons에 h5 / h1+h5 사전등록(V8 [21,63] 핀 → V10 계약 개정). 기대 중립.

**예산 24 = 단독 12(W1 3·W2 3·W3 2·W4 2·W5 2) + E0 항등 1 + 조합 5 + 예비 6.** 조합은 단독
쌍대 개선 > +0.1%p인 것만, 별도 사전등록. stop-loss: 단독 12 소진 시 최고 쌍대 개선 < +1%면 중단.

## 4. 진단 절차 실행 사양 (매 실험 의무)

1. **E0 항등 사전검사** — identity_test PASS 없으면 실험 무효.
2. **쌍대 통계** — Δ_i = CRPS_i^{E0} − CRPS_i^{cand}(동일 원점), 평균·stationary block bootstrap
   (ℓ=13주, B=2000) CI90, dual MDE50 공표.
3. **게이트 여유 추적** — 4개 실질 제약(h63 cov 상단·투영 CI 상단·p25–p75 하단·GFC) 실측값과
   임계 거리를 원장 `gate_margin` 필드로 직렬화. **여유가 E0보다 줄어든 후보는 개선이 있어도
   "통과 위험" 플래그.**
4. **국면 분해** — GFC/2020/2022 국면별 coverage·CRPS 분해 병기(2020·2022는 설계창 밖이라 전체창
   재분석 참고값으로만, 판정 아님).
5. **노이즈 진단** — Δ=0 비율(95~98% 기대) 확산형/집중형 판정.

## 5. 최종 설계서 대비 달라진 점

1. **프레임 전환(§0.1)**: "통과시키기" → "E0가 이미 통과 — 통과 유지 + 쌍대 개선". 실질 제약 2축
   (h63 cov 상단 여유 0.008·투영 CI 여유 0.0002) 신설, gate_margin 추적 의무화(§4-3).
2. **A′를 권고에서 유일 합법 경로로 격상(§0.2)**: 봉인창 hold 사유가 GFC 필수국면 규칙 단일임을
   실측 — B는 게이트 산술 개정 없이 불가.
3. **W1 가중식 명시**: exp(−κ|s_t−s_i|) 근접도 가중 + κ 격자 {0.5,1.0} 확정, κ=0 별도 항등 실험.
4. **W3 방향 확정**: γ<0(고변동 시 historical↑)로 2020 과잉폭 완화 — 격자 {−0.10,−0.20}.
5. **W2 세트 수치 확정** 3종 + 상한 .70(E8 교훈).
6. **정량 기대의 정직화(§1)**: 단독 격자 기대 +0.2~0.5%p — 통과선은 이미 넘었으므로 위험은
   coverage 이탈에 의한 통과 상실.
7. **파일 단위 포크 설계·identity_test 사양(§2)** 신설.
