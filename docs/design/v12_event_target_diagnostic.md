## 0. 판정 (accept — 1건)

**S3 진입.**

설계도 §1 의 통과 조건은 "과신 구조가 두 지평·국면 초월로 재현되면 S3 진입" 이다. 이 문장을 네 가지로
조작화해 **전부** 평가했고(표 A), 그중 어느 것을 채택하는지의 근거를 결과와 무관하게 고정했다:

> **채택 = R0(설계도 문자·2026-09-04 사전등록) AND R2(엄격 · 주체 = 표적 구조).**
> R1(엄격 · 주체 = V8)은 더 좁은 질문이며 결과와 무관하게 함께 공표한다.
> R3(로짓 기울기)는 보강 증거로만 쓰고 판정에 넣지 않는다 — S2-1 `gate_definition` 승계.

R0 충족(두 지평 부호 양수 · 국면 8/8), R2 충족(h21 CI90 하한 +0.0078 · h63 +0.0654) → **진입**.

**진입이 뜻하지 않는 것 (반대 기록).** R1 은 h21 에서 미달한다(CI90 하한 −0.0097). 즉 확립된 것은
**표적의 과신 구조**이지 **V8 의 과신**이 아니다. 그리고 S2-2 가 확정했듯 V8 은 자유 파라미터 0 개인
반사원리 공식을 두 지평 어디서도 엄밀히 이기지 못한다(표 B2). S3 는 "V8 을 고치면 된다" 는 전제 위에
서 있지 않으며, 그 전제를 되살리는 서술은 본 진단서와 충돌한다.

**채택 근거가 사후 선택이 아닌 이유.** 설계도 §1 문장의 주어는 "V8 의 과신" 이 아니라 **"과신 구조"** 다.
S2-2 가 그 구조의 담지자를 식별했다 — 자유 파라미터가 0 개인 기준선도 같은 방향으로 과신하고(8/8 셀),
V8 확률과의 순위상관은 0.9514(h21)·0.9126(h63), AUC 차는 0.008·0.019 다(표 B2). 과신은 −10%
first-passage 를 변동성으로 확률화할 때 생기는 표적의 성질이므로, "구조가 재현되는가" 를 엄격
조작화로 물을 때 주체는 기준선이어야 한다. 다만 이 논증은 S2-2 결과를 본 뒤에 쓰였다. 그래서 판정에
**유일한 사전등록 조작화인 R0 을 AND 로 함께 요구**해, 사후에 느슨한 쪽으로 갈아타 통과시키는 경로를
막았다(`tools/v12_s2_verdict.py::ADOPTION` 에 문자열로 고정, `V7` 검증이 대사).

기준선은 `p_reflect = 2Φ(−ln(S/K)/(σ√T))`, K/S=0.90, σ = EWMA(λ=0.97) — **자유 파라미터 0 개**.

- **h21 은 V8 이 점추정으로 진다**(기후 대비 스킬: 반사 +7.07% > V8 +4.98%), h63 은 앞서지만(+3.28%)

- 명세 민감도 7 종에서 결론 불변이며 오히려 헤드라인이 기준선에 유리해진다(λ=0.94 는 두 지평 모두 더 좋다).
  V8 이 h63 에서 CI90 하한>0 으로 이기는 유일한 상대는 λ=0.99 — 인위적으로 느리게 만든 변동성뿐이다.
- 드리프트는 과신의 원인이 아니다(μ̂ 투입해도 BS 사실상 불변). 연속 모니터링 가정이 기준선 과신의
  20~45% 를 설명한다(BGK 배리어 보정 β=0.5826, 보편 상수). **단 V8 은 일간 종가 경로에서 최소값을
