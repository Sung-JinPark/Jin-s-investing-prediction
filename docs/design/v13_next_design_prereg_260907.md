## 1. T-A [전제] 검정 기계 수리 — 대안 귀무 3종 (결과 전 등록)

V12 S3의 N1 귀무(창 안 p 치환)가 T1류 수축 맵에 관대해 T5가 실패했다(pooled 0.254 > 0.1). 재개의 전제는
이 기계 수리다. **아래 3종을 결과 보기 전 고정 등록**하고, 기존 S3 데이터(first_touch p/y, 417×h21/63)로 재검한다.

| 귀무 | 정의 | 의도 |
|---|---|---|
| **N-y** | y-치환: 터치 라벨 y를 블록(ℓ=13) 보존 순열, p 고정 | 맵이 실제 p→y 관계가 아닌 p 자체 구조를 이용하는지 |
| **N-blk** | 블록 순열(ℓ=13): (p,y) 쌍을 블록 단위로 시간 순열 | 시간 구조 파괴 하 우연 통과율 |
| **N-rank** | 창 내 순위보존 p 셔플: p의 순위는 보존하되 y와의 정렬만 무작위화 | 순위정보 보존 하 귀무 (기존 N1의 정밀판) |

- **수리 판정** = 세 귀무 **모두** 기존 T5 조건에서 통과율 ≤ 0.10. 하나라도 초과 → **미수리 → 어떤 재개도 금지**.
- 0 백테스트(원장 재분석). 실패 시 T-B/T-C의 전이 검정은 무의미하므로 **T-A가 T-B·T-C 게이트다.**

## 2. T-B [1순위·구조] V12b — 경로 생성기 수정 (H3)

- **후보(사전등록 격자)**: 표준화 잔차 z의 재표집을 i.i.d.에서 단기 자기상관 보존으로:
  - `B(ℓ_z)` stationary block bootstrap, ℓ_z ∈ {2, 3, 5}. **ℓ_z=1 = 현행 i.i.d. = E0 항등**(비트 검증).
  - `AR1(φ)` 잔차 경로 z_t = φ·z_{t−1} + ε, φ는 research_train 추정(φ=0 = E0). P1 실측 φ̂=−0.053 → 음의 φ 기대.
- **제약(전부 충족해야 채택)**: ① **CRPS 게이트 무손상**(h21/63 종점 분위수 coverage 밴드 내·쌍대 CRPS 비열화) ∧
  ② E0 항등 테스트(ℓ_z=1 비트동일) ∧ ③ 사전등록 ∧ ④ **T-A 수리된 귀무**로 터치 Brier 양방향 전이(CI90 하한>0) ∧
  ⑤ 상위5% 원점 제거 후 부호 유지.
- **예산 ≤ 6**: E0 항등(ℓ_z=1) → B(2)·B(3)·B(5) → AR1 → 예비 1. design 창·2000경로. **홀드아웃 미소모.**
- **정직한 기대**: P1이 modest(VR 0.87)라 저변동·단기 터치 과예측 축소는 소폭(h21 BSS +1~3%p 추정). 실패도 정보.

## 3. T-C [1순위·병렬] V13-VOL — 변동성 이벤트 확률 트랙 (별도 계약·예산)

- **모형 사다리(전부 기후 내포)**: 기후 → EWMA 로짓 → HAR-로지스틱(Corsi 2009) → GARCH-t 시뮬레이션.
- **게이트(새 계약 V13, 사용자 승인)**: BSS vs 기후 CI90 하한 > 0 ∧ 양방향 전이 ∧ reliability 보고.
  채점 Brier/log, 쌍대 블록부트, MDE 공표, 5-role·PIT 승계. **CRPS 게이트·V8 무관 독립 트랙**(파생층 아님).
- **예산 ≤ 8**: 기후·EWMA·HAR·GARCH-t × 지평/표적. **홀드아웃 미소모.**
- **정직한 기대**: 변동성은 예측가능(|r| 자기상관)이라 skill 사전확률 높음. 단 가치는 **EXIT 트리거 base rate 공급**이지 가격 방향이 아니다.

## 7. 정직한 기대치 (전체)

사전확률 높으나 가치는 base rate 공급. 둘 다 실패하면 잔여는 옵션 데이터(C1, CBOE 허가 종속). **게이트 완화·
outer 재사용으로 뒤집는 경로는 없다.** T-A 실패 시 재개 자체가 금지된다 — 이 문서의 첫 게이트.
