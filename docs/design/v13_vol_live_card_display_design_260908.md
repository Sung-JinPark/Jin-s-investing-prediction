# V13-VOL 파생층 라이브 카드 표시 설계서 (2026-09-08)

> 지위: **설계서(T1)**. 표시 자체는 배포 사다리 T2(숨김 패널)→T3(라이브 카드) 승격 결정 후에만 구현한다.
> 현재 V13-VOL은 **T0(내부 산출물·미배선)** — `src/` 어디에도 V13 참조 0건. 이 문서는 "어떻게 올릴 것인가"를
> 결정 전에 못 박아 사후 완화·이름 혼동을 막는 것이 목적이다.
> 상위 정본: 계약 `data/contracts/multivariate_timeseries_v13_vol.yaml`, 판정 `V13_VOL_RUNG1/2_VERDICT`,
> 사다리·X1 원문 `docs/design/v12_gate_design.md §4`, UI 관례 `website_uiux_visualization_design_260902.md`.

## 0. 표시하려는 것이 정확히 무엇인가

- 모형: **EWMA-logit (champion)** — 현재 VIX 레벨·EWMA21(VIX) → 로지스틱 → P(이벤트). RV 표적은 RV21·EWMA21(RV21).
- 표적 9셀: P(VIX_close ≥ 25 within h)·P(VIX_close ≥ 30 within h), h∈{5,21,63} **영업일**; P(RV21_ann > 0.1694 within h).
- 성격: **변동성 지속성 기반 base rate**. 기후 대비 스킬 실재(BSS +0.09~+0.90, 양방향 CI90>0, 건전귀무≤0.017)이나
  richer 모형이 증분 0 → 스킬=지속성. 가치 = EXIT 트리거 base rate·조기경보 공급. **시장 엣지·매매 신호 아님.**
- 검증 지위: **설계창(2007-2014) 한정, 홀드아웃(2015-2018) 미검증**(V13-D3 보류). reliability: h5 잘 보정(rel≈0.002),
  h63 오보정(rel≈0.08).

## 1. 이름 충돌 X1 — 이 설계의 핵심 문제

**규칙 X1(승계)**: 파생층이 표시면에 오르려면 화면에서 같은 이름의 수들의 **정의·지평·출처·보정 상태가 구분
가능**해야 한다. 구분할 수 없으면 표시하지 않는다.

### 1.1 실제 충돌 대상 (실측)

| 표시면의 기존 수 | 정의 | 지평 | 출처 | 보정 상태 |
|---|---|---|---|---|
| 질문 `vix-25-90d` "90일 내 VIX 종가 25 상회" | P(VIX_close>25 1회 이상) | **90 달력일**, rolling | **LLM 예측 파이프라인**(§06 추론 코어, 리서치·premortem) | 캘리브레이션 원장 채점(Brier), '참고 의견' |
| V13-VOL `vix25_h63` | P(VIX_close≥25 within 63) | **63 영업일 ≈ 90 달력일** | **결정론 수치모델**(EWMA-logit, 지속성) | 설계창 스킬, 홀드아웃 미검증, 원장 채점 아님 |

**거의 같은 양을 두 출처가 낸다.** 같은 화면에 "VIX 25 상회 확률 xx%"가 둘 뜨면 사용자 기억에서 분리되지 않는다
(V12-D3가 '−10% 접촉' 16곳에 대해 경고한 것과 동일 구조). 게다가 두 수는 **역할이 다르다**: LLM 예측이 1차 목표
(이벤트 확률화)의 본체이고, V13-VOL은 그 예측에 **base rate로 공급**되는 outside view다. 둘을 동격으로 나란히
표시하면 역할 혼동까지 생긴다.

### 1.2 해소 설계 (충족 못 하면 표시 금지)

1. **명칭 분리 — 같은 단어를 쓰지 않는다.** V13-VOL 카드 제목은 "변동성 지속성 base rate"(또는 "VIX 지속성 기준율").
   "예측"·"확률 예측"이라는 표현은 LLM 질문 카드에만 쓴다. V13-VOL 셀 라벨은 "기준율 xx%"로, 질문 카드는 "예측 xx%".
2. **출처 배지 상시**: V13-VOL 카드에 `수치모델 · 지속성` 배지(회색), LLM 카드에 `AI 예측` 배지. 배지 없는 확률은 없다.
3. **지평 단위 명시**: V13-VOL은 "63영업일", 질문은 "90달력일". 숫자만 쓰지 않는다(63과 90이 같은 창임을 각주로 설명).
4. **보정 상태 라벨 상시**: V13-VOL 카드 caveat lead = "설계창(2007-2014) 스킬 · 홀드아웃 미검증 · 참고 의견".
   홀드아웃 통과 시 문구만 갱신(카드 구조 불변).
5. **역할 관계 명시**: LLM 질문 카드가 있을 때 V13-VOL 카드에 "이 값은 위 예측의 base rate(outside view)로 공급됨"
   한 줄. 두 값의 괴리가 15%p+ 이면 `due`의 divergence 관례처럼 **표시만**(자동 재예측·자동 조정 금지, CLAUDE.md).
6. **금지**: 두 값을 합산·평균·"컨센서스"로 묶어 하나의 수로 보이게 하는 것.

X1 충족 판정은 **사람 검수**(V13 표시 승격 결정 시 스크린샷으로 확인)다. 6개 중 하나라도 미충족이면 T3 진입 불가.

## 2. 배포 사다리 위치와 게이트

| 단계 | 내용 | 게이트 | V13-VOL 현재 |
|---|---|---|---|
| T0 | 내부 산출물(`data/timeseries_v13/**`) | 봉인 무변경·원장 무수정 | **현재 위치** ✓ |
| T1 | 문서·리뷰팩 | 수치에 CI·귀무 동반·미검증 표기 | ✓ (판정서·이 설계서) |
| **T2** | 대시보드 **숨김 패널**(기본 hidden, 검증 대기 라벨) | 게이트 무장 + G0 무손상 대사 + **표시 승격 승인(V13-D4 신설)** | 미진입 — 결정 대기 |
| **T3** | **라이브 카드** 노출 | T2 + 게이트 두 지평 전부 통과 + **X1 해소(§1.2 6항)** + '참고 의견' 상시 | 미진입 |
| T4 | 실전 자금 결정 근거 | CLAUDE.md **P3 게이트**(해소 50문항+ & Brier<0.18) | **차단** — 어떤 조건에도 안 열림 |

- "게이트 무장": 계약 `gates.armed`를 true로 올리고 `evaluated_candidates=1(ewma_logit)`, 통과 기록. 현재 draft는
  후보 0 상태의 사전등록이라 armed=false — 승격 시 **결과를 본 뒤 임계를 바꾸지 않았음**을 amendment로 남긴다.
- **홀드아웃과의 관계(권고)**: 사다리 원문은 T3에 홀드아웃을 명시 요구하지 않는다. 그러나 이 설계는 **T3 전에
  V13-D3(홀드아웃 소모) 통과를 권고**한다 — 이유: 라이브 카드는 사용자가 매일 보는 면이고, 설계창 한정 스킬을
  "검증됨"으로 오독할 위험이 크다. 홀드아웃 없이 T3로 가려면 caveat lead에 "홀드아웃 미검증"을 **굵게 상시** 유지해야
  하며, 이 경우 T2(숨김 패널)에 머무는 것을 1차 권고한다.

## 3. 데이터·계산 경로 (v8 shadow card 패턴 미러)

```
market archive (봉인 V2 read_market_observations, PIT: available_at ≤ now)
  └─ VIX 최신 종가·EWMA21 · NASDAQCOM→RV21·EWMA21          ← 실시간 아님, 일간 T+1
frozen coefficients artifact  data/timeseries_v13/vol/ewma_logit_coefficients.json
  └─ 설계창 전체(2007-2014)에 1회 적합한 β·μ·σ(표준화) + sha256 · 재적합 금지(retune 금지 승계)
compute  P_{K,h} = σ(β·[1, z(VIX), z(EWMA21)])  ×9셀
  └─ 80% 대역: 계약 부트스트랩 se 기반 ±1.28·se (CLAUDE.md '80% 신뢰구간 병기' 규약)
write   reports/timeseries_v13_vol.json  (전용 예산 24 KB — statistics.json 160KB 예산에 얹지 않는다)
load    src/ai_fc/timeseries_v13_vol_display.py :: validate_latest → build → load (fail-closed)
  └─ 신선도 실패(VIX가 1영업일 초과 stale) / 스키마 실패 / 계수 해시 불일치 → None → 카드 HOLD 표시
render  dashboard.js renderTimeseriesV13Vol (v8 card 함수 구조 복제)
```

- **계수 동결**: 라이브에서 절대 재적합하지 않는다(V8의 retune 금지·frozen 승계). 계수 파일은 해시로 계약에 핀.
  갱신은 "새 버전 사전등록→게이트 재통과"로만.
- **PIT·신선도**: 카드에 `기준일 YYYY-MM-DD (KST)`·`VIX xx.x` 원값 병기. stale이면 확률을 숨기고 "데이터 지연" HOLD.
- **예산**: 9셀×(p, 80%대역, 기준일) + 메타 ≈ 2 KB 실사용. 24 KB 상한을 `DASHBOARD` 예산 상수에 신설
  (`TIMESERIES_V13_VOL_BUDGET_BYTES`). 기존 raw 1536 KB(34.8% 여유)·statistics 160 KB 예산 무접촉.
- **원장**: 라이브 산출 시각·입력·출력을 `data/timeseries_v13/ledgers/vol_live.jsonl`에 append-only 기록
  (이후 홀드아웃·라이브 포워드 채점의 원천). 예측 파일·캘리브레이션 원장(`calibration/ledger.csv`)에는 **쓰지 않는다**
  — 그건 LLM 예측 전용이며 V13-VOL은 캘리브레이션 표본이 아니다(dualdb §8).

## 5. 표시 규율·금지 (CLAUDE.md 하드 게이트 승계)

- 모든 출력 **'참고 의견'** 지위 상시. P3 게이트(해소 50문항+ & Brier<0.18) 전엔 실전 자금 결정 근거 아님 → T4 차단.
- **매매 신호 아님** — 사용자 하드 룰(VIX 25+, 드로다운)은 확률과 무관하게 기계적 유지. 이 카드는 조기경보 보조.
- LLM 예측과의 괴리(15%p+)는 **표시만** — 자동 재예측·자동 조정 금지, 판단은 사람.
- 라이브 재적합·임계 완화·outer 재사용 금지. 표시 후 게이트 값 변경은 사후 완화 = 위반.
- Brier 무능 도메인(>0.22) 차단 규칙은 LLM 도메인용이나, V13-VOL도 라이브 포워드 채점(`vol_live.jsonl`)이 쌓여
  h별 Brier가 기후를 못 이기면 해당 셀 표시를 내린다(자동 게이트 — 사전등록).

## 8. 구현 단계 (설계서 — 착수는 승인 후, 각 단계 로컬 커밋·게이트 대사)

1. 계수 동결 artifact 생성 + 계약에 해시 핀 (`ewma_logit_coefficients.json`).
2. `timeseries_v13_vol_display.py`(validate/build/load, fail-closed) + `reports/timeseries_v13_vol.json` + 예산 상수.
3. `vol_live.jsonl` append 원장 + 라이브 포워드 채점 스크립트(사전등록 자동 게이트).
4. dashboard.js 숨김 패널(T2) + X1 6항 구현 + 접근성. 브라우저 검증(패널 hidden/0폭 rAF 함정 주의 — 기존 메모).
5. 사람 검수(스크린샷) → V13-D4 → T2 배포. 이후 D3·D5 충족 시 T3 노출.

## 9. 정직한 한계

- 표시 값은 **지속성**이다 — VIX가 낮으면 낮은 확률, 높으면 높은 확률. 놀라운 정보가 아니라 "지금 변동성 국면에서
  임계 터치의 역사적 기준율"이다. 그 이상으로 읽히게 하는 UI는 X1 위반이다.
- 설계창이 GFC 포함이라 기준율이 위기 가중(base rate 높음). 평온기 라이브에서는 낮은 값이 정상.
- 63영업일 셀은 오보정(rel 0.08) — 대역·마커 없이 단독 표시 금지.
