## 2. E2~E4 재분해 — 초안이 못 본 것 (부트스트랩 10,000회, n=417/지평)

### 2.1 숨은 개선은 없다 — 16개(실험×지평)·12개(실험×국면) 검정 전수

- 유의 **개선 0건**. 유의 악화 3건은 전부 E2 TOTCI (h1 +0.245%·h21 +0.105%·h63 +0.097%).
- **E3 TOTLL h5 −0.255%는 무유의 확정** (CI90 [−0.614%, +0.135%], GFC 구간에 몰린 요동).
  원장 요약치의 h5 개선율 차이를 유의 신호로 인용하지 말 것.
- **"위기 국면 개선" 가설 기각**: 유동성·신용 계열이 위기에 도움될 것이라는 기대와 반대로
  GFC에서 E1 M2SL +0.071%·E4 WRMFNS +0.057% 유의 악화, 유로위기에서 E2 +0.129% 유의 악화.

### 2.2 실패 모드 판별 — 정보 중복이 아니라 노이즈 주입

- 중복이었다면 Δ≈0 무해였어야 한다(상관 0.11~0.17로 낮음). 실제는 E2가 **2단 구조 악화**:
  - 2010+ **확산형**: 악화 원점 비율 61%(2011년 81%), 상위 1% 절사 후에도 평균 양수 —
    ridge에 노이즈 회귀변수를 더한 전형적 패턴.
  - 2007~08 **집중형**: 상위 10개 원점이 총 악화의 66%(2008-09-26 h63 단독 18%) —
    신용 z-점수 급변 시 tilt가 크게 어긋난 사례.
- **부수 발견(전 실험 공통)**: 2007~08 장기지평 쌍대차의 94~96%가 Δ<1e-8 — 확장창 초기에는
  신규 exog가 장기 FHS tilt에 사실상 0 가중(2009년경 활성화). 즉 GFC 본체에서 신규 피처는
  작동조차 안 했고, 작동 후에는 노이즈만 남았다.

### 2.3 설계 함의 (다음 채널의 요건)

1. 수준변화 유동성·신용 계열과 **동일 소스의 변형(스케일링·차분 차수 변경) 재시도 배제**.
2. 필요한 것은 직교성이 아니라 **예측력 자체가 있는 가격 기반 상태 변수** — 일간 갱신,
   분포·스케일 채널 직결.
3. 신규 피처 정의에 **z-급변 가드(윈저라이즈 ±3, 사전등록)** 포함 — 2008-09-26류 단일 대형
   악화 방지. (tilt 클리핑 자체는 V8 엔진 수정이라 불가 — 피처 전처리 단계에서만.)
4. 설계창 검출력 한계 공표: 이 표본으로 판별 가능한 최소 효과는 지평별 상대 0.03~0.4%p.

## 8. 초안(DRAFT_A) 대비 달라진 점과 근거

1. **채널 우선순위 재편**: 초안의 "일간 신용 스프레드" 후보를 **폐기 확정**으로 강등 —
   ALFRED·fredgraph 실측으로 소스 롤링 3년 창(백필 불가)이 확인됐기 때문.
2. **"변동성 기간구조" 명명 폐기 → 교차지수 스프레드로 재정의** — VXN 단일물로 기간구조가
   성립하지 않고, 원시 Δlog(VXN)은 상관 0.918로 자동 기각됨을 사전 실측. 스프레드 형태만
   등록 가능함을 실측 수치로 확정.
3. **부분-온셋 아키텍처를 '검토'에서 '구체 사전등록 사양(§4 R9-A)'으로 승격** — VXN 온셋
   (2009-09)이 이 아키텍처 없이는 P1 채널 자체가 불가능하기 때문. 2007-08 장기지평 무작동
   실측(§2.2)이 서브창 손실이 작다는 근거를 제공.
4. **위기 국면 기대의 명시 기각**: 초안은 신용·유동성의 위기 기여를 암묵 가정했으나 국면
   분해로 반증(GFC·유로위기 유의 악화) — 새 채널 기대치 산정에서 이 가설 사용 금지 명문화.
5. **z-윈저라이즈 가드 추가**: E2의 2단 악화 구조(집중형 성분) 실측에서 도출.
6. **거버넌스 게이트 구체화**: CBOE 사용 범위 확장이 소유자 결정(12-5 미발송 허가서·약관
   문언)임을 실사로 확인 — 초안의 "검토" 표현을 결정 대기 항목(V9-D6/D9)으로 승격.
