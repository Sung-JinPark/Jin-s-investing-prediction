# T03 — σ 공급과 V13 base rate 배선 (2026-09-11)

> 사용자 확정(2026-09-10, 결과 보기 전) 2건:
> ① **양 일치 우선 + 두 경로가 같은 양을 재면 큰 σ 채택**
> ② **배선 코드는 만들고 대상 0으로 페일클로즈**

## 1. 팩의 전제 하나를 정정했다 — V13 은 σ 를 공급할 수 없다

T03 팩은 "변동성 질문 → V13 PB 셀(검증 3셀만)"로 σ 매핑을 적었다. 그런데 V13 셀 산출은
`P(사건)` 이지 **산포가 아니다**. 확률에서 σ 를 역산하면 두 가지가 동시에 깨진다.

- **8-8 위반** — 공식 확률은 LLM rN 이고 트랙 확률은 결합되지 않는다. σ 를 거쳐 들어와도 결합이다.
- **z 규율의 자기무력화** — z 규율이 존재하는 이유는 정직 확률 `p` 를 **독립적으로 구속**하는 것이다.
  `p` 에서 `z` 를 뽑으면 `z = Φ⁻¹(1−p)` 라는 항등식이 되어 어떤 `p` 를 써도 자동 통과한다.
  `SELECTION.md` 가 `fedfunds-cut-to-350-by-2027-01-15` 을 거부한 사유가 정확히 이것이다.

그래서 σ 경로는 둘이다: **정규화 계열 저장소(참조클래스)** 와 **V8 분위수**. V13 의 몫은
`vol_base_rate_wiring` 의 **표시 전용** 경로이며 §4 에서 따로 다룬다.

## 2. 정본 규칙 — `src/ai_fc/sigma_supply.py`

### 규칙 1 · 양(quantity) 일치가 선결 조건

σ 는 "질문이 묻는 양"의 산포여야 한다. 창 내 최댓값을 묻는 질문에는 창 내 최댓값 분포를,
종점 값을 묻는 질문에는 종점 수익률 분포를 쓴다.

| 경로 | 잴 수 있는 양 |
|---|---|
| `reference_class` (계열 저장소 7종, 1990~) | `terminal_log_return` · `window_max` · `window_min` · `window_count_above` |
| `v8_quantiles` (V8 산출 JSON) | NASDAQCOM `terminal_log_return` **뿐** |
| `manual_reference_class` (`base_rates/*.md`·예측 파일) | 자유 문자열로 선언한 양 (실적 서프라이즈·SEP 점 분산 등) |
| `v13_vol_cells` | **없음** |

양이 다른 견적은 경쟁에 올리지 않고 **제외 사유와 함께 인쇄**한다 — 조용히 버리면
"두 경로를 봤다"는 인상만 남는다. 어느 경로도 양을 맞추지 못하면 거부한다. 근사 σ 를 지어내지 않는다.

### 규칙 2 · 둘 다 같은 양을 재면 큰 σ

큰 σ 는 z 를 낮춰 등록을 어렵게 만드는 방향이라 게이밍의 반대편이다. 작은 쪽은 교차검증으로 남긴다.

### 규칙 3 · 조건화는 계산 **전에** 하나로 선언한다 (규칙 2 의 구멍 막기)

`전체기간 σ` 와 `2010년 이후 σ` 는 두 경로가 아니라 **한 경로의 두 파라미터**다. 큰 쪽을
고르게 두면 규칙 2 가 조건화 쇼핑 장치로 변한다. 실측으로 이 구멍은 크다 — 나스닥 87영업일
종점 로그수익률 σ 는 **전체 0.0971 · 2010+ 0.0772 · 2015+ 0.0841** 로 26% 벌어지고,
어느 쪽을 고르느냐로 `nasdaq-comp-30000` 의 z 가 **1.37 ~ 1.73** 을 오간다.
`adopt()` 는 같은 `path` 의 견적이 둘 이상이면 거부한다.

### 규칙 4 · σ 는 자(尺)이지 과녁이 아니다

이 모듈은 임계를 제안하지 않는다. `sigma-quote` CLI 는 `--threshold` 와 `--center` 를
**사람이 줄 때만** z 를 계산하고, 주지 않으면 "임계는 사람이 정한다"고 인쇄하고 멈춘다.
자를 건네는 쪽이 과녁도 그리면 z 규율은 자기충족이 된다.

## 3. 등록 12건과의 대조 — σ 값은 재현되고, 라벨만 소급 기재했다

기계 경로 4건을 이 모듈로 다시 계산했다.

| 질문 | 경로 | 등록값 | 재계산 | 차이 |
|---|---|---|---|---|
| `vix-40-touch-by-2027-01-15` | reference_class · `window_max` | 6.553 | **6.553** | 0 |
| `t10y2y-100bp-by-2027-01-15` | reference_class · `window_max` | 0.230 | **0.230** | 0 |
| `nasdaq-comp-30000-close-2027-01-15` | v8_quantiles · `terminal_log_return` | 0.08117 | **0.081172** | 2e-6 |
| `vix-above20-40days-by-2027-01-15` | reference_class · `window_count_above` | 20.015 | **19.644** | −1.9% |

마지막 한 건의 차이는 **분위수 보간 방식**에서 온다(카운트는 0 에 몰린 이산 분포라 보간에
민감하다). z 는 1.60 vs 1.63 으로 계약 밴드 판정이 바뀌지 않는다.

**값은 바꾸지 않았다.** 계약이 "규칙 변경은 기존 등록분에 소급하지 않는다"고 못박았고,
T03 채택 규칙은 **이후 등록분**부터 적용된다. 12건의 `prereg` 에는 `sigma_quantity` ·
`sigma_path` · (기계 경로 4건은) `sigma_reproduce` 라벨만 추가했다 — 어느 양을 어느 경로로
쟀는지가 기록에 없으면 나중에 T03 규칙으로 감사할 수 없기 때문이다.
나머지 67문항은 바이트 무변경(diff `+40 −0`).

경로 분포: `manual_reference_class` 8 · `reference_class` 3 · `v8_quantiles` 1 · `v13_vol_cells` **0**.

## 4. V13 배선 — 대상 0건, 페일클로즈

배선 자격은 세 조건의 **논리곱**이고, 계약에서 읽는다(리터럴 금지 — 테스트로 고정).

| # | 조건 | 통과 |
|---|---|---|
| 1 | 홀드아웃 통과 — `publication.holdout_pass_cells` | `vix25_h21` · `rv_h5` · `rv_h21` |
| 2 | 설계창 국면 가드 통과 — `publication.wiring_eligible_cells` | `rv_h5` · `rv_h21` |
| 3 | **대응하는 등록 질문 존재** | **없음** |

`vix25_h21` 은 홀드아웃을 통과했지만 설계창 late 국면이 4개뿐이라 (2) 에서 걸린다 —
통과만 보면 새어 들어오므로 **교집합**을 쓴다. `rv_h5`·`rv_h21` 은 `P(RV21 > 0.1694)` 을
묻는데 레지스트리에 실현변동성 질문이 없다. 등록된 `vix-25-90d` 는 90달력일 ≈ 63영업일이라
`vix25_h63` 에 대응하는데 그 셀은 홀드아웃에서 **실패**했다.

그래서 **배선 0건**이고 화면에 바뀌는 것은 없다. 코드를 미리 두는 이유는 자격 셀이나 대응
질문이 생겼을 때 설계를 다시 하지 않고 `CELL_QUESTION_MAP` 만 채우면 켜지게 하기 위해서다.
자격 미달 셀을 지도에 넣으면 **예외로 거부**된다(테스트 4셀로 고정).

배선이 켜져도 내보내는 것은 **원재료**뿐이다 — 기후 기저율 `clim_base_rate` · 임계 · 지평 · as_of.
모델의 `p`·`p_raw`·`band80`·`se_raw` 는 넘기지 않는다. 앵커링 금지가 이유다: 질문별 매핑
확률이 digest 에 들어가면 rN 이 트랙 확률의 재진술이 되고, 그 순간 원장은 LLM 캘리브레이션
표본이 아니라 트랙의 그림자가 된다. 기후 기저율은 트랙의 견해가 아니라 **역사 빈도**라서
outside view 재료로 정당하다.
