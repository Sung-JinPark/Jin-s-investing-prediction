# T03 — 수치 트랙 → 등록 시점 σ 공급 (확률 아님) + 검증 셀 base rate 표시 배선

## 목표
V8(분위수)·V13(변동성 사건) 트랙이 게이트에 기여하는 유일한 합법 경로: **σ(산포)를 질문 등록 시점에 공급**해 z 규율을 집행한다. 확률 결합은 금지(8-8).

## 절차
1. `ai_fc/sigma_supply.py`: 질문 유형별 σ 소스 매핑 — 지수 수준/수익률 질문 → V8 분위수(q25–q75→σ 환산, 봉인 파일 무접촉·산출 JSON만 읽기), 변동성 질문 → V13 PB 셀(검증 3셀 rv_h5·rv_h21·vix25_h21만), 그 외 → 참조클래스 sd. 출처·시점(available_at) 기록.
2. 등록 CLI가 σ를 자동 채우되 **사람이 임계를 정한다** — σ는 앵커가 아니다(문서 문구 고정).
3. base rate 표시 배선(V13-D6): 검증 3셀만 대응 EXIT 질문 카드에 "참고 base rate" 표시. h63·VIX30 셀 배선 금지.
4. 테스트: σ 출처 필수·확률 필드 부재·미검증 셀 배선 거부.

## 수용 기준
등록 질문 파일에 σ·출처 100% 기재 · 확률 결합 0 · 배선은 검증 셀 3개로 한정.
