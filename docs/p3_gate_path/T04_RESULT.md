## 2. 등록 시점 z 사후 계측 — 재분류 없음

계측만 하고 아무것도 바꾸지 않았다. `status` 무변경 · `research_status` 무변경 ·
void 0건 · 원장 행 무수정 · 예측 파일 무수정. `postmortem` 블록은 점수에 개입하지 않는다.

| 질문 | z | 정직확률 | 기대 바닥 | 문항 상한 0.21 | 계약 밴드 |
|---|---|---|---|---|---|
| `nfp-aug2026-below100k` (해소) | **0.474** | 0.682 | 0.2168 | 초과 | reject |
| `nfp-oct2026-below100k` | **0.228** | 0.590 | 0.2418 | 초과 | reject |
| `nfp-nov2026-below100k` | **0.228** | 0.590 | 0.2418 | 초과 | reject |
| `nfp-dec2026-below-neg75k` (신규) | **1.526** | 0.064 | 0.0594 | 이내 | accept |

**σ 경로가 둘로 갈린다.** aug 는 r1 시점에 컨센서스가 있었으므로 컨센 오차 σ 95K 로
`|100 − 55| / 95 = 0.474`. oct·nov 는 r1 시점 컨센이 **NOT FOUND** 였으므로 컨센 σ 를 쓸 수 없고,
계열 자체 산포로 계측했다 — 2026년 1~7월 최초 공표 `[130, −92, 178, 115, 172, 57, −23]K` 의
평균 76.7K · 표본SD 102.0K → `|100 − 76.7| / 102.0 = 0.228`. 컨센이 없으면 z 가 **더 나빠진다**.

**손실의 대부분은 예측이 아니라 질문에서 왔다.** aug r1 은 q=0.74 로 정직확률 0.682 와 +0.058
차이뿐인데 실현 Brier 는 0.5476 이었다. 기대 바닥만으로 이미 0.2168 이다.

**지렛대는 임계다.** 신규 `nfp-dec2026-below-neg75k` 는 **같은 σ 95K 를 그대로 두고** 임계만
100K → −75K 로 옮겼다. z 0.474 → 1.526, 기대 바닥 0.2168 → 0.0594 로 **72.6% 하락**.
무엇을 묻느냐가 아니라 임계가 어디 있느냐가 바닥을 정한다.

## 3. 팩 문구 하나를 정정했다 — L3 는 이 두 건에 적용되지 않는다

팩은 "T02 의 L3 규칙에 따라 컨센서스 공표 후 r2 재예측"이라고 적었다. 그런데 계약의
`L3_defer_r1_if_no_consensus.scope` 는 **"이 계약 등록일(2026-09-10) 이후 신규 등록 질문만.
기존 질문에 소급 적용 금지"** 다. oct·nov 는 2026-07-20 등록이라 L3 대상이 아니다.

실무적으로 결과는 같다 — 두 질문의 등록 cadence 가 이미 `r1 + D-3` 이고
(oct D-3 = 2026-11-03 · nov D-3 = 2026-12-01), 컨센서스는 통상 발표 1~2주 전에 형성되므로
D-3 회차는 자연히 컨센 공표 이후가 된다. **L3 를 발동할 필요가 없다.** 필요도 없는데 소급
적용하면 "유예 규칙을 결과를 보고 꺼내 썼다"는 기록만 남는다.

## 4. r2 는 r1 손실을 지우지 않는다

원장은 회차별로 행이 남고 대표 Brier 는 **행 평균**이다. 늦게 나온 정확한 회차는 r1 행을
덮지 않고 **희석만** 한다. 재예측은 손실 취소가 아니라 표본 추가다. 두 질문의 `postmortem.r2_note`
에 이 문장을 넣었고 테스트로 고정했다.

## 5. 손실 3분해 — `src/ai_fc/loss_decomp.py`

    Brier = (q − y)²
          = p(1−p)                    ← 기대 바닥   · 등록 시점에서만 고칠 수 있다
          + [(p − y)² − p(1−p)]       ← 뽑기        · 고칠 수 없다 (기댓값 0)
          + [(q − y)² − (p − y)²]     ← 앵커 초과   · 유일한 실력 축

`p` 는 **등록 시점 고정값**에서만 온다: `prereg.honest_probability_estimate` 또는 `notes` 의
`예상확률 N% (첫 예측 전 고정)`. `리서치 이후 산정` 으로 명기된 대체 질문은 제외한다
(`budget_reconciliation` 과 같은 규약). 둘 다 없으면 **분해하지 않는다** — 없는 값을 지어내지 않는다.

앵커 초과는 부호가 양쪽으로 열려 있다. 음이면 그 회차에서 `q` 가 `p` 보다 나았다는 뜻이다.
벌점 전용이면 분해가 아니라 훈계다.
