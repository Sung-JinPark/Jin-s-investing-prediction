# T04 — NFP 계열 가드: 예약된 2연패 대응(파일 무수정 하에서)

## 사실
`nfp-oct2026`·`nfp-nov2026` r1 = 66%(컨센 NOT FOUND, 같은 날·같은 전제). 둘 다 NO면 primary 0.1599→**0.2058**. r1 파일은 수정·삭제 불가.

## 허용되는 대응(전부 사전등록 cadence 내)
1. T02의 L3 규칙에 따라 **컨센서스 공표 후 r2 재예측**(새 파일). 원장에는 회차별 행이 남고 대표 Brier는 primary 규칙대로 — r2를 만든다고 r1 손실이 사라지지 않음을 문서에 명시.
2. 임계 설계 교훈 등재: NFP형 질문은 z≥1.0 미달 시 등록 거부(T02). 기존 2건은 `z_at_registration` 사후 계측만(0.47σ류) — 재분류·void 금지.
3. 손실 분해 스크립트(`ai_fc/loss_decomp.py`): 기대바닥 p(1−p)·뽑기·앵커초과 3분해를 해소 시 자동 기록(팩 §3-2 공식).

## 수용 기준
r1 무수정 · r2는 컨센 공표 이후 시각 증명 · 분해 리포트 생성 · 향후 NFP 등록은 z 게이트 통과분만.
