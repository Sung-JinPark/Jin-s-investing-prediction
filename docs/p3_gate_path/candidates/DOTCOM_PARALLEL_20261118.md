## 4. 재현 절차

1. 일간 종가: dualdb `price_daily` `^IXIC`(1990-01-02~)에 Yahoo 일봉을 이어 기준일 종가까지 만든다.
2. 창 길이 H: 창 시작일부터 마감까지의 NYSE 거래일 수.
3. 각 출발일 i 에 대해 기준일과 창 시작일 사이의 거래일 공백을 똑같이 두고 창 `w` 를 잡는다(최종 B′ 는 공백 0).
4. 하방 질문은 `ln(min(w)/close[i])`, 상방 질문은 `ln(max(w)/close[i])` 를 표본으로 쓴다.
5. σ = IQR/1.349, 중심 = 중앙값, 임계 거리 = `ln(임계/기준일 종가)`, z = `|임계 거리-중심|/σ`.
6. 빈도는 하방 `표본 <= 임계 거리`, 상방 `표본 > 임계 거리` 의 비율이다. 겹치는 창이라 독립 표본이 아니다.
