## 0. 이 문서가 지키려는 산술

기대 Brier 바닥 = **E[p(1−p)]**. 계약의 z 밴드는 정규 꼬리 매핑 `z = Φ⁻¹(1−p)` 과 정확히 일치한다
(계약 rationale 재검증: z=1.0 → 0.1587 ≈ 0.16, z=0.7 → 0.2420 ≈ 0.242 — 본 문서에서 직접 재계산).
따라서 **임계를 σ 로 밀면 z 가 오르고 기대 Brier 바닥이 내려간다**. 이 문서의 모든 후보는
"무엇을 묻는가"가 아니라 **"임계를 σ 의 몇 배 밖에 두는가"** 로 설계됐다.

## 2. 후보별 상세

### M1 — 연내 3회 인상급: 12/9 결정 후 목표범위 상단 4.50% 이상

- **질문**: 2026-12-09 종료되는 FOMC 회의의 결정이 반영된 시점에, 연방기금금리 목표범위 상단이 4.50% 이상일 확률은?
- **마감**: 2026-12-09
- **판정기준**: YES = 2026-12-09 회의 결정 직후 유효한 연방기금금리 목표범위의 **상단 수치가 4.50% 이상**.
  현 상단 3.75% 기준 누적 +75bp 이상(25bp×3 또는 50bp+25bp 등)이 필요하다.
  판정은 성명서의 **수치**로 하며 특정 문구·문장 표현에 의존하지 않는다.
  1차 출처: 연준 통화정책 결정 공표(federalreserve.gov). 2차: FRED `DFEDTARU` 의 2026-12-10 값.
  불일치 시 1차 우선. **12/9 이전의 임시(intermeeting) 결정도 상단에 반영해 판정한다.**
- **중심추정**: 2026-06 SEP 의 2026년말 점 18개 평균 = **3.8333%(중점 기준)**.
  드리프트 보정: 9/16 인상 시장내재 약 54% × 25bp = +0.135%p → **3.968%(중점)**.
- **σ = 0.267%p** — 2026-06 SEP 2026년말 점도표 18개 분포(4.375×1 · 4.125×5 · 3.875×3 · 3.625×8 · 3.375×1)의
  모표준편차. 본 문서에서 직접 산출(mean 3.8333 · pstdev 0.2668 · sstdev 0.2745).
  **σ 출처**: `forecasts/2026/2026-09-09_fomc-sep-2027-below-2026_r1.md` frontmatter `sep_2026_06_dots_2026ye` (검증).
- **z = |4.375 − 3.968| / 0.267 = 1.52** (무보정 중심 3.8333 을 쓰면 z=2.03).
- **민감도**: 점도표 분산은 *위원 간 이견*이지 *결과 불확실성*이 아니므로 σ 를 과소평가할 소지가 있다.
  σ=0.40 으로 늘려도 **z=1.02 로 여전히 채택 밴드**다. 이 강건성이 이 후보의 핵심 근거다.
- **정직 확률 7%** (z=1.52 의 정규 꼬리 6.4% 에 매파 두꺼운 꼬리 여유 +0.6%p).
- **NFP 교훈 반영**: NFP 는 임계를 **컨센서스가 이미 가리키는 쪽**(컨센 +55K < 임계 100K)에 0.47σ 만 떨어뜨려
  정직 확률을 68%(사구간 한복판)로 만들었다 — M1 은 임계를 **컨센서스 반대쪽 꼬리**에 1.5σ 밖으로 뒀다.
- **데블스**: Warsh 체제의 매파 전환 속도가 6월 점도표를 무력화할 수 있다. 7/13 CME 가 46.5% 까지
  갔던 전례처럼 리프라이싱은 수일 만에 일어난다. σ 과소평가가 이 후보의 최대 약점이다.

### M2 — 인하 방향 tail: 2027-01-15 까지 목표범위 상단 3.50% 이하

- **질문**: 2026-09-15 부터 2027-01-15 까지, FOMC 결정으로 연방기금금리 목표범위 상단이 한 번이라도 3.50% 이하가 될 확률은?
- **마감**: 2027-01-15 (계약 상한과 동일)
- **기간 시작일: 2026-09-15 00:00 ET** — 초안 작성일(2026-09-10) 이후로 못박아 이미 일어난 결정이 창에
  들어오지 않게 했다(5원칙 5 백테스트 금지). 창에 들어오는 결정은 2026-09-16 · 10-28 · 12-09 정기회의와
  그 사이의 임시 결정뿐이다.
- **판정기준**: YES = 해당 기간 중 어느 FOMC 결정에서든(정기·임시 불문) 목표범위 **상단 수치가 3.50% 이하**로
  설정되면 YES. 현 상단 3.75% 기준 순인하 25bp 이상이 필요하다. 중간에 인상한 뒤 되돌려 3.50% 이하에
  도달해도 YES. 기간 종료 시점의 값이 아니라 **기간 중 최저 상단**으로 판정한다.
  1차: 연준 결정 공표. 2차: FRED `DFEDTARU` 일별 계열의 기간 내 최솟값.
- **중심추정 / σ**: 이 후보는 **시장내재확률 자체가 중심추정**이다. repo 스냅샷(2026-09-09)이
  "인하 확률은 사실상 0%" 로 기록했다(Kalshi 54.5% / Polymarket 52.5% / CME ~56% 는 전부 **인상** 확률이며 인하 버킷은 ~0).
  계약의 z 밴드가 `z = Φ⁻¹(1−p)` 매핑이므로 **확률에서 z 를 직접 역산**한다.
  **σ 출처**: `forecasts/2026/2026-09-09_fomc-sep-2027-below-2026_r1.md` frontmatter `market_hike_odds` (검증).
  주의: 시장내재확률은 **risk-neutral 측도**이지 실확률이 아니다(CLAUDE.md 하드게이트 병기 의무).
- **z = Φ⁻¹(1 − 0.04) = 1.75**, **정직 확률 4%**.
  회의별 인하확률 ~0 에 ① 4개월 창(3회 회의) 합산 ② 임시 인하(2020-03 류 충격) ③ 시장이 tail 을
  체계적으로 저평가하는 성향을 얹어 0% → 4% 로 올렸다.
- **NFP 교훈 반영**: NFP 는 σ 대비 임계 거리를 재지 않고 "심리적으로 둥근 수"(100K)를 임계로 삼았다 —
  M2 는 임계를 **정책 격자의 한 칸(25bp)** 이라는 기계적 단위로 잡고 z 를 확률에서 역산해 검증했다.
- **데블스**: 이 후보는 7건 중 **정보량이 가장 낮다**(p=4%). "쉬운 NO 를 사서 게이트를 채운다"는 비판이
  성립한다. 다만 인하는 Jin 포트폴리오 EXIT 프레임의 감시 대상이며(충격성 완화 = 침체 확인),
  기존 macro 27건이 전부 인상·동결 방향이라 **방향 커버리지 공백**을 메운다. 등록 우선순위는 낮게 둔다.

### M3 — 12월분 NFP 초판 −75,000 이하 (컨센 −1.5σ)

- **질문**: 2027년 1월 초 발표되는 2026년 12월분 고용상황 보고서에서 비농업 신규고용(NFP) **최초 공표치**가 −75,000 이하일 확률은?
- **마감**: 2027-01-08 (BLS 일정 확정 필요 — 2027-01-01 이 금요일·공휴일이라 통상 다음 금요일)
- **판정기준**: YES = 총 비농업 취업자수의 전월대비 변화 **최초 공표 수치**가 −75,000 이하.
  **개정 고정**: 같은 릴리스에 실리는 10·11월 개정치, 이후 연례 벤치마크 개정은 판정에 반영하지 않는다.
  판정값은 발표 당일 BLS 릴리스에 인쇄된 12월분 수치이며, 판정 시 그 스냅샷을 예측 파일에 기록한다.
  1차: BLS 고용상황 릴리스. 2차: 동일 수치를 보도한 주요 매체 1곳. 불일치 시 1차 우선.
- **중심추정 +70,000** — 최근 3개월 초판 평균 +65.3K (6월 +57K · 7월 −23K · 8월 +162K), SPF Q2-2026 월평균 +34.6K,
  직전 초판 +162K 를 보수적으로 절충. **등록 시 반드시 공표 컨센서스 스냅샷으로 교체**한다.
- **σ = 95,000** — 2026년 7개월 컨센서스 오차의 표준편차. **σ 출처**: `data/base_rates/macro.md`
  "NFP 최초 공표치 100K 미만 — 개정치 기저율과 구분 (2026-08-31 정량화)" 항목
  (검증, 컨센서스는 보도 경유 [부분 미검증]).
- **z = |−75,000 − 70,000| / 95,000 = 1.53**, **정직 확률 7%** (정규 꼬리 6.3% + 두꺼운 꼬리 여유).
- **임계 산출 근거**: 지시대로 "컨센 ± 1.5σ 지점"을 계산하면 70,000 − 1.5×95,000 = **−72,500**.
  −75,000 은 그 지점을 살짝 넘긴 반올림 값이다. **100K 를 쓰면 z=0.32** 로 즉시 거부된다.
- **NFP 교훈 반영 (직계 후속)**: `nfp-aug2026-below100k` 는 컨센 +55K·σ 95K·임계 100K → **z=0.47 → 정직 68% →
  기대 Brier 바닥 0.2176 > 문항 상한 0.21** 이었다. M3 는 **같은 σ 를 그대로 쓰되** 임계를 **3.3배 멀리**
  (z 0.47→1.53) 밀어 바닥을 0.2176 → 0.0651 로 내렸고, 방향도 컨센 반대쪽으로 뒤집었다.
- **데블스 / 남은 위험**: ① 8월 +162K 는 컨센 대비 **+107K(1.13σ)** 상방 서프라이즈였다 — NFP 오차는 정규가 아니라
  두꺼운 꼬리이고 σ 표본이 7개뿐이다. ② `nfp-jul2026` 초판 −23K 가 +21K 로 상향 개정되며 r1 의 전제
  ("사이클 첫 마이너스")가 소멸했다 — **초판 고정은 판정을 지켜주지만 추론의 전제는 지켜주지 않는다.**
  ③ 12월분은 연말 소매·물류 계절조정 잡음이 크다. ④ 이미 `nfp-oct2026-below100k`·`nfp-nov2026-below100k`·

### M4 — 12월분 실업률 3.8% 이하 (하방 tail, 노동시장 재긴축)

- **질문**: 2027년 1월 초 발표되는 2026년 12월분 고용상황 보고서에서 실업률(U-3) **최초 공표치**가 3.8% 이하일 확률은?
- **마감**: 2027-01-08 (BLS 일정 확정 필요)
- **판정기준**: YES = 12월분 U-3 실업률 최초 공표치가 **3.8% 이하**(BLS 공표 소수 첫째 자리 기준).
  3.9% 이상이면 NO. 이후 계절조정 재산정·연례 개정 무관.
  1차: BLS 고용상황 릴리스. 2차: FRED `UNRATE` 의 발표 당일 값.
- **중심추정 4.1%** — 2026-07 4.1%(6월 4.2%에서 하락) · 2026-08 4.1% 유지.
- **σ = 0.20%p (잠정)** · **σ_source: [부분 미확인]**
  - 인용 가능한 것: BLS 고용상황 기술노트의 "실업률 **월간 변화**의 90% 신뢰구간 약 ±0.2%p" → 표본오차 σ₁ ≈ 0.12%p.
  - 인용 불가한 것: **4개월 누적 실제 변화의 표준편차** — repo 에 산출값이 없다. 0.20%p 는 표본오차
    (0.12×√2 ≈ 0.17)에 실질 변화분을 얹은 **파생 추정**이며 1차 출처를 댈 수 없다.
- **z = |3.85 − 4.1| / 0.20 = 1.25 (잠정)** — 인쇄 반올림 경계 3.85% 를 임계로 썼다.
  **민감도: σ=0.25 → z=1.00 (경계) · σ=0.30 → z=0.83 (예외 슬롯 구간)**. 즉 σ 값에 따라 판정이 뒤집힌다.
- **정직 확률 8%**.
- **등록 조건 (차단)**: **FRED `UNRATE` 로 비침체 표본의 4개월 변화 SD 를 직접 산출해 σ 를 확정하기 전에는 등록 불가.**
  검증 불가능한 σ 로 만든 z 는 규율을 형해화한다. σ 확정 결과 z<1.0 이면 예외 슬롯을 쓰거나 폐기한다.
- **NFP 교훈 반영**: NFP 실패의 절반은 "σ 를 알면서도 임계를 σ 로 정당화하지 않은 것"이었다 —
  M4 는 반대로 **σ 를 모른다는 사실을 z 옆에 명시**하고 등록 자체를 σ 확정에 걸어뒀다.
- **데블스**: 3.8% 는 2026년 저점(4.1%)보다 0.3%p 낮아 사이클 후반부에서 드물다. 반대로 U-3 는
  **분자(실업자)와 분모(경활인구)가 함께 움직이는 비율**이라 이민정책·경활참가율 하락으로 고용 부진과
  실업률 하락이 **동시에** 나타날 수 있다 — M3(NFP 급랭)와 M4 가 **함께 YES 가 되는 경로가 실재**한다.
  둘을 "반대 방향이라 안전하다"고 읽으면 안 된다.

## 3. 상관 클러스터 경고 — 7건 전부 등록하면 안 된다

전부 저확률 tail 이라 개별 기대 Brier 는 좋다(평균 0.0709). 그러나 **레짐이 깨지면 한 클러스터가 통째로 YES 로 뒤집힌다.**
정직 확률 7~10% 짜리가 YES 로 해소되면 행 Brier 는 **0.81~0.86** 이다. 3건이 동시에 터지면 게이트가 즉사한다.
이것이 T04 가 기록한 NFP 2연패의 확대판이다.

| 클러스터 | 후보 | 동시 발화 시나리오 |
|---|---|---|
| **과열·매파** | M1(3회 인상) · M4(실업률 3.8%) · M7(GDP 4%+) | 노동시장 재긴축 + 인플레 재점화 |
| **침체·완화** | M2(인하) · M3(NFP −75K) · M6(GDP 수축) | 급랭 → 연준 반전 |
| **디스인플레** | M5(core 2.1%) | 침체 클러스터와 부분 상관(침체 → 디스인플레) |

- 두 클러스터는 **서로 반대**라 하나의 레짐 전환이 양쪽을 동시에 터뜨릴 수는 없다 — 구조 자체는 나쁘지 않다.
- 그러나 **클러스터당 최대 2건**을 넘기면 단일 레짐 전환의 손실이 감당 범위를 벗어난다.
- **M3·M4 는 반대 방향처럼 보이지만 함께 YES 가 될 수 있다**(경활참가율 하락 경로) — 같은 클러스터로 취급할 것.
- 기존 레지스트리에 `nfp-sep2026-negative`·`nfp-oct2026-below100k`·`nfp-nov2026-below100k`·`unemployment-44-nov2026` 등
  **침체 방향 macro 가 이미 4건 이상** 있다. 신규분은 침체 클러스터를 더 늘리지 않는 편이 안전하다.

### 권고 조합 (4건)

**M1 · M7 · M6 · M5** — 과열 2(M1·M7) + 침체 1(M6) + 디스인플레 1(M5).
σ 가 전부 검증 또는 부분검증이고, M6·M7 은 상호배타라 동시 손실이 봉쇄되며, 기존 레지스트리의
침체 편중을 더 키우지 않는다. 기대 Brier 바닥 평균 = **0.0797**.

- **M3 보류 사유**: σ 는 가장 튼튼하지만 침체 클러스터에 NFP 계열이 이미 3건 있다(T04 경고 대상).
- **M2 보류 사유**: p=4% 로 정보량이 가장 낮다. "쉬운 NO 사재기" 비판을 피하려면 후순위.
- **M4 보류 사유**: σ 미확인 — 확정 전 등록 불가.

## 7. 솔직한 한계

1. **σ 3건이 파생·미확인이다.** M4 는 [부분 미확인], M5 는 [부분 미검증](repo 내부값 + √h 파생),
   M6·M7 은 σ 는 검증됐으나 **중심추정이 미확정**이라 z 가 잠정이다. 검증 불가능한 σ 로 만든 z 는
   규율을 형해화하므로, 이 3건은 σ·중심 확정을 등록 조건으로 **명시적으로 차단**해 뒀다.
2. **정직 확률 자체가 추정이다.** z 는 정규 가정에서 확률을 주지만 macro 오차는 두꺼운 꼬리다.
   NFP 8월 서프라이즈가 1.13σ 였다는 사실이 그 증거다. 표의 7~10% 는 정규 꼬리보다 위로 올려 잡은 값이지만
   **여전히 낙관일 수 있다.**
3. **저확률 tail 포트폴리오의 구조적 대가**: 기대 Brier 바닥은 좋지만 정보량이 낮고,
   YES 로 해소되면 행당 0.81~0.86 의 손실이 난다. 이는 게이트를 **"잘 맞히기"가 아니라 "안 터지기" 게임**으로
   바꾸며 한 번의 레짐 전환에 취약하다. §3 의 클러스터 상한을 지키는 것이 이 초안의 전제다.
4. **이 문서는 등록이 아니다.** `questions/registry.yaml`·`forecasts/`·`calibration/` 무수정을 확인했다.
