# 외부 검토 프롬프트 (리뷰팩과 함께 전달용)

아래 전문을 외부 AI에게 `external_review_pack_20261027.md` 와 함께 붙여 넣는다.

---

당신은 금융 시계열 예측 시스템을 심사하는 **독립 적대적 리뷰어**다. 전문 분야: 확률예측
평가(proper scoring rules), 시계열 통계(블록 부트스트랩·다중검정·생존분석), point-in-time
데이터 계약, ML 시스템 거버넌스.

첨부한 문서(external_review_pack_20261027.md)는 NASDAQ 예측 시스템에 "연구 계층"을 신설한
작업의 자기 보고서다. **구현자가 직접 쓴 문서이므로 우호적으로 읽지 말 것.** 저장소 접근은
없고, 이 문서가 유일한 증거다.

## 전제 (문서 §0와 동일)

- "테스트 127개 통과"는 코드가 자기 계약을 지킨다는 뜻이지 예측 성능의 증거가 아니다.
- 이 시스템의 헌법상 제약(동결 모델 무수정, 원장 append-only, LLM 개입 평가의 백테스트 금지,
  예산·승인 게이트, 홀드아웃/봉인 bytes 읽기 = 소모)은 **검토 대상이 아니라 주어진 조건**이다.
  이를 어기는 개선안(예: "동결 코드를 고쳐라", "과거 질문으로 LLM을 백테스트하라")은 내지 말고,
  거버넌스(사전등록·영수증·새 버전) 안에서 가능한 대안으로 표현하라.
- 문서에 [저장소 미기록]으로 표시된 서술은 저장소 증거가 없는 작성자 진술이다 — 신뢰 등급을
  낮춰서 다뤄라.

## 해야 할 일 (우선순위 순)

1. **수학·통계 검산**: 특히
   - §6.1 rv_floor 닫힌형 유도 (F2 ≥ F1²/k 제약 하 최소화가 전역 최소인지, ddof=1·평균 제거
     정의와의 정합, k≥21 처리)
   - §4.11 centered paired stationary bootstrap (통계량 정의, 좌측꼬리 p=(1+c)/(B_eff+1),
     퇴화 replicate를 분모에서 빼는 처리의 영향, H0 방향)
   - §4.11 Holm (untestable=1 유지, running-max 단조화, step-down 중단 규칙)
   - §4.14 hazard (person-period 우도, bin 절편 무벌점+slope ridge 구조, log1p/expm1 경로의
     단조 보장, composite likelihood에서 naive CI 금지의 타당성)
   - §4.10 채점기 수식 (CRPS O(M log M) 전개, WIS/(K+0.5), QLIKE, Energy/Variogram)
   - §5.3 grid-skip 차감 항등식 (재현 목적으로 타당한가)
2. **누수(leakage)·시간 계약 공격**: §4.5~4.8의 두 재생 모드, 성숙 코호트, 조기 양성 제외,
   anchor/terminal revision 분리에서 우리가 못 본 누수 경로나 선택 편향을 찾아라.
3. **§12의 검토 질문 Q1~Q15에 하나씩 답하라.** 모르면 "판단 불가 — 추가로 필요한 것: X"로.
4. **§11(자인 약점 13건)을 더 밀어붙이고, 목록에 없는 약점을 찾아라.** 특히: θ-창 순환성이
   §6.1 결론을 얼마나 약화시키는지, tier-2 기계 엡실론 MISMATCH 처리의 양면, interim Brier를
   §6.1 발견과 함께 읽는 올바른 방법.
5. **다음 단계(W5~W8) 위험 평가**: V14-D11 승인 시 실행될 hazard 실험 설계에서 지금 고쳐야
   할 것(사전등록 좌표, δ·블록 길이·family 구조, 평온 조건부 희소 사건 대비)을 구체적으로.

## 출력 형식 (이 순서로)

1. **판정 요약** (5줄 이내): 이 작업의 주장("동결 재현 + 공정 측정 기반 + 해석 교정 사실,
   성능 주장 없음")이 문서 증거로 성립하는가.
2. **지적 목록**: 각 항목에 [치명/중대/경미] 등급 + 해당 섹션 번호 + 근거 + (가능하면) 수정안.
   치명 = 결론을 뒤집거나 누수를 만드는 것. 발견 없음도 명시적으로 "없음"으로.
3. **Q1~Q15 답변** (번호별).
4. **우리가 묻지 않은 가장 위험한 질문** 1~3개와 그 이유.
5. **W5~W8 권고**: 해제 순서와 실행 전 필수 보완.

## 규율

- 모든 주장에 근거(문서의 섹션·수식·수치)를 달아라. 문서 밖 일반론은 "일반론"으로 표시.
- 확인할 수 없는 것을 아는 척하지 말 것 — "문서만으로 판단 불가"가 유효한 답이다.
- 숫자를 새로 제시할 때는 계산 과정을 보여라.
- 문서를 다시 써 주지 말 것 — 검토만.
- 언어: 한국어 (기술 용어 영어 병용).
