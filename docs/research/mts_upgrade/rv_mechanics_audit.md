## 해석 (주장의 경계 — §4.5-5; 2026-10-27 외부 리뷰 F01·Q4·DQ2 정정 반영)

- **감사 가설 확인**: 설계창 RV 양성의 상당수(h5 85%, h21 70%, h63 55%)는 원점에 이미
  알려진 창 구성만으로 **하한이 θ 를 넘는** 기계적 확정이다 — 그 양성 라벨들은 미래
  수익과 무관하게 원점에서 확정돼 있었다.
- **귀속 주장 철회 (F01)**: "V13 BSS 의 큰 몫이 지속성+창 역학" 류 귀속은 측정(양성 중
  확정 비율)보다 강한 추론이라 철회한다 — 사건의 구성과 모델의 성적 기여는 다른 양이다.
  확정 비율만으로는 PB Brier 개선의 어느 몫이 기계적 원점에서 왔는지 말할 수 없다.
  후속(사전등록 후): per-origin 기계적 플래그를 V13 해소 원장과 조인한 Brier 분해
  (ΔBS = P(M)·E[ΔL|M] + P(¬M)·E[ΔL|¬M]).
- **구조 정리 (Q4)**: rv_floor 는 k 에 **비증가**(알려진 집합 축소의 SSE 단조성)라
  `argmax_k ≡ 1` — 세 지평의 확정 수가 전부 47 로 같은 것은 표본의 우연이 아니라 정의의
  구조적 귀결이다. 따름정리: rv_floor(1) ≤ RV21(원점) 이므로 **V14 평온 자격(RV21≤θ)은
  이 종류의 기계적 양성을 구조적으로 배제**한다 (평온 48원점 중 기계적 확정 0 실측).
- **읽기 범위 공시 (DQ2)**: 마지막 원점들(2014-10-06·11-04·12-04)의 h63(및 12-04 의 h21)
  라벨은 2015-01-02~**2015-03-09** 종가를 소비한다 — 원점·확률·채점은 전부 설계창이고
  계약 정의상 홀드아웃 평가 소모가 아니나, 원 노출 영수증의 window 끝(2014-12-31)은 과소
  신고였다. 정정 행 `rv-mechanics-20261026-correction-r2` 를 exposures.jsonl 에 append.
- window-mechanics baseline(등록 생성기 2종 + 실제 추정식 + 기간내 max)은 PB 와 별개의
  **역학 기준선** 재료다. PB 대비 증분 주장은 하지 않는다(사전등록된 비교 아님).
- 기대값 변종은 `not_a_probability` 로만 산출·등록 거부(T21).
- 이 진단은 base rate 참조이지 캘리브레이션 표본이 아니다 (CLAUDE.md 5-5).
- `forward_realized_variance`(알려진 성분 제거 표적)는 **별도 연구 표적** 후보로만 기록 —
  현행 RV21 사건 정의는 불변.
