calibration-in-the-large·기준선별 BSS 를 함께 보고한다.

## 3. 판정 규칙(결과 전 고정)

- effective_from: 머지 뒤 main 예약 CI 의 첫 실행이 `arming.jsonl` 에 쓴 날짜(UTC)보다 엄격히 뒤의 첫 XNAS 세션. 사람이 고르는 날짜 0.
- 셀별 첫 적격 접두 1회: n ≥ 60 ∧ floor(n/ℓ_h) ≥ 5 ∧ 사건·비사건 ≥ 20 ∧ 국면 ≥ 5/5, 접두 안 pending 없음,
  접두 끝 ≤ V13 최신 as_of − 20 XNAS 세션. ℓ_h = max(13, h). 늦게 파생된 V15 행(derived_at ≥ 원점 + 20 XNAS 세션)은
  접두에서 제외한다(V13 백필이 확정된 접두를 소급으로 바꾸는 경로 차단).
- 쌍대 d = BS_PB − BS_arm, 정지 블록 부트스트랩 B=5000(셀당 같은 인덱스), 단측 p, 고정 가족 20쌍 Holm(α 0.05).
- 음성 대조 = 블록 부호반전 귀무 120회(내부 B=300) — 통과율 > 0.10 이면 void. 설계창에서 중앙 ≈ 0.10 이라 void 가 드물지 않을 것이다.
  통과율은 d 의 부호와 무관하고 |d| 의 블록 지속에만 의존한다 — 블록 안에서 거의 일정한 강한 우세는 void(실측 0.16~0.22)라,
  run 이 긴 변동성 라벨·ℓ 이 긴 h21·h63 셀에서는 pass 가 구조적으로 거의 나오지 않는다(결과 전 공시).
  블록 안에서 d 가 거의 일정한 강한 우세는 이 대조에서 void 가 된다(테스트로 고정) — 보수적 실패다.
- pass = Holm 기각 ∧ CI90 하한 > 0 ∧ 귀무 ≤ 0.10 ∧ 최유리 블록 제외 d̄ > 0 ∧ 로그점수 비열화. 가족 완결 전 비기각은 잠정.
- verdict verb 는 사람이 돌리는 인쇄 전용이며 워크플로에 없다. 판정·채점 코드 5파일은 LF 정규화 sha256 로 핀된다.
