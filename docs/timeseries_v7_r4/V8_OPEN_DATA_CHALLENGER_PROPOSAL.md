# V8 open-data challenger proposal

Status: **PROPOSED_NOT_APPROVED**

This proposal isolates nine official open-data families in a research-only
challenger lane. It does not alter the frozen V7 feature set, research
coordinates, probability output, or official Gate eligibility.

Every source starts with exact weight `0.0`. A later, separately reviewed V8
contract must preregister its feature definition, point-in-time `available_at`
rule, revision treatment, license and terms receipts, validation windows, and
promotion threshold before any non-zero weight or official Gate eligibility is
possible. Filing acceptance time is the availability boundary for SEC data;
release/publication timestamps are the boundary for statistical sources.

No approval is granted by this document.
