# 변동성 데이터 오픈소스 재검토

## 결론

FRED API 키는 인증 수단이며 데이터 이용권을 확장하지 않는다. 현재 FRED Services 약관은 API를 포함해 콘텐츠를 ML에 사용하거나 저장·캐시·아카이브·DB 편입하는 행위를 금지하므로 V8R 학습 수집에는 사용할 수 없다.

Cboe는 VIX9D·VVIX 등 역사 CSV를 공개하지만, 공개 다운로드가 오픈 라이선스를 뜻하지는 않는다. Cboe 웹사이트 약관은 개인 비상업 목적의 1부 다운로드 외 저장·파생 사용에 사전 서면 동의를 요구한다.

## 확인한 공개 후보

- `datasets/finance-vix`: PDDL을 선언하지만 VIX 하나만 포함한다. README도 원자료의 public-domain 여부를 권리자의 허가가 아닌 작성자의 추정으로 설명한다.
- `vix_utils`: MIT 라이선스는 프로그램 코드에만 적용된다. 프로그램이 가져오는 Cboe 데이터 권리를 재허가하지 않는다.
- 공개 변동성 연구 저장소와 Yahoo 기반 도구: 구현 참고에는 쓸 수 있지만 원천 데이터의 오픈 라이선스 증거가 되지 않는다.

따라서 VIX9D·VVIX·SKEW·VIX 선물 전체를 PIT 학습 DB에 적재할 수 있는 권위 있는 오픈 라이선스 원천은 확인되지 않았다. 이 상태에서 제3자 복사본을 사용하면 V8R 불변 계약 9의 `license → PIT contract → receipt` 순서를 위반한다.

법적으로 안전한 기술 대안은 기존 R5 수익률에서 계산하는 단기/장기 실현변동성 비율, 변동성의 변동성, 하방 반분산, 점프 변동과 CFTC 포지셔닝을 별도 라운드에 사전등록하는 것이다. 이들은 Cboe 내재변동성 지표와 동일하다고 표시해서는 안 되며, 현재 8개 후보와 섞기 전에 새 후보 라운드 승인과 상관·MDE 예산 검사가 필요하다.
