# V8R 실행 보고

사용자의 DV-1, DV-2, DV-3 승인을 append-only 결정 기록에 남겼다. 승인된 8개 후보도 평가 전에 등록했으며, R5 조건부 스케일·FHS 선행 모듈이 존재함을 확인했다.

## 실행 결과

- `V8R-D3`은 CFTC 공식 Public Reporting API로 완료했다. NQ·ES·VIX 선물의 leveraged-money 순포지션을 미결제약정 대비 fraction으로 저장했다.
- 2006-06-13부터 2026-08-18까지 3,121개 ObservationFact를 적재했다. 중복 fact/관측 0, PIT 지연 위반 0, 원문·영수증 계보 위반 0이다.
- 휴일 주간의 월요일·수요일 기준일을 화요일로 바꾸지 않았다. 원 기준일을 보존하고 같은 주 금요일 15:30 ET를 `available_at`으로 적용했다.
- 증분 커서는 마지막 보고일 2026-08-18과 14일 correction window를 보존한다. 증분 재실행은 9개 원천 행을 확인하고 새 fact 0개를 추가했다.

## 정지 사유

- `V8R-D1`: 현재 FRED API 약관은 API를 ML에 쓰거나 콘텐츠를 저장·캐시·아카이브하는 사용을 금지한다. 수집 0건으로 차단했다.
- `V8R-D2`: Cboe 일반 약관과 공개 역사자료 페이지에서 이 저장소의 보존·파생 모델 사용을 허용하는 데이터셋별 권리를 확인하지 못했다. 수집 0건으로 차단했다.
- `V8R-F1`은 D2, `V8R-X1`은 F1, `V8R-E1`은 X1 의존성 때문에 시작하지 않았다. outer 평가 사용 행은 0이며 R5 Gate와 E0는 변경하지 않았다.

사용자 승인은 작업 착수를 허가하지만 제3자 권리까지 대체하지 않는다. D1/D2를 해제하려면 해당 용도를 포괄하는 서면 라이선스 또는 별도 라이선스가 있는 대체 원천이 필요하다.
