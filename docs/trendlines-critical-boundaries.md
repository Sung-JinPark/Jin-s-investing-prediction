# 핵심 지지·저항 읽기 모델

기존 원본, 확정 피벗, 빗각선의 방정식·ID와 이벤트 이력은 그대로 보존한다. `trendlines_critical_v1.yaml`은 화면에 표시할 경계를 선정하는 별도 정책이다. 이 정책은 반등 확률이나 공식 예측을 생성하지 않는다.

## 선정 기준

- 최신 확정 종가를 기준으로 4 ATR 및 20% 이내, 최근 63세션 안에 접촉한 경계만 표시한다.
- 독립된 확정 접촉 3회 이상을 요구하며, 확인 구간이 겹치는 피벗을 중복 접촉으로 세지 않는다.
- 전체 검증 후보를 평가한다. 기존 전송 자료에 선택된 몇 개 선만 필터링하지 않는다.
- 같은 종류의 확정 피벗으로 수평 가격대를 구성하고 중앙값을 기준값으로 사용한다.
- 허용폭 밖 확정 종가 2개 연속과 결측 세션을 검수한다. 가격이 선을 넘었다는 이유로 역할을 자동 전환하지 않는다.
- 거리, 최근 접촉, 독립 접촉 수, 접촉 오차, 고정 ID 순으로 선택하며, 0.5 ATR 안에 겹치는 경계는 하나로 줄인다.
- 각 차트에는 지지와 저항을 최대 하나씩 표시한다. 적합한 경계가 없으면 일봉만 표시한다.

ATR14는 기존 계약의 **14개 True Range 단순평균**이다. [Fidelity ATR](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)은 변동성 단위로서의 ATR을 설명하는 참고 자료이며, 그 페이지의 평활 공식을 여기서 도입하지 않는다. 역할 검수의 배경은 [Fidelity 지지·저항](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/support-and-resistance)을 참고한다. 수치 임계값은 사용자 표시 정책이다.

## 전송과 실패 처리

`GET /api/private-trendlines/<asset-id>/critical`은 미리 계산한 불변 snapshot만 읽는다. 요청으로 수집이나 계산을 시작하지 않는다. 현재 및 전체 원본 snapshot, 기준 종가·세션, 정책 버전, JSON 실바이트 해시를 대조한다. 실패하면 기존 다수 선으로 되돌아가지 않고 검증된 일봉을 표시한다.

개인 연구 원천의 기존 승인 상태는 유지한다. 이 경로는 공개 OHLC 정본이나 공식 예측 원장으로 승격되지 않으며, 개인 원본·가격은 Pages 산출물에 포함하지 않는다. 미확보 Magnificent Seven 공식 지수는 미산출 상태를 유지한다.

## 화면과 운영

선 가격은 마우스가 가리키는 거래 세션을 원래 선형·로그 방정식에 대입해 표시한다. 실제 종가와 선 가격·차이를 구분하고, 수평 가격대는 기준값과 범위를 표시한다. 미래에는 거래소 달력으로 검증한 날짜와 추세선 연장값만 제공한다.

전체 차트 기본 범위는 선정 경계의 첫 기준점 앞 10개 봉부터이며, 경계가 없으면 최근 252개 봉이다. 전체 확보 기간을 별도로 복원할 수 있다. 확대는 같은 선정 결과를 다시 렌더링하고 계산과 선택을 바꾸지 않는다.

기존 07:17·09:17·16:17 KST 갱신에서 원본 및 전체 후보 검증 뒤 핵심 모델을 계산한다. 자산별 오류는 격리한다. 롤백은 코드와 선택 포인터만 복원하며 원본·정정·이벤트·불변 snapshot은 삭제하지 않는다.
