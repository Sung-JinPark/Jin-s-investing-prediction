# 대표 추세선과 장기 고점·저점 연결선

기본 화면은 200일 가격 회귀선, 현재 상승·하락 구조선, 장기 주요 고저점 구조선을 함께 보여준다. 충분한 확정 일봉이 있는 자산에 세 종류를 제공한다. 각 선은 종류별로 선택할 수 있으며 확대와 표시 범위 변경은 계산 입력이나 선정 결과를 바꾸지 않는다.

여기에 별도 `long_boundaries_v1` 읽기 모델의 장기 고점 연결선·저점 연결선을 추가한다. 화면은 SK하이닉스, SOXX, 나스닥 종합, S&P 500, BTC/USD, 다우 6개 자산만 제공한다. 빅테크7의 원천 계약과 7행 상태 검증은 보존하며, 기존 빅테크7 화면 URL은 하이닉스로 이동한다.

## 장기 상·하단 보충 모델

최근 756세션에 속한 전체 확정 10·10 피벗에서 고점끼리, 저점끼리 독립적으로 연결한다. 두 앵커는 최소 60세션 떨어져야 하며 둘째 앵커는 최근 252세션 이내여야 한다. 현재 확정 종가의 위쪽 고점선·아래쪽 저점선만 후보가 되고, 가격 거리는 8 ATR과 종가의 50%를 모두 충족해야 한다. 현재와 미래 연장값은 양수여야 한다. 선형·로그축을 각각 선정한다.

형성과 현재 역할이 온전한 후보는 독립 접촉 수, 최근 접촉, 현재 거리, 앵커 간격, 고정 ID 순으로 선택한다. 없으면 형성자료 완전성, 관측된 최대 관통/허용폭, 최근 둘째 앵커, 현재 거리, ID 순으로 구조 참고선을 고른다. 형성구간 결측·ATR 부재·관통·이탈을 기록하고 참고선은 옅은 색으로 표시한다. 2점 연결과 3회 이상 독립 접촉을 구분하며, 원래 지지·저항 역할을 자동으로 뒤집지 않는다. 적격 후보가 없으면 추가선만 미산출하고 회귀나 평행 이동으로 채우지 않는다.

`GET /api/private-trendlines/<asset-id>/long-boundaries`는 별도 불변 snapshot을 읽는다. 원본·전체 일봉·기존 3선 snapshot과 payload 해시를 고정하며, 기존 `/representative` 계약은 정확히 3종 그대로다. 보충 자료는 `data/trendlines_research_long_boundaries/`에 추가된다. 갱신은 기존 3선 다음에 실행하고, 실패는 추가 2선에 격리한다. 미래 날짜는 기존 거래소 달력의 21거래일 또는 BTC 30일을 재사용한다.

기본 화면은 최대 5종을 표시한다. 현재 선택한 목록 안에서만 같은 축·같은 종류의 동일 앵커·가격·방정식·표시 구간을 병합한다. 원래 선과 ID는 변경하지 않고 범례에 별칭을 함께 보여준다. ‘상·하단’ 필터는 보충 2선을 독립적으로 표시한다. 장기 기준점 보기는 선택한 선 중 가장 이른 실제 앵커의 10봉 전부터 시작한다. 기존 3개 인사이트 아래에 보충 2행 가격·앵커·상태를 제공한다.

브라우저는 원본에 연결된 compact OHLC의 고저점·접촉·ATR·상태·식과 가격을 독립 대조한다. compact 일봉에는 영수증 시각이 없으므로 원본 시각의 완전 검수는 배치 replay에서 수행하고, 브라우저는 전달된 피벗 확인 시각이 기준 snapshot 이후가 아닌지 검사한다. 정책·원본·3선 snapshot 불일치나 보충 API 오류 시 추가선만 숨긴다.

이 화면의 대표선은 방향과 가격 구조를 설명한다. 기존 `critical_v1`의 독립 접촉 3회 이상인 검수된 지지·저항 경계와 다른 읽기 모델이며, 해당 정책·snapshot·이벤트 이력은 보존한다. 회귀선과 두 점 연결선은 검증된 지지·저항이나 반등 확률로 표시하지 않는다.

## 계산

- **200일 가격 추세:** 최근 200개 확정 관측 봉의 종가를 사용한다. X는 원래 거래 세션 번호이며 결측을 압축하지 않는다. 실제 관측 수·시작과 끝·누락 세션 수를 기록한다.
- **현재 추세:** 최근 63봉 방향과 맞는 확정 3·3 피벗 두 점을 연결한다. 앵커 간 최소 10세션, 확인 구간의 독립성, 형성 중 침범과 현재 역할을 확인한다. 적합하지 않으면 최근 63봉의 회귀선으로 표시하며 그 방법을 명시한다.
- **장기 주요 고저점:** 확정 10·10 피벗 중 중요한 같은 종류의 고점 또는 저점을 연결한다. 최근 756세션의 지배적 확정 고점·저점을 포함한 통과 후보를 먼저 선택하고, 최근 기준점과 변동성 대비 돌출 정도로 순서를 정한다. 앵커 간 최소 60세션과 최근 기준점의 시의성을 요구한다. 현재가에서 지나치게 멀거나 0에 가까운 선을 제외한다. 적합하지 않으면 252봉 회귀선으로 표시한다.

각 축에서 회귀는 중심화한 X와 Y를 이용한다. 선형 축은 Y=종가, 로그 축은 Y=ln(종가)다. 기울기는 `Σ((x−x̄)(y−ȳ))/Σ((x−x̄)²)`, 절편은 `ȳ−기울기×x̄`다. 마지막 종가를 통과시키기 위해 절편을 이동하지 않는다. 로그 회귀선은 지수 변환한 기하 추세 수준이며 산술 기대가격으로 해석하지 않는다. R²와 RMSE의 계산 공간도 명시한다.

[NIST의 최소제곱 설명](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd431.htm)과 [Python 표준 회귀 함수](https://docs.python.org/3.12/library/statistics.html#statistics.linear_regression)를 수식 검수의 참고 자료로 사용한다.

## 전달과 화면

`GET /api/private-trendlines/<asset-id>/representative`는 배치에서 계산한 불변 snapshot만 읽는다. 현재 OHLC와 전체 기간 snapshot, 확정 기준 종가·세션, 정책 및 JSON 실바이트 해시를 대조한다. HTTP 조회는 수집이나 계산을 시작하지 않는다. 새 정책과 자료는 기존 원본·검수 경계 이력과 별도 경로에 추가한다.

갱신 작업은 기존의 용량 제한이 있는 메모리 검수 캐시를 사용할 수 있다. 이미 통과한 같은 입력·정책·계산 함수의 과거 산술만 재사용하며, 매번 원본·영수증·snapshot·export의 실바이트 해시와 연결을 검사한다. 조회는 원천 OHLC 배열과 계산 당시 달력 좌표의 입력 해시를 대조한다. 배치와 명시적 재검수는 전체 달력과 원문을 다시 검수하며, 캐시 없는 재검수는 전체 산술도 다시 수행한다.

기본 차트의 세 종류와 아래 가격·기간 설명은 같은 목록을 사용한다. 회귀선은 계산 구간 이전으로 무한 역연장하지 않는다. 장기 기준점 보기와 전체 확보 기간 보기를 구분하고, 숨긴 선이나 먼 미래 값으로 Y축을 늘리지 않는다. 원래 방정식으로 해당 세션의 선 가격을 계산해 실제 종가 및 차이와 함께 호버에 표시한다. 미래 부분은 주식·지수 21거래일, BTC 30일의 추세선 연장값이며 미래 OHLC를 만들지 않는다.

기존 07:17·09:17·16:17 KST 개인 갱신에 대표선 생성을 추가한다. 공개 원천 승인 상태와 공식 예측·확률·원장은 변경하지 않는다. 원천이 없는 빅테크7을 다른 ETF로 대체하지 않으며, 결측 종가를 별도 현재가로 채우지 않는다. 검증 실패 시 해당 대표선을 미산출로 표시하고 다른 방법을 몰래 도입하지 않는다.

## 검수와 롤백

같은 입력의 기존 검수 경계와 새 대표선을 섀도 비교한다. 독립 회귀 재산술, 확정 피벗 확인 시점, 앵커 식, 결측 세션 간격, 방향과 상태, 선형·로그 가격, 동일 의미 재실행을 검수한다. 화면에서는 세 종류의 선 가격·SVG 끝점·호버·표 일치와 확대 후 선택을 확인한다.

롤백은 코드와 대표선 선택 포인터를 이전 검수 snapshot으로 되돌린다. 기존·신규의 불변 원본, 정정, snapshot과 이벤트 이력은 삭제하거나 덮어쓰지 않는다.
