# [초안 A] 다변량 시계열 게이트 성공 전략 설계 — V9 이후의 길

> 지위: **초안**. 받은 Claude가 이 초안을 그대로 따를 필요 없음 — 저장소·원장 실측 후
> 더 고도화되고 정밀한 설계로 대체 가능. 단, §1의 헌법 제약은 어떤 전략에서도 불변이다.
> 작성: 2026-09-02. 근거 원장·보고서는 동봉 ZIP evidence/ 참조.

## 1. 불변 헌법 (전략 자유도의 경계 — 완화 금지)

- 게이트 판정식·임계는 V8 원문 승계 고정: design proxy(장기 CRPS 개선 ≥ +2.5%,
  paired se ≤ 0.001, full-투영 CI90 상단 ≤ −0.0004, coverage 밴드, GFC ≥ 0.72),
  홀드아웃(≥ +2%, CI90 상단 ≤ 0), 봉인 1회·retune 금지.
- 예산: design 24회(현재 소진 기록 동봉), 홀드아웃 finalist 3. 그리드 밖 조합 0.
- 정지점 2개: 홀드아웃 소모 = 명시 사용자 승인, 봉인 = 사인오프 후 별도 세션.
- PIT: 모든 피처 available_at ≤ origin, first-release 불변 객체, E0 내포(비트 동일).
- 챔피언 자격: 신규 피처 ≥ 1 (E0 항등은 기준선일 뿐) + **E0 대비 쌍대 개선**이
  실질 기준(절대 proxy만 통과하는 무효익 후보를 홀드아웃에 올리지 않는다).
- V8 봉인 0바이트·라이브 표면 무접촉. 실패의 정직한 기록(HOLD)도 성공이다.

## 3. 전략 지형 — 세 갈래와 각각의 트리거

### 갈래 1: 단독 피처가 E0 대비 쌍대 개선을 보인 경우
1. 개선 피처들만의 조합 그리드를 **별도 사전등록 개정**으로 추가 (다중성 통제:
   조합 수 최소화, 사전 서열 명시).
2. 조합 챔피언 확정 → G3 정지 → 사용자 승인 시 홀드아웃 1회 → PASS 시 SEALED-READY.
3. 봉인 PASS 후 표면 배선은 P1 패턴(#116/#122) 재사용 — 비봉인 display 모듈,
   fail-closed, V8 카드와의 관계(교체 vs 병렬)는 promotion 계약 절차로만.

### 갈래 2: 전부 무효익(M2SL과 동일 패턴)인 경우
정직한 결론은 "주간 거시·신용 수준 변화의 first-print는 일간 NASDAQ 분포에 추가 정보가
없다"이다. 다음 후보 채널의 우선순위(모두 사전등록 후):
- **변동성 기간구조·옵션 표면**: VXNCLS는 vintage 온셋(2014)이 부족 — 대신 CBOE 원천
  일간 히스토리(VIX 계열은 이미 V2 아카이브 관행)로 VXN을 reconstructed 등급 수집하는
  트랙 검토. 시장가격 계열은 revision이 없어 T+1 available_at 재구축이 정당(V2 선례).
- **일간 신용 스프레드**: BAMLH0A0HYM2의 ALFRED 백필(현 스토어 2023+뿐 — vintage
  깊이 실측 필요) 또는 T+1 재구축 검토.
- **부분-온셋 피처 아키텍처**: NFCI(2011+)·WALCL(2013+)을 쓰려면 완전 패널 요구를
  피처 가용성 마스크로 확장해야 한다 — V8 엔진 수정 불가이므로 **V9 래퍼 레벨**에서
  설계창을 2011+ 서브윈도로 나누는 이중 평가 설계(사전등록 필요, 통계력 저하 명시).
- 아무것도 안 나오면: V9 트랙 동결, shadow 데이터 축적 + V8 유지가 정답.

### 갈래 3: 일부 개선이나 proxy 미달(방향성 신호만)인 경우
- 효과 크기와 MDE를 공표하고, 표본 확장(설계창 밖 홀드아웃을 태우지 말 것) 대신
  **피처 정제 그리드**(변환·표준화 창)를 소규모 사전등록 — 예산 잔여와 교환 판단.

## 4. 예산·일정 규율

- design 예산 잔여 19/24 — 조합 실험은 개선 증거가 있는 경우에만 (현재 근거 0).
- 홀드아웃 3회는 "확신 후보"에만. 무효익·경계 후보에 소모 금지.
- 봉인은 조합 챔피언 + 홀드아웃 PASS + 사용자 사인오프의 3중 조건 후에만.
- 주간 운영(자동): V8 shadow 적립·신선도 게이트는 이 전략과 독립으로 계속.

## 5. 받은 Claude에게 — 이 초안을 넘어설 지점

- E2~E4 원장(동봉)의 지평별·국면별 분해에서 초안이 못 본 패턴을 찾아라
