## D1 — 트랙 미개시 유지

트랙을 열지 않는다(`track_open: false` 그대로). 근거: T5 음성대조가 실패한 검정 기계에서 얻는 통과는
증거로 쓸 수 없고, 같은 표본에서 다섯 번째 맵을 만드는 것은 등록부 위반이다. 여는 유일한 길은
재개 프로토콜(다른 데이터 + 기계 수리 + 새 사전등록)이며 그 전에는 예산 배정 0. **미루는 비용 0**
— 홀드아웃 미소모·봉인 무변경 상태가 유지된다. 되돌릴 수 있는 결정이다.

## D2 — 게이트 임계 승인·적용 (유일한 계약 변경)

**지금이 후보 0 이라 사후 완화 없이 임계를 고정할 마지막 시점**이라는 판정에 따라 승인·적용했다.
P1~P5 전부 강화·구체화·신설이며 완화 0. `gates.armed=false`·`evaluated_candidates=0`·게이트 산술 수치
무변경. gap 주체는 **R2(표적 구조)** 승인, R1(주체=V8)은 known_limits 에 대안으로 보존.

계약 `data/contracts/multivariate_timeseries_v12.draft.yaml` 에 반영(YAML 파싱 검증 완료):
- **P1** G4 판정 다리 = 상위분위 gap 단독, reliability → G5 보고 의무.
- **P2** G1 구속 기후 = in-sample, expanding 병기, 표본-다른-BSS-비율 비교 금지 신설.
- **P3** 개시 시 S3 소모분 4 계상 → 잔여 20 (`evaluations_spent_on_open`).
- **P4** 재개 문턱에 셀별 귀무 통과율 ≤ 0.05 신설(pooled ≤ 0.10 병행).
- **P5** 배포 사다리 T0~T4 + 이름충돌 규칙 X1 을 `deployment_boundary` 로 등재.

`amendments_applied.V12-D2` 에 승인일·근거·변경 목록 기록. draft·로컬·후보 0 이라 되돌릴 수 있다.

## D3 — 파생층 미표시 유지

표시하지 않는다(T0, 미배선). 실질 위험은 정확도가 아니라 **이름 충돌** — 표시 계통에 이미 '−10% 접촉'
계열 확률이 16 곳 있고, V12 파생층은 산출 모델·지평 규약·보정 상태가 전부 다르다. X1 규칙(구분 불가 시
표시 금지)이 계약에 등재됐다. T2 이상 승격은 별도 사용자 결정. 표시는 되돌리기 어려우므로 안 한다.

## D4 — CBOE 허가 발송: 초안 준비, 미발송 (사용자 실행 사항)

**이 세션은 발송하지 않는다.** 외부 발송은 되돌릴 수 없고 소유자 직접 발송 사항이며, 자율 세션이
사용자를 대신해 외부 조직에 보낼 항목이 아니다. 초안 `docs/cboe_permission_request_draft.md` 준비 완료.
발송 여부·시점은 사용자가 정한다. reopen_protocol 의 유일 경로이므로 리드타임 관점에서 D1 을 (a) 로
두더라도 D4 를 별도로 진행하는 것은 모순이 아니다. '일중 합법 소스 전수조사'는 별도 태스크로 남긴다
(요청 시 착수).

## D5 — V10 조합격자 미재개 + D7 스킵 사유 정정

격자를 다시 돌리지 않는다(격자 재실행은 V12 루프의 금지 verb, 홀드아웃 슬롯 3/3 보존). 다만 **정정을
기록**한다:

- **V10-D7 의 조합격자 스킵 사유("W3 외 축이 모두 0 또는 음")는 사실과 달랐다.** 적격 축에
  `W1_sens_rv_kappa_10`(+0.477%)와 `W4a_isotonic`(+0.033%, CI90 하한 > 0)이 포함되고, 조합격자는 실제로
  미표집 영역이다. 최상 조합 상대개선 +1.147% 로 챔피언(+0.64%)보다 크다.
- 그럼에도 **채택 가능성은 낮다**: 적격 12 조합 전부 상위 5% 원점 제거 후 CI90 하한이 음이고, 최상값도
  홀드아웃 게이트(+2%)에 미달하며, 33 셀 다중비교 보정이 없다. V10 동결 판정은 유지된다.
- 이 정정은 계약 `decisions_resolved.V12-D5` 와 최종 보고서 §7-5 에도 기록돼 있다. 격자를 도는 것과
  이 사실을 남기는 것은 별개이며, 후자만 한다.

## push·배포 없음 (성공 조건 미충족)

V12 는 부정 결과다 — 채택 후보 0, 게이트 무장 0. 사용자 조건 "성공했을 때만 push 및 배포"에 따라
`claude/v12-sunday` 는 원격에 푸시하지 않고 로컬에 유지한다. PR 초안 `outputs/timeseries_v12/loop/PR_BODY.md`
는 준비돼 있으나 열지 않는다. (V9·V10·V11 동결 브랜치도 같은 근거로 기록용 외 미배포.)
