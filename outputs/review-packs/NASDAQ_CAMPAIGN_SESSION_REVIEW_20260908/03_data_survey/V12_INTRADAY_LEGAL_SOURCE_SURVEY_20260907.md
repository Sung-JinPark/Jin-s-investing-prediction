# V12 일중·옵션표면 합법 데이터 소스 전수조사 (2026-09-07, DECISIONS 12-8 형식)

> 목적: 재개(다른 데이터) 경로의 전제 — 설계도 §0 "합법 일중 소스 부재"가 실제로 맞는지 검증.
> 방법: 6 에이전트 병렬 웹조사(벤더 공식 약관·가격·API 문서 직접 확인, 확인일 2026-09-07).
> 판정 기준: **연구 약관 허용 + 2007-2014 이상 심층 + PIT/영수증 가능**을 동시 만족(또는 근접). 비용·재배포·표시는 요건 아님.
> 규율: 약관 우회·스크래핑 0 · 시크릿 미로드(키 필요 엔드포인트 실호출 0) · 데이터 수집 0 — 조사·문서만.

## §0 판정 — 합법 소스는 실재한다 (설계 §0 전제 반증)

**LEGAL_SOURCE_EXISTS.** 연구 용도에서 "합법 + 2007-2014 심층 + PIT"를 동시 만족(또는 근접)하는 소스가 복수 실재한다.
설계도 §0의 "합법 일중 소스 부재"는 **부정확**하며, 정확한 벽은 아래 §4의 **"동시성 부재"**로 재기술해야 한다.

- 재배포·저가·표시합법은 판정 요건이 아니므로 **상업 라이선스 게이트는 실격 사유가 아니다.**
- 무료·학술·공공(§3) 티어 *내부*와 두 세부요건(§4)에서는 §0이 여전히 참에 가깝다 — 전제를 통째로 폐기하지 말고 정밀 재기술.

## §4 정확한 벽 — "부재"가 아니라 "동시성 부재" + 진짜 공백 2건

세 판정요건만 보면 소스는 실재한다. 실제 벽은 요건 밖 축이다:
1. **비용**: 심도·PIT 최상(TAQ·AlgoSeek·OptionMetrics)은 상업 직판이 고가.
2. **접근권(자격 게이트)**: 저가로 심층+vintage-PIT를 주는 WRDS TAQ/OptionMetrics는 **학술기관 소속 필수** — 비학술 CEO는 직접 상업 라이선스(고가)만 남는다.
3. **PIT**: 저가·표시합법인 FirstRate는 조정 재구성본 → vintage 아님. **저가+표시합법+vintage-PIT를 한 소스가 동시에 못 준다.**
4. **진짜 공백 2건(무벤더)**: (a) **틱을 1996까지** 소급하는 벤더 없음. (b) **2007-2014 진짜 일중(틱/분) 옵션 IV 표면**을 주는 벤더 없음 — 일중은 트레이드/쿼트만, 표면이면 EOD(OptionMetrics)이거나 near-EOD(ORATS). 설계 §0은 이 두 세부요건에 한해서만 참에 가깝다.

## §5 D4(CBOE 발송) 함의 — 조건부 GO

옵션표면 갈래에서 **Cboe DataShop/LiveVol이 실행가능 최우선 표적**: (a) 2004+로 창 커버, (b) §1 내부연구 명시허용, (c) §2b가 파생데이터 디스플레이 재배포를 조건부 허용(재배포권 선택 + 원자료 역설계 불가 + 인덱스 제3자 라이선스 확인) — 옵션 중 유일하게 연구+합법표시 공존. **D4 라이선스 요청 발송은 근거가 탄탄하다.**

- **포크 A(권장·깨끗)**: QQQ(Nasdaq-100 ETF) 옵션 = NDX 대용 프록시. OPRA 통합 소스라 Cboe 단일 약관으로 커버, **제3자 오버레이 없이** 진행.
- **포크 B(오버레이 필요)**: NDX 인덱스옵션 자체. §3d·§16 제3자 수익자 조항상 **Nasdaq(지수 소유자) 별도 라이선스** 확인 필요 — 발송 시 이 오버레이 조건을 명시 질의.
- 해상도·예산: 일중 1분 애드혹 $1.5k~2.5k/월·요청 vs 구독 $5~6k/월. EOD는 $500/월.

## §6 권장 다음 단계 (전부 사용자 결정 영역)

이 조사는 판정만 했다. 실제 데이터 취득·CBOE 발송·설계 §0 문안 수정은 **되돌릴 수 없거나 예산·법적 결정**이라 사용자 몫이다.

1. **[옵션표면] D4 CBOE 발송 = GO 권고.** 사용자 결정: (i) NDX 인덱스옵션이면 Nasdaq 제3자 오버레이 동반확인, 또는 **QQQ 프록시로 우회**, (ii) 예산 티어(애드혹 vs 구독), (iii) 라이브카드 파생표시가 목표면 §2b 재배포권 옵션 선택.
2. **[주식 일중] 이지선다(예산·PIT 우선순위 사용자 결정)**:
   - **AlgoSeek**(2007+ 틱, as-traded PIT, 엔터프라이즈가) — 틱 해상도·PIT 순정성 필요 시.
   - **FirstRate**(1분 2000+, ~$300, 무키, 연구+표시 합법) — 저가·즉시착수·표시합법 우선, PIT 순정성 양보 가능 시.
3. **[배제]** WRDS TAQ/OptionMetrics는 심도·PIT 최상이나 **학술 소속 필수** — 접근경로 없음(학술 제휴 확보 시에만 재검토). 직판 상업 라이선스는 고가 대안.
4. **재개는 새 검정**: 데이터를 사도 재개 프로토콜(T5 실패 기계 수리=대안 귀무 확정 + 새 사전등록 + PIT·영수증 data_policy 충족 + 봉인 무변경)이 전제. 데이터 확보 ≠ 트랙 개시.

## §7 caveats

1. 이 문서는 벤더 약관을 **확정 판정하지 않는다** — 사용자의 법적 확인을 위한 지도다. 최종 적격성은 계약서·법률검토로 직접 확인.
2. 약관·가격·커버리지는 변한다. 다수 [미확인](정확 구독가·2007-2009 ITCH 소급·NDX 인덱스옵션 정확 커버·상업 표시조항) — 견적·서면확인 선행.
3. 재배포·상업판매는 판정요건이 아님. 표시 restricted를 실격으로 쓰지 않았다 — 라이브카드 공개표시가 실제 목표가 되면 별도 승인/라이선스 필요(재검토).
4. LEGAL_SOURCE_EXISTS는 **연구 용도** 기준. 무료·학술 티어 내부, 틱→1996·진짜 일중 옵션 IV표면 두 세부요건은 여전히 공백.
5. **백테스트 금지 원칙**: 이 데이터의 2007-2014은 결정론 수치모델의 base rate 참조·워크포워드용(dualdb §8 예외)이지 LLM 캘리브레이션 표본이 아니다. 하이퍼파라미터가 정점지식을 간접 내포할 수 있다는 caveat 유지.

## §8 설계 §0 정정 필요 (기록만 — 문안 수정은 사용자 승인)

설계도 §0의 "합법 일중 소스 부재"는 반증됐다. 정확한 재기술: **"연구용 합법·심층 소스는 존재하되, 저가·표시합법·vintage-PIT의 동시성이 없고, 틱→1996·2007-2014 진짜 일중 옵션 IV표면 두 세부요건에 무벤더 공백이 있다."** 이 정정은 설계 문서(사전등록 아님)에 반영할지 사용자 결정. 본 조사는 판정·기록만 한다.
