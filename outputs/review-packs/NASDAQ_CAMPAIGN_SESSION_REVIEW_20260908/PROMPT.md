# 외부 검증 요청 — NASDAQ 게이트 캠페인 세션 전 과정

당신은 이 캠페인의 **독립 검증관**이다. `00_SESSION_TIMELINE.md`가 세션 전 과정을 단계별로 요약하고,
트랙별 폴더(01~06)에 상세 원본이 있다. 각 단계의 판정과 최종 거버넌스 행동(main 병합·배포)을
적대적으로 재검토하라. 결론을 그대로 승인하지 말고 반대 입장을 최대한 세운 뒤 증거로 반박되는지 확인하라.

## 검증할 것 (단계별)

1. **V9~V11 동결 (01)**: 세 동결이 옳은가. `verdict_recompute.json`으로 V10 GFC-인공물(상위5% 제거 부호반전)·
   V11 전이 실패를 독립 재현. 민감도 그리드(v10/v11)로 판정 안정성.
2. **V12 부정결과 (02)**: `SUNDAY_LOOP_FINAL_REPORT`의 채택 0/8·T5 실패(0.254)를 재현. T4 하한=0을 '미달'로
   본 것·관대 5셀의 검정력 논거가 타당한가. 재보정 맵이 정말 죽었는가.
3. **합법 소스 조사 (03)**: "LEGAL_SOURCE_EXISTS" 판정이 옳은가. 벤더 약관(FirstRate 표시허용·Cboe §2b)이
   실제로 그러한지 공식 페이지로 교차확인. QQQ 프록시가 Nasdaq 제3자 오버레이를 실제로 회피하는가.
4. **포스트모템 H3 (04) + P1/T-A (05)**: H3(경로 생성기 과확산)가 옳은 진단인가. P1 VR(5)=0.874가 포스트모템
   0.72와 다른 이유(정의·창)가 결론을 바꾸는가. **T-A NOT_REPAIRED**(N-p-block 0.201)가 T1맵 누수를 옳게
   증명하는가 — `ta_null_repair.json`으로 재계산. B1·T-B 종결이 정당한가.
5. **V13-VOL (06)**: rung-1 EWMA가 기후 대비 9/9 통과(`ladder_ewma_logit.json`)·rung-2 HAR 증분 0/9
   (`ladder_har_logit.json`)를 재현. **"스킬은 지속성 지배"** 판정이 옳은가 — 특히 나이브 지속성(persistence)
   기준선 대비 EWMA의 증분을 별도로 재봐라(기후는 약한 기준선). reliability(h63 오보정) 해석. GARCH-t 미실행이
   정당한가(HAR null 증분으로 moot인지, 아니면 GARCH가 다를 여지가 있는지).
6. **거버넌스 — main 병합·배포**: V13-VOL이 홀드아웃 미검증(설계창만)인데 main에 병합한 것이 적절한가.
   봉인 무변경·CI 통과는 확인됐으나, 파생층 미배선(T0) 유지가 옳은가. V13-D3 홀드아웃 보류 권고가 타당한가.

## 거버넌스 제약 (필수)

- 재계산·판정만. 홀드아웃(2015-2018)·봉인(2019+) 미열람. 봉인 파일·원장·예측 무수정. push·CBOE 발송 금지.
- 백테스트는 결정론 수치모델의 design 창만(dualdb §8) — 산출은 base rate 참조이지 LLM 캘리브레이션 아님.

## 산출

각 단계 판정(유지/번복) + 근거 수치 + 캠페인 관통결론("효율적 시장 벽 + V13-VOL은 지속성") 동의/이견 +
다음 단계 제언(현 계보 소진 여부, 옵션 데이터 C1의 실질 가치, V13-VOL 홀드아웃 소모 권고).

## 정직성 기준

이 캠페인 방법론 핵심: **in-sample 통과 ≠ 채택; 표본외 양방향 전이가 진짜 필요조건.** 어떤 대안을 제시하든
전반↔후반 양방향 전이(CRPS/Brier 부호까지)로 검증한 뒤 제시하라. 결과 본 뒤 귀무·가설·문턱 교체는 위반.
