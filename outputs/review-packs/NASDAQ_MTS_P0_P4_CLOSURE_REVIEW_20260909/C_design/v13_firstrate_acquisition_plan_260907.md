# FirstRate Data 취득·적재·컴플라이언스 실행계획 (2026-09-07)

> 사용자 결정: 주식 일중 갈래 = **FirstRate**. 이 문서는 구매 후 바로 실행할 수 있는 계획이다.
> **구매($300)·다운로드는 사용자 실행 사항**(금전거래·계정) — 자율 세션은 실행하지 않는다.
> 포스트모템(V12_POSTMORTEM_NEXT_DESIGN) 재편에 따라 FirstRate 일중은 **후순위 행정·리드타임 트랙(T-D/A4)**이다 —
> 근본 원인은 데이터 부족이 아니라 경로 생성기(H3)라, 1순위는 기존 데이터로 하는 V12b(T-B)·V13-VOL(T-C)이다.
> FirstRate는 그 두 경로가 소진되거나 일중 실현변동성 정밀도가 필요할 때 값을 낸다.

## 1. 무엇을 사는가 (구매 사양)

- 벤더: FirstRate Data (https://firstratedata.com). 라이선스: https://firstratedata.com/about/license (확인 2026-09-07).
- 대상: **NASDAQ-100(NDX) 지수 + QQQ + NDX 구성종목**의 1분봉 (설계창 2007-2014 커버; 1분봉 이력 2000+).
  - 최소셋: NDX 지수 1분봉(V12b·V13 실현변동성 입력) — 저비용 착수.
  - 확장셋: QQQ + 구성종목 1분봉(경로 사건 분석·교차검증). 번들 ~$300–400 일회.
- **틱은 2010+**라 설계창 하단(2007-2009)은 1분봉만 — 사양에 명기. 1분봉으로 H3 되돌림·실현변동성은 충분.
- 무료 2주 샘플로 **스키마·품질 선검증 후** 구매 권장.

## 2. 컴플라이언스 경계 (라이선스 명문)

- 허용: 내부 연구·재분석 / **파생물(모델·리서치·그래프·확률) 발행 — FirstRate 귀속표기 조건**. → 연구(a)·표시(b) 둘 다 합법.
- 금지: **원자료(raw) 재판매·재배포**. raw는 로컬에만 두고, 공개 표시는 파생 확률·그래프만(귀속표기).
- 경계 규칙: `data/**`의 FirstRate raw는 **커밋·재배포 금지**(gitignore). 파생 산출물만 커밋·표시.

## 3. 적재 경로 (구매 후 실행)

1. 다운로드 → `data/intraday/firstrate_raw/`(**gitignore, 로컬 전용, 재배포 금지**). 다운로드 URL + 시각 + 파일 sha256를 `data/intraday/receipts.jsonl`에 기록(DECISIONS 12-6/12-8 캡처영수증).
2. 적재 도구 `tools/v13_firstrate_ingest.py`(**샘플 확보 후 작성** — CSV 스키마 확정 전 추정 파싱 금지): 1분봉 → PIT-안전 일중 피처 스토어 `data/intraday/features/`(trailing-only, 각 origin은 자기 시점까지만).
3. **불변식**: 봉인 V8/V2·forecasts/·calibration/·원장 **무접촉**. 새 스토어(data/intraday/)에만 기록. main 커밋·push 없음.

## 4. PIT 지위 (정직한 한계)

- FirstRate 1분봉은 **조정(back-adjust) 재구성본** — first-print/vintage가 **아니다**. 영수증은 다운로드-시각 캡처 등급.
- 따라서 산출물은 **결정론 수치모델의 base rate 참조·워크포워드용**(dualdb §8 예외)이지 LLM 캘리브레이션 표본이 아니다.
  하이퍼파라미터(창·경계)가 정점지식을 간접 내포할 수 있다는 caveat 유지.
- 순정 first-print PIT가 필요하면 대안은 NYSE Daily TAQ/AlgoSeek(고가·학술게이트) — 조사 문서 §1 참조.

## 5. 어떻게 쓰는가 (V12b·V13 입력)

- **V13-VOL(T-C)**: 1분봉 → 일중 실현변동성 RV(HAR-RV 입력). FRED 일간 대비 정밀 σ. 단 V13 1차 사다리는 FRED만으로 착수 가능(FirstRate는 정밀도 향상 옵션).
- **V12b(T-B)**: 경로 생성기 검정에 일중이 필수는 아님(일간 잔차 재표집 구조 문제) — FirstRate는 사건(배리어 터치)의 일중 실현 검증용 보조.
- 결론: FirstRate는 **1순위 두 트랙의 필수 입력이 아니라 정밀도·검증 보강**. 그래서 리드타임 트랙으로 두고, 구매 시점은 V12b/V13 1차 결과를 본 뒤로 미뤄도 손실 0.
