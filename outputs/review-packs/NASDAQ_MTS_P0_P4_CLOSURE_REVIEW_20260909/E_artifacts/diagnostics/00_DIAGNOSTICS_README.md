### 3.7 인정 — **사전등록 검정은 낙관적이었다**

명확히 적는다.

> **사전등록된 family 검정 `P(k≥3 | n=9, p=0.05) = 0.008361` 은 셀 독립을 가정했고, 그 가정은 이 팩의 자료로 거짓임이 측정되었다. 측정된 종속을 넣으면 같은 결과의 P 는 0.041515 로, 사전등록값보다 4.97배 크다. 0.05 문턱까지 남은 여유는 0.0085 이며, 비율로는 문턱의 17% 다. 사전등록값이 시사한 "여유 6배"(0.05/0.008361)는 실재하지 않는다.**

이 인정은 `B_verdicts/00_VERDICT_DIGEST.md` §8-W5 가 이미 **정성적으로** 적어 둔 것(*"독립 가정 하의 0.0084 는 낙관적이며, 실제 유효 검정 수는 9보다 작다"*)에 **숫자를 채운 것**이다. 새 주장이 아니라 기존 자백의 정량화다.

한 가지 더 — **통과 3셀은 서로 가장 강하게 얽힌 조합이 아니다.**

| 조합 | 쌍별 상관 |
|---|---:|
| `rv_h5` × `rv_h21` | +0.2911 |
| `rv_h21` × `vix25_h21` | +0.2548 |
| `rv_h5` × `vix25_h21` | +0.0934 |
| **평균** | **+0.2131** |

전체 84개 3셀 조합의 쌍별 상관 평균 중앙값은 **+0.2228** 이고, 관측된 통과 조합은 **46위/84** — 중앙보다 약간 아래다. 가장 얽힌 조합은 `vix25_h5`·`vix30_h5`·`vix30_h21`(평균 +0.6932)이다.
**그러나 이 사실을 방어에 쓰면 안 된다.** 사전등록 검정은 K(통과 셀 **개수**)에만 걸려 있고 "어느 셀이 통과했는지"에 조건부가 아니다. 조건부 재기술은 사후 재정의이므로, 위 표는 **정황**일 뿐 P 값을 되돌리지 않는다.

### 3.8 "유효 검정 수를 줄인다"는 경로는 **방향이 반대다** — Q3 (d) 정정

`00_REVIEW_REQUEST.md` §3-Q3 (d) 는 이렇게 적었다:

> *"유효 검정 수를 예컨대 4~5 로 보면 k=3 의 family P 가 0.05 를 넘길 수 있고…"*

**이 진술은 산술적으로 틀렸다.** 같은 이항 규약에서 n 을 줄이면 P(k≥3) 은 **작아진다**(기회가 줄기 때문). 실측:

| 기준 | n | P(k≥3 \| p=0.05) | 사전등록 대비 |
|---|---:|---:|---|
| 명목 (사전등록·공식) | 9 | **0.008361** | — |
| Cheverud–Nyholt | 8 | 0.005788 | **0.69× (더 작아짐)** |
| Li–Ji | 7 | 0.003757 | **0.45× (더 작아짐)** |
| Q3(d) 가정치 | 5 | 0.001158 | 0.14× |
| Q3(d) 가정치 | 4 | 0.000481 | 0.06× |

`cell_dependence_design_window.json` 의 `family_p_sensitivity` 배열이 앞 세 행을 그대로 싣고 있다(0.008361 · 0.005788 · 0.003757). **즉 이 팩이 자기 손으로 계산해 둔 값이 Q3(d) 의 서술과 모순된다.**

왜 그런가 — `n_eff` 를 이항의 n 에 그대로 꽂는 것은 잘못된 도구다. 그것은 **검정 횟수만 줄이고 k 는 3 으로 고정**하므로, "9번 중 3번" 을 "7번 중 3번" 이라는 **더 드문 사건**으로 재기술해 버린다. 종속의 진짜 효과인 **동시 통과의 클러스터링**은 이 방식으로 표현되지 않는다.

**코퓰러가 옳은 도구다.** 코퓰러는 검정 수를 9로 유지한 채 통과 지시자 사이의 상관을 넣으므로, 클러스터링을 통해 P 를 **올바른 방향으로 — 위로** 움직인다(0.008361 → 0.041515).

> 검토관에게: §3-Q3 의 답 형식 (a) 는 **A**(그대로 유효) / **B**(유효 검정 수 축소) / **C**(참고값 표기 강화)였다. 이 진단은 **B 가 실행 불가한 선택지**임을 보인다 — 축소는 문턱을 올리는 게 아니라 내린다. 남는 선택은 A·C 이거나, 또는 **D: 코퓰러 P 0.0415 를 병기한다**이다. D 는 이 팩에 없던 네 번째 선택지다.

### 4.6 이것이 S1-1 을 **완전히 해소하지는 않는 이유** — 네 가지

JSON 자신의 `caveat` 필드가 첫째를 적고 있다: *"이 표는 '사후 MDE 만 있었다'는 지적을 반박할 뿐, 사후 MDE 사용 자체를 정당화하지 않는다."* 네 가지로 풀어 적는다.

1. **판정 문서가 인용한 MDE 는 여전히 사후 MDE 다.** 이 대조표는 **사후에 만든 대조**이며, 홀드아웃 판정서와 원장이 실은 `mde` 필드는 §4.1 표 그대로 사후값이다. S1-1 이 요구한 것은 "결과 전 공표본이 있었느냐"였고 그 답은 "있었다"이지만, **판정에 실제로 쓰인 것이 그 공표본이었느냐**의 답은 여전히 "아니다"이다.

2. **두 MDE 는 서로 다른 창·다른 n 의 다른 추정량이다.** 비평 §S1-1 5번이 지적한 대로 `vix25_h5` 는 설계창 late **0.075655** vs 홀드아웃 사후 **0.010041** = **7.5배** 차이다. 사전 MDE 는 설계창 반창(n≈1,000)의 PB-vs-기후 부트스트랩이고, 사후 MDE 는 홀드아웃 전창(n=1,001)의 champion-vs-기후 부트스트랩이다. **"사전 MDE 를 넘었다"는 진술은 설계창 검출력 기준의 진술**이지, 홀드아웃 검정이 사전 등록된 문턱을 통과했다는 진술이 아니다.

3. **rung-4 는 이 표가 다루지 않는다.** S1-1 의 파급 중 가장 큰 것은 §3-Q7 — `measured_zero` 27/27 라벨이다. 비평은 rung-4 의 셀별 `paired.*.mde` 도 결과 산출물 안에만 존재한다고 실측했다(예: `rv_h21|F1_term_spread.paired.early_to_late.mde = 0.008692737`). **이 대조표는 홀드아웃 9셀만 다루므로 rung-4 27검정의 첫째 연언지는 여전히 미해결**이다.

4. **T6 판정은 여전히 검토관 몫이다.** C0 ③("결과 전 MDE 공표")이 충족인지 아닌지는 "공표본이 존재했다"가 아니라 "**판정이 그 공표본에 걸려 있었다**"로 판단해야 한다. 이 진단은 전자를 증명하고 후자는 증명하지 않는다. 비평이 요구한 *"T6 을 '미발생'에서 '검토관 판단 대기'로"* 는 **이 진단으로 자동 해소되지 않는다.**

## 5. 이 진단들의 한계 — 세 가지

### 한계 1. 상관은 **설계창**에서 쟀다. 홀드아웃 창의 상관은 다를 수 있다.

§3 의 모든 상관·고유값·유효 검정 수·코퓰러 귀무 분포는 **2007-2014 설계창** 자료다. 정작 family P 가 적용되는 검정은 **2015-2018 홀드아웃**에서 일어났다.

**왜 홀드아웃에서 재지 않았는가**: 홀드아웃 원장(`E_artifacts/ledgers/holdout_scorings.jsonl`)은 셀별 **요약 통계와 10구간 신뢰도 곡선**만 담고 **원점별 배열을 담지 않는다**(비평 §S2-1 실측). 따라서 홀드아웃 상관행렬을 만들려면 **홀드아웃 창을 다시 열어 원점별 계열을 재생성해야 한다.** 이 팩의 계약은 결과 확인 후 그 창의 재사용을 금지하며(`prohibitions.outer_window_reuse_after_results`), 재열람은 남은 슬롯 논쟁과 무관하게 **오염 위험**이다. 그래서 하지 않았다.

**대가**: 설계창은 GFC(2008-2009)가 지배한다 — `B_verdicts/00_VERDICT_DIGEST.md` §8-W5 인접 논의가 *"설계창 GFC 지배 때문에 'early↔late 전이' 검정은 사실상 '위기↔평온 전이' 검정"* 이라고 적은 그 창이다. **위기 국면은 모든 변동성 셀을 동시에 움직이므로 상관을 부풀릴 소지가 있다.** 반대로 홀드아웃(2015-2018)은 2015-08·2018-02·2018-12 세 개의 짧은 스파이크가 있는 상대적 평온기라, 셀 간 동조가 **더 낮을 수도 있고**(→ 코퓰러 P 가 과대) 스파이크 집중 때문에 **더 높을 수도 있다**(→ 과소). **부호를 알 수 없다.** 0.041515 를 홀드아웃 창의 값으로 읽어서는 안 된다.

### 한계 2. 코퓰러는 '손실차 상관'을 '통과 지시자 상관'에 **사상**한다 — 근사다.

측정한 것은 **연속 손실차의 피어슨 상관**이고, family 검정이 세는 것은 **이산 사건(셀이 게이트를 통과했는가)**이다. 가우시안 코퓰러는 손실차 상관을 잠재 정규변수의 상관으로 놓고 그 상단 5% 절단으로 통과 지시자를 만든다. 이 사상에는 세 겹의 근사가 있다.

- **분포 형태**: 손실차는 유계·비대칭이며 정규가 아니다. 가우시안 잠재변수 가정은 **꼬리 종속(tail dependence)을 0 으로 놓는다** — 실제 변동성 셀은 극단에서 더 붙는 경향이 있으므로 이 방향으로는 **0.041515 가 과소추정**일 수 있다.
- **게이트 형태**: 셀별 PASS 는 G1(CI90 단측 ≈ 0.05) ∧ G4(≤0.10)의 **합성**이며, 그 결합 크기가 정확히 0.05 라는 보장이 없다(§8-W5 가 이미 지적). 코퓰러는 "셀당 0.05" 를 그대로 받아 쓴다.
- **부트스트랩 상관**: 9셀·4 rung 이 단일 시드 `20260907` 을 공유하므로 **부트스트랩 오차 자체도 셀 간 독립이 아니다**(§3-Q3 (c)). 손실차 상관은 이 성분을 담지 않는다.

또한 최근접 PSD 보정이 원 행렬을 미세하게 바꾼다(최소 고유값 0.0859 > 0 이므로 보정량은 작다). 그리고 200,000 추출의 몬테카를로 오차는 P≈0.0415 에서 표준오차 ≈ 0.00045 다 — 독립 재시뮬레이션에서 0.04138 을 얻었다(§6-B). **0.0415 는 소수 셋째 자리까지만 신뢰할 값이다.**

### 한계 3. 설계창 MDE 는 설계창 표본 크기·기저율에서 나온 값이라 **홀드아웃 검출력과 같지 않다**.

`prepublished_mde_design_max` 는 설계창 반창(n≈1,000, split 2011-01-01)의 사건율과 부트스트랩 분산에서 나왔다. 홀드아웃 창은 **다른 n · 다른 기저율 · 다른 국면 구조**를 갖는다. §4.6-2 의 7.5배 사례가 그 크기를 보여 준다.

이 때문에 §4.5 의 "배수" 열은 **"홀드아웃 효과가 설계창 문턱의 몇 배인가"** 라는 혼종 비율이지, 어느 한 창 안에서 닫힌 검정통계량이 아니다. **가설검정으로 읽지 말고, 사전 선언된 크기 감각과 사후 관측 크기의 대조로만 읽어야 한다.**

### A. 상관행렬을 CSV 에서 직접 다시 만들기 (S2-1 핵심)

```python
import json, itertools
import numpy as np, pandas as pd

D = "."  # 이 디렉터리
dep  = json.load(open(f"{D}/cell_dependence_design_window.json", encoding="utf-8"))
cells = dep["cells"]
clim  = {k: v["clim_base_rate"] for k, v in dep["per_cell"].items()}   # 기후는 셀별 고정 상수

df = pd.read_csv(f"{D}/per_origin_design_window.csv")
assert len(df) == dep["n_panel"] == 2014
assert df.date.min() == "2007-01-03" and df.date.max() == "2014-12-31"   # 설계창 한정 확인

# 손실차 = (clim - y)^2 - (p - y)^2   (양수 = champion 우세)
L = pd.DataFrame({
    c: (clim[c] - df["y_" + c])**2 - (df["p_" + c] - df["y_" + c])**2
    for c in cells
})

print("셀별 n        :", L.notna().sum().to_dict())          # per_cell.<cell>.n 과 일치
print("셀별 평균손실차:", L.mean().round(6).to_dict())        # per_cell.<cell>.mean_loss_diff 와 일치

C = L.corr()                                                 # pairwise-complete (pairwise_n 과 동일 규약)
print(C.round(4).to_string())

ref = np.array(dep["correlation_matrix"])
print("JSON 대비 최대 절대차:", np.nanmax(np.abs(C.values - ref)))
# → 4.5e-05 이하. JSON 이 4자리로 반올림 저장되어 있기 때문이며(반올림 반폭 5e-05), 부동소수 오차가 아니다.

# 비대각 요약 (JSON offdiagonal_summary 재현)
off = [C.values[i, j] for i, j in itertools.combinations(range(9), 2)]
print(f"고유 쌍 {len(off)}개 | 평균 {np.mean(off):.4f} | 중앙값 {np.median(off):.4f} "
      f"| 최소 {min(off):.4f} | 최대 {max(off):.4f}")
# → 36쌍 | 평균 0.2552 | 중앙값 0.1353 | 최소 -0.0302 | 최대 0.8955
#   (JSON 의 pairs: 72 는 순서쌍 기준. 대칭이므로 평균·중앙값은 동일)

# 가장 강한 쌍이 어디인지
rank = sorted(((C.values[i, j], cells[i], cells[j])
               for i, j in itertools.combinations(range(9), 2)), reverse=True)
for v, a, b in rank[:5]:
    print(f"{v:+.4f}  {a} × {b}")
# → +0.8955  vix30_h5 × vix30_h21   (같은 임계 · 중첩 지평)
```

### B. 코퓰러 귀무 분포 재시뮬레이션

```python
import json
import numpy as np
from scipy.stats import norm

D = "."
dep = json.load(open(f"{D}/cell_dependence_design_window.json", encoding="utf-8"))
R = np.array(dep["correlation_matrix"])

# 최근접 PSD 보정 후 상관으로 재정규화
w, V = np.linalg.eigh(R)
R2 = V @ np.diag(np.clip(w, 1e-10, None)) @ V.T
s = np.sqrt(np.diag(R2)); R2 = R2 / np.outer(s, s)

rng = np.random.default_rng(20260907)                 # family_null_under_dependence.json → seed
Z = rng.multivariate_normal(np.zeros(9), R2, size=200_000)
K = (Z > norm.ppf(1 - 0.05)).sum(axis=1)              # 셀당 귀무 통과확률 0.05

for k in range(1, 6):
    print(f"P(K>={k}) = {(K >= k).mean():.6f}")
# → 0.2819 / 0.1039 / 0.0414 / 0.0158 / 0.0055
#   JSON tail_probabilities: 0.28052 / 0.103255 / 0.041515 / 0.01663 / 0.00595
#   차이는 몬테카를로 오차(P≈0.04 에서 se≈0.00045). 셋째 자리까지만 신뢰할 것.
```

### D. 유효 검정 수와 이항 tail

```python
import json, math
import numpy as np

D = "."
dep = json.load(open(f"{D}/cell_dependence_design_window.json", encoding="utf-8"))
lam = np.array(dep["eigenvalues"]); M = 9

cn_sample = 1 + (M - 1) * (1 - lam.var(ddof=1) / M)   # 8.04  ← JSON 이 쓴 판
cn_pop    = 1 + (M - 1) * (1 - lam.var(ddof=0) / M)   # 8.147 ← 다른 관례
li_ji     = sum((1 if x >= 1 else 0) + (x - math.floor(x)) for x in lam)   # 7.0000
print(f"Cheverud-Nyholt(ddof=1) {cn_sample:.2f} | (ddof=0) {cn_pop:.3f} | Li-Ji {li_ji:.4f}")

tail = lambda n, k, p=0.05: sum(math.comb(n, i) * p**i * (1-p)**(n-i) for i in range(k, n+1))
for n in (9, 8, 7, 5, 4):
    print(f"n={n}  P(k>=3) = {tail(n, 3):.6f}")
# → 0.008361 / 0.005788 / 0.003757 / 0.001158 / 0.000481
#   n 을 줄이면 P 는 작아진다 — §3.8 의 방향 오류 정정을 여기서 직접 확인할 것.
```

|---|---|---|
