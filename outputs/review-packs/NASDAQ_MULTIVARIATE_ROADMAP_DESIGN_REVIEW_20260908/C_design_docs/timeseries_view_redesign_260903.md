- 요청: UI 패턴 정리, 모든 그래프에 마우스 호버, 외부 예측 시각화 벤치마킹 후 다양한 도표 도입, **'예측 방식' 박스는 전망 요약 하단에만**

## 1. 데이터 경계 (설계의 물리적 한계)

라이브 read model(`DATA.timeseries`, V8)에 **실제로 있는 것**만 1차 릴리스에 쓴다.

| 있음 (available_now) | 없음 (V8 미산출·미투영) |
|---|---|
| 4개 기간(1·5·21·63거래일) × 분위수 p10/p25/p50/p75/p90 (log_return + 지수 레벨 band_index/median_index) | 일별 63스텝 분위수 경로 (V2 전용) |
| 기간별 `probability_up` (원점 종가 대비 상승 경로 비율 — 계약상 표시 허용, 이미 카드에 노출 중) | 표본 경로·시나리오 군집 (20,000 경로는 미보존) |
| 원점(anchor) 종가·`as_of`·최근 63세션 실적 | 요인 기여도(attribution) — **V8은 어떤 기여도도 산출하지 않음** |
| 봉인 평가: 원점 1,011개, 21/63일 CRPS 개선율·p10–p90 적중률, run_id | 1/5일 봉인 지표, PIT, 원점별 오차, 국면별 적중률 (원장에 있으나 미투영 → 2단계) |
| 운영 신선도 5종(NASDAQCOM·VIX·DGS2·DGS10·DTWEXBGS_or_DTWEXB; status 값은 `fresh`) | 전진(라이브) 성숙 원점 — 현재 0개 |

**정직성 규율**: ① 보간 구간의 숫자를 만들지 않는다(호버는 실측 지점에만 스냅). ② 새 확률 파생값(임계 초과확률 "X 아래일 가능성 N%")을 만들지 않는다 — 분위수는 분위수 정의로만 서술. ③ 확률·분위수 모두 read model 값 그대로.

## 2. 벤치마킹 요약 → 채택/기각

| 관례 (출처) | 채택 여부 | 이유 |
|---|---|---|
| 중첩 분위수 대역 + 단일 색상·단조 투명도, 중앙선은 대역과 같은 색 (BoE fan chart, Prophet, GluonTS, Nixtla, Chronos) | **채택** — 기존 p10–p90 연한/p25–p75 진한 대역 유지 | 모든 조사 라이브러리가 동일; 다른 색 대역은 반패턴 |
| 과거→전망 경계 세로선 + 원점 라벨 (BoE, Orbit) | **유지** | 이미 구현(현재선) |
| 중앙선을 "예측"이 아니라 통계 이름으로 라벨 (Betterment '중앙값', Fed SEP 'Median', BoE Mode/Median) | **채택** | 툴팁·표 모두 '중앙값' 명칭, '목표가' 어휘 금지 |
| 커버리지는 항상 명시("80% 구간"), 여집합 공시 (thinkorswim "32%는 밖", BoE 1995 교훈) | **채택** | 호버·범례에 '설계 80% 구간' 명시 |
| 원점 기준 % 범위 막대 — 애널리스트 목표 범위 바 / ECMWF 메테오그램 기간별 상자 | **채택 → S1 기간별 예상 범위 막대** | 4개 기간의 20개 숫자를 한 그림으로; 기간이 멀수록 벌어짐이 한눈에 |
| 분위수 사다리 표(BoE CDF 표, ECB SPF 구간표) — 차트와 같은 색으로 | **채택 → P2 분위수 표** | 숫자를 정확히 읽고 싶은 독자용, 차트↔표 교차 하이라이트 |
| 밀도 곡선/리지라인/히스토그램 | **기각** | 분위수 5개로 밀도를 그리면 형태를 지어내는 것 — 데이터 없음 |
| 스파게티(표본 경로) 플롯 | **기각** | 표본 경로 미보존 |
| 임계 확률표 "P(지수>X)" (옵션 확률 콘) | **기각** | 새 확률 파생 금지 + 목표가처럼 읽힘 |
| SHAP 워터폴/발산 막대 (기여 요인) | **기각(1차)** | V8 기여도 미산출 — 가짜 SHAP 금지. 대신 '입력 신호 신선도'와 '입력 요인 묶음'으로 정직하게 |
| 스킬 스코어 막대 + 기준선 0선 명시 (ECMWF CRPSS, fpp3) | **채택 → B1 CRPS 개선율 막대** | "0 = 최선 기준선과 동일" 축 제목 |
| 구간 커버리지 vs 공칭(45°/목표선), 보수·과신 음영 (scoringutils, 코로나 예측 허브) | **채택 → B2 적중률 vs 80% 목표** | 적중률만 단독 표시 금지 관례 → 목표선·편차 병기 |
| 점수-기간 곡선(h별), PIT 히스토그램, 국면별 커버리지 | **2단계** (builder 투영 필요) | 원장에 있으나 read model 미투영 |
| x축 지배 크로스헤어 + 공유 툴팁, 오버레이 rect 1개, 스냅 데드존 없음 (TradingView LWC, Plotly x unified, Observable Plot) | **채택 → bindTsHover** | 마크별 리스너 금지, 커서 우측 14px 배치·가장자리 플립 |
| 터치: 탭-고정, 키보드: 포커스 가능 + 화살표, aria-live 낭독 (Chartability, WCAG 1.4.13) | **채택** | 모든 `[data-ts-chart]`에 role=status 리드아웃 |

주요 출처: BoE 'Understanding the fan chart'(1998)·Fan charts Nov 2017, Prophet plot.py, GluonTS/Nixtla 플롯 소스, TradingView Forecast/Probability Cone 문서, Fed SEP 2026-06, ECB SPF, ECMWF Forecast User Guide §12.B·scorecards, scoringutils, SHAP docs, NY Fed Staff Nowcast, TradingView Lightweight Charts tooltips 튜토리얼.

## 3. 정보 구조 (탭 하나 = 질문 하나 = 도표 1개 + 보조 1개)

공통 골격: `.timeseries-hero`(칩·제목·원점 문장 + **게이트 칩 2개를 히어로 안으로** → 전 탭에서 PASS 상태 유지) → 탭 스트립 → 4개 패널 → footnote(**'매매 신호가 아닙니다'를 footnote 기본 문구에 추가** — 방법 박스가 첫 탭으로 들어가도 4탭 모두 공시 유지).

### 01 전망 요약 `#timeseries`
- **K1 기간별 KPI 카드 4장** (기존 `.timeseries-horizons` 유지, 호버 stop 승격): 기간 / 중앙값 레벨 / `+x.xx% · 상승 가능성 NN%`. 호버·포커스 시 분위수 5행 툴팁, ←/→ 이동.
- **S1 기간별 예상 범위 (신규 SVG)**: y=기간 4행, x=원점 대비 %(0% 굵은 선 + '원점 종가' 라벨, 상단 보조 눈금=지수 레벨). 행마다 p10–p90 연한 막대, p25–p75 진한 막대, 중앙값 세로 틱. 호버: 행 하이라이트 + 분위수 툴팁. 읽는 법 3행.
- **S2 상태선**: "참고 의견입니다 — 매매 신호가 아닙니다 · 봉인 원점 N개 · 63일 CRPS 개선 +x.x% · 검증 성적 전체 보기 →" (기존 봉인 성적 카드는 04로 이동).
- **S3 예측 방식 박스** `timeseriesSpecCard(ts)` — **이 패널의 마지막 자식으로만**. model_id 분기(V8 문구 / 그 외 모델 불특정 문구).

### 02 경로 분포 `#timeseries/path`
- **P1 대역 차트** (기존 `timeseriesV8BandSvg` + 호버 레이어): stop = 실적 63 + 원점 + 실측 노드 4. 실적 구간 툴팁 '날짜 · 실제 기록 · 종가', 노드 툴팁 'N거래일 · 날짜 · p90/p75/중앙값/p25/p10 · 상승 가능성'. 노드 라벨은 `N일`로 축약(확률은 호버·표로).
- **P2 분위수 표** (차트 아래 동시 노출): 행=기간, 열=10%·25%·중앙·75%·90% 분위수·상승 가능성. 셀=레벨 + 부호 있는 %. 행 호버 ↔ 차트 노드 확대(렌더 스코프 버스, 재마운트 누수 없음).
- **P3 캡션**: 기존 보간 정직성 문장 유지 + 불확실성 성장 한 줄 — 부호 있는 양끝("1일 −1.4%/+1.4% … 63일 −8.1%/+12.6%", 실제 값으로 계산).

### 03 기여 요인 `#timeseries/drivers` (V8에서 활성화)
- 리드 1줄: "이 화면은 모델 입력이 무엇이고 얼마나 신선한지입니다 — 기여도(가중치×변화)가 아닙니다. 봉인 모델은 기여도를 산출하지 않습니다."
- **D1 입력 신호 신선도**: 5행 막대(경과시간/한도), 상태 `fresh`=정상 그 외 경고, 한글 라벨(`DTWEXBGS_or_DTWEXB`→달러지수 포함). 호버: 시리즈·경과·한도.
- **D0 입력 요인 묶음**: 계약 문구 그대로 "VARX 내생 5종 + DFM 성장·물가 요인" 정적 목록, 값·부호·색 없음.
- 2단계 후보: 최근 63세션 입력 변화(builder 투영 필요) — 1차 생략.

### 04 검증 성적 `#timeseries/backtest` (V8에서 활성화)
- **B0 KPI 3장**: 봉인 원점 N / 63일 CRPS 개선 / 63일 80% 구간 적중률(+편차). read model 밖 수치(기간 '2007~', 전진 원점 0) 표시 금지.
- **B1 기준선 대비 CRPS 개선율 막대**: 21·63일, 0선="최선 기준선과 동일", 음수면 갈색으로 그대로 노출.
- **B2 80% 구간 적중률 vs 목표**: 행=기간, 목표선 80%, 오른쪽 '보수적' 왼쪽 '과신' 음영, 편차 라벨.
- 리드: "단 1회 공개된 봉인 평가(run …)입니다 — 재조정 불가."
- 2단계 후보: 1/5일 지표·국면별 적중률·롤링 CRPS(원장 투영 후).

## 4. 공유 호버 시스템 `bindTsHover(host, spec)`
- 기존 `bindScenarioV52Hover` 골격(오버레이 rect 1개 → viewBox 좌표 최근접 stop → 크로스헤어/점 갱신 → 전역 `#tip`) + `role=status` 리드아웃·키보드.
- spec: `{W,H,axis:'x'|'y',positions[],describe(i)→{head,rows[{name,value,sub,color}],speak},paint(i)}`; DOM 표면(카드·표·리스트)은 `[data-ts-stop]`으로 동일 spec.
- 출력 3곳: ① `#tip`(fine pointer만, 커서 우측 14px, 오른쪽 넘치면 좌측 플립) ② SVG 안 크로스헤어·활성 점 ③ `.ts-readout`(role=status, aria-live) — 터치·키보드 사용자용 상시 텍스트.
- 규율: 데드존 없음(전폭 매핑), 실측 stop만, 가격+확률 결합 문장 금지, 인라인 색 대신 CSS 클래스, `.admin-ts` 클래스 미사용(rect fill 특이도 충돌).
- 확대(줌) 모달은 클론이라 호버 없음 → 값 라벨을 SVG 본문에도 인쇄.
