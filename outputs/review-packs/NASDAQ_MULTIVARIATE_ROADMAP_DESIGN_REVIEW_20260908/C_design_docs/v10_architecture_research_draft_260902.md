# [초안] V10 분포 계층 아키텍처 연구 설계서 (2026-09-02)

> 지위: **DRAFT — V10-D1(개시 승인) 전.** 이 문서는 연구를 개시하지 않는다. 계약 작성·코드·
> 실험은 전부 승인 후 별도 커밋. 근거: V8 분포 계층 코드 실측 + 개발 원장 E0~E11 전수 +
> 봉인 run 약점 분해 + V9 무효익 판정 (워크플로 2에이전트 정찰, 2026-09-02).

## 0. 존재 이유 — V9가 실측으로 좁혀 준 문제

V9는 단독 ablation 6종(주간 거시신용 4종 전체창 + 직교 스프레드 1종 서브창 + M2SL)으로
**"V8 동결 승자 위 exog 열 추가"라는 경로 전체를 소진**시켰다 — 효과 부재이지 검정력
부족이 아니다(설계창 paired se ≈ 0.0008로 +2%급 효과는 확실히 검출됐을 표본). 남은 개선
여지는 **분포를 만드는 계층 그 자체** — 잔차 풀·혁신 분포·발생기 혼합·재보정 맵 — 이며,
이는 V8 봉인 계약이 동결한 영역이라 **새 모델 계약(V10)** 으로만 열 수 있다.

## 1. 불변 헌법 (승계 — 어떤 후보 아키텍처에서도 유지)

- V8은 불변 선행자: `src/ai_fc/timeseries_v8/**` 0바이트, 봉인 run 4핀(run_id·content·
  contract·model_code) 벤치마크. V2 8파일 동일. retune 금지.
- 게이트 산술 무변경: publication p10–p90 [0.76,0.84]·p25–p75 [0.45,0.55]·regime ≥0.70·
  장기 ≥+2%·CI90 상단 ≤0; dev proxy(R8-D1 개정형) ≥+2.5%·se ≤0.001·full-투영 CI 상단
  ≤−0.0004·coverage 밴드.
- 정지점 2(홀드아웃 승인 문자열·봉인 사인오프 별도 세션), 예산·finalist 유한, append-only
  원장, E0 내포(퇴화 파라미터 = V8 챔피언 비트 동일), 챔피언 자격 = E0 대비 쌍대 개선.
- 결정론 수치 모델 예외 안에서만: DL·가중치 학습 금지(CLAUDE.md ML 게이트), 고전 통계
  방법(부트스트랩·quantile map·isotonic·모수 꼬리)만.
- **이중 반청정 caveat (V10 신규)**: V2에 이어 V8의 2019+ 봉인 성적도 이미 공개됐다.
  V10 개발은 그 요약 통계를 아는 상태에서 진행됨을 계약에 명기하고, 2019-blindness
  (개발 데이터 절단 2019-04-30)를 코드로 강제하되 이 한계는 소거가 아니라 공시로만
  다뤄진다.

## 2. 기준선의 정확한 기계 — V8 챔피언(E10)이 실제로 하는 일

| 계층 | 챔피언 상태 | 수학적 형태 (코드 좌표) |
|---|---|---|
| 엔진 | V2 비트동일 | ridge-VARX 잔차의 stationary bootstrap, `혁신 = 잔차[bs]×scale[bs]` — EWMA devol/revol 일간 FHS (model.py:199). expanding+rolling 2모델, CRPS 역수 앙상블 가중 clip[.25,.75] |
| B1 기간구조 | **미사용** (φ=None) | 스텝 승수 √(v_t/v_now) — 기각 이력 §4 |
| B2 위치앵커 | **미사용** (ω=0) | 유계 이동 clip(ω(μ̂h−mean), ±σ_cap·σ) |
| B5 FHS | **h21·63만** | 겹침 h-창합 z-표준화(창 시작 시점 EWMA로 devol) → σ_proj(current_ewma)로 재구성. 엔진 한계분포를 **통째 교체** (backtest.py:158~172). tilt ω=0 |
| B3 블렌드 | w=.75 (h21·63) | historical_simulation과 가중 점질량 혼합 — CRPS는 Cramér 정확식, w는 지평별 **정적 상수** (backtest.py:179) |
| B4 재보정 | s=.5, 전 지평 | u* = (1−s)·Q̂_pit(q) + s·q — 경험 quantile map + 선형 수축. 성숙 PIT ≥104(성숙=68세션) 필요 → **2007~09 비활성** |
| 단기 h1·h5 | 엔진+B4만 | FHS·블렌드 미적용 — 순수 V2 한계분포에 재보정만 |

## 3. 봉인 실측이 가리키는 표적 (1,011원점, 2019+)

1. **국면 비대칭 coverage — 1순위 표적**: pandemic-2020 p10–p90 **0.917(과잉폭, 48원점)**
   vs tightening-2022 **0.750(과소폭, 52원점 — 하한 0.70까지 5pp)**. 급락형엔 너무 넓고
   완만 긴축형엔 너무 좁다. 무조건부 잔차 풀 + 정적 w의 구조적 귀결.
2. **중심 구간 과잉폭**: p25–p75가 h1 0.517·h63 0.520 (명목 0.50) — 혼합 분산 팽창
   (E8에서 실측된 Cramér 분산항 w(1−w)d̄)의 잔재.
3. **장기 배리어 확률화 취약**: first_touch Brier h63 0.166·log 0.525 — 경로 내부 동학은
   한계분포 교체(B5)가 다루지 못하는 영역.
4. 개선 절대 규모 정체: 장기 손실차 CI90 [−0.00264, −0.00086] — baseline의 ~2% 수준.
5. h1 방향성 0.526 — 단기 위치 신호는 사실상 없음 (기대치 관리: M6 IR −3.4 문헌 정합).

## 5. 연구 그리드 후보 — 다섯 개의 대체 지점 (코드 좌표 포함)

각 후보는 ① 표적 약점 ② 대체 지점 ③ 퇴화 항등(파라미터 0 = E0 비트동일) ④ 기각 선행과의
차별 ⑤ 실패 모드 진단(§6)을 갖춰야 사전등록 자격이 있다. 우선순위 순:

### W1 — 국면조건부 잔차 재표집 (비대칭, 상태 지수형)
- 표적: §3-1 국면 비대칭. 가설: 현재 상태(v_now/v̄ 비율 등 **내생 변동성 상태만** — exog 금지)와
  유사한 국면의 잔차를 과표집하면 2020 과잉/2022 과소가 동시에 줄어든다.
- 지점: 엔진 bootstrap 인덱스 생성(model.py:188~194) 또는 B5 z-풀 `keep` 마스크(L464)에
  상태 가중 w_i(state) 도입. 격자: 가중 강도 κ∈{0(항등), .5, 1}, 상태 정의 1종 고정.
- 차별: B1/E11은 **대칭 시간 감쇠**(모든 국면 동일 φ) — 이것은 **상태 유사도 가중**으로
  방향이 다르다. 단 EWMA devol/revol이 이미 변동성 조건화를 수행하므로 증분은 겸손히 기대.
- 리스크: 유효 표본 축소 → 꼬리 잡음. 진단 필수.

### W2 — K-성분 발생기 혼합 (2성분 하드스위치의 일반화)
- 표적: §3-2 중심 과잉폭 + CRPS 정체. `mixture_quantile_function`은 이미 임의 가중 점질량
  혼합이라 {엔진, FHS, historical, block_bootstrap} K성분화가 자연스럽다
  (backtest.py:158~172의 교체→가중 편입, model.py:342 시그니처 일반화).
- 격자: 사전등록 고정 가중 3세트만 (탐색 최소화 — E8의 Cramér 정확식으로 후보별
  CRPS-폭 트레이드오프를 **실행 전 계산**해 밴드 예상 위반 세트는 등록에서 제외).
- 차별: E8은 2성분 w 확대 — 이것은 성분 추가로 분산항 구조가 다름.

### W3 — 상태의존 블렌드 w(state)
- 표적: §3-1·2. 지점: backtest.py:179 한 줄(`blend_weight_by_horizon` 조회) — w를
  사전등록 함수형 w(state)=clip(w₀+γ·(state−1), [.5,.9])로. 채점 인프라 무변경
  (원점 시점에 w 확정이면 Cramér 정확식 그대로 성립).
- 격자: γ∈{0(항등), ±1단계}. 가장 침습이 작고 E8/E9의 트레이드오프를 국면별로 재배분.

### W4 — 재보정 맵 고도화 (국면 층화 포함)
- 표적: §3-2 중심 과잉폭. 지점: recalibration_levels(model.py:389~413)의 경험 quantile map을
  isotonic(PAV)/beta calibration으로 — 계약이 이미 `isotonic_monotone`으로 명명한 자리.
  선택지: 국면 2층(고/저변동) 분리 PIT 이력.
- 경계: E9 교훈 — 국면 무차별 강화는 위기 꼬리를 자른다. 층화 없는 강화 세트는 등록 금지.
  워밍업 공허성(성숙 104 규칙상 2007~09 비활성 → GFC 검정 공허) 명시 의무.

### W5 — 단기 지평 아키텍처 (h1·h5 FHS 확장) [저순위·저기대]
- 표적: h5 cov 0.790(살짝 과소)·h1 중심 과잉. 지점: fhs_horizons에 {1,5} 추가는 config
  한 줄 — 단 h1 창합=일간 수익 그 자체라 FHS 이득이 이론상 얇다. 정직한 기대치: 중립.
- 가치: "단기는 왜 그대로 뒀나"에 대한 실측 답을 원장에 남기는 것 자체.

**음성 목록(등록 불가)**: 모든 tilt류(E7), 대칭 기간구조(B1·E11), 국면 무차별 재보정
강화(E9), exog 추가(V9 전체), DL/학습 가중, first-touch 전용 경로 모델(경로 동학 개편은
V10 범위 밖 — 필요하면 V11 의제로 명시).

## 6. 사전등록 진단 의무 (V9에서 이월·강화)

채택 판정 전 모든 후보에 대해:
1. **확산형 노이즈 진단**: 악화 원점 비율·상위 1% 절사 후 쌍대 평균 부호 (E2 패턴 검출).
2. **집중형 진단**: 상위 10원점 기여율·최대 단일 원점 기여 (2008-09-26형 폭주 검출).
3. **국면 분해**: GFC·유로위기·평시 (서브윈도 사용 시 워밍업 공허 구간 명시 —
   2007-08 장기지평 쌍대 94~96% Δ=0 실측의 재확인 의무).
4. **MDE 공표**: 창별 se(전체창 0.0008 / 서브창 0.0006)와 검출 가능 최소 효과.
5. W2는 추가로: Cramér 정확식 사전 계산치 vs 실측 일치 검증 (E8 선례 — 소수점 일치했음).

## 7. 평가 구조 — 봉인창 문제 (핵심 미결, 사용자 결정)

V8이 2019+를 봉인 해제·공개했으므로 V10의 창 구조는 자명하지 않다:

- **옵션 A — V8 구조 승계** (design 2007–14 / holdout 2015–18 / sealed 2019+):
  절차 연속성 최상. 단 봉인창 오염이 2겹(V2·V8 공개 성적)이며, §3의 1순위 표적(2020·2022
  국면)이 **개발 중 관측 불가** — 표적을 못 보고 표적을 고치는 연구가 된다.
- **옵션 B — 창 전진** (design 2007–18 / holdout 2019–22 / sealed 2023+):
  표적 국면(2020·2022)이 홀드아웃에 들어와 1회 검증 가능. 단 sealed 2023+는 ~190
  주간원점으로 현행 minimum_origins 250 미달 → **봉인 요건 완화 없이는 봉인 불가**
  (완화는 금지). 봉인을 수년 뒤로 미루는 선택.
- **옵션 C — 하이브리드**: 옵션 A 창 + "2020·2022형 국면 프록시"를 design 창 안에서 정의
  (2008 급락·2013 테이퍼 긴축을 대리 국면으로 사전등록). 봉인 즉시성 유지, 대리 타당성
  caveat 필요.

초안 권고: **C를 1차(빠른 반복), B를 봉인 시점 결정으로 병기** — 즉 개발·홀드아웃은 C로
진행하되, 봉인은 2023+ 원점이 250개를 채우는 시점(약 2027-10)까지 유예하는 경로를
기본안으로 제시한다. 결정은 V10-D2.

## 8. 예산·단계·정지점 (제안)

- 예산: design 24회(W1~W5에 사전 배분 6/6/4/4/2 + 예비 2), holdout finalist 3, 봉인 1회.
- 단계: G0 계약 draft+E0 항등 재현(비트동일 테스트) → G1 W1·W3(최소 침습 우선) →
  G2 W2·W4 → G3 champion 정지(사용자) → 봉인(옵션 B/C 결정에 따름) → 표면 배선은
  P1(#116/#122/#133) 패턴 재사용.
- stop-loss: 사전등록 6회 소진 시점에 최고 후보 쌍대 개선 < +1%면 중단·보고
  (V8 stop-loss 계보 승계).
- 구현 격리: `src/ai_fc/timeseries_v10/` 신규 패키지, V8 함수 read-only import
  (V9 래퍼 선례) — 단 W1·W4는 V8 함수 **대체 구현**이 필요하므로 V10 패키지 안에
  포크된 사본을 두고, E0 항등 테스트가 사본과 원본의 비트 동일을 강제한다
  (사본 드리프트 방지 — 원본 파일 해시를 계약에 핀).

V10-D1의 초안 권고가 "보류"인 이유를 정직하게: V8은 이미 게이트를 통과해 라이브로
운영 중이고, V9의 교훈은 "이 아키텍처 계보에서 싼 개선은 남아 있지 않다"였다. V10은
성공 확률이 불확실한 중규모 연구(수십 시간 계산+검증)이며, 그 동안 쌓이는 V8 shadow
해소(주간)가 어차피 V10 설계의 가장 좋은 추가 증거가 된다. 급할 이유가 없다.

## 10. 초안의 한계 (받는 쪽이 넘어설 지점)

- W1의 상태 정의(내생 변동성 상태)는 1종으로 고정 제안했으나 최적 정의는 미검증 —
  개시 시 G0에서 후보 2~3종의 사전 비교(설계창 밖 통계량만으로)를 권함.
- 옵션 C의 대리 국면 타당성(2013 테이퍼 ≈ 2022 긴축?)은 가정이다 — 국면 유사도의
  정량 근거(변동성·금리 경로 상관)를 G0에서 실측할 것.
- first_touch 약점(§3-3)은 이 초안이 다루지 않는다(경로 동학 = V11 의제) — 의도적 비범위.
