## C. 다음 단계 설계

### C-1 [전제·사전등록] 지속성 기준선 게이트 (V13 계약 개정 제안)
- 문제: 기후는 지속 계열에 약한 기준선. EWMA-logit의 스킬 중 "당일 VIX 수준만으로 얻는 자명한 부분"을 분리해야 base rate 공급자로서의 정직한 라벨이 된다.
- 등록: 기준선 **PB = logit(P | VIX_t 수준 단독)** (1 피처, research_train 적합). 지표: 쌍대 Brier(EWMA − PB), 양방향, 블록부트 CI90, 건전 y-블록 귀무. **채택 문턱은 "PB 대비 비열화"(CI90 상단 > 0 아님)** — PB를 못 이겨도 EWMA 폐기가 아니라 "PB=champion"으로 교체(더 단순한 모형 우선). 백테스트 0회(기존 원장 재분석).
- 산출: 9셀 EWMA−PB 표 + champion 확정(EWMA 또는 PB).

### C-2 [핵심] V13-D3 홀드아웃 1슬롯 소모 — 조건부 권고
- 소모 조건(전부 사전등록·결과 전 커밋): ① C-1 champion 확정 ② h63 reliability를 **calibration 역할 cross-fit isotonic**으로 처리(파생 확률층, V8 무접촉) ③ 홀드아웃 게이트 = 기후 대비 CI90 하한>0 **AND PB 대비 비열화** AND reliability 보고 ④ finalist = champion 1개(3슬롯 중 1).
- 소모 근거: 재현 개연성이 높다는 것은 "슬롯이 아깝다"가 아니라 **"싸게 첫 표본외 홀드아웃 긍정을 확보한다"**는 뜻. 그 긍정이 EXIT 트리거 base rate 피드(1차 목표)를 정식 개통하는 유일한 관문이고, 실패해도 2슬롯 남는다.
- 보류가 옳은 경우: C-1에서 EWMA가 PB 대비 열위이고 PB조차 기후 대비 CI가 0에 근접할 때(그땐 정보가 "자명"을 넘지 못함).

### C-3 [배선] V13 파생층 = 이벤트 질문 base rate 레이어 (가격 카드 아님)
- 홀드아웃 PASS 후에만. 대상: EXIT 트리거 질문 중 변동성 사건형(VIX≥K by D, RV>θ) — `physical_event` 공간에 **base rate 참조**로만 주입, LLM 예측과 산술 결합 금지(기존 원칙). 라이브 가격 카드(V8 research_reference)에는 미표시 유지(V12-D3 (a)와 동일 논리 — 이름 충돌 회피).

### C-4 [데이터·리드타임] 구매·발송은 사용자 — 우선순위 정직화
- **CBOE DataShop QQQ 질의 발송(V12-D4)**: 리드타임 독립 → 지금 발송 권고. 옵션 표면(IV·스큐)은 변동성 사건(V13)에도 가격 꼬리에도 유일한 미검증 정보집합.
- **FirstRate(~$300)**: V13 결과(richer 무익)로 보아 일중 RV가 변동성 사건 스킬을 더 올릴 여지는 작다. 실질 가치는 **보류된 경로 생성기 트랙(T-B, 일중 되돌림 구조)**에 있으므로 C1(옵션) 회신·V13 홀드아웃 결과 뒤로 순위 조정. 구매 자체는 저비용이라 반대하지 않음.
- 약관 재확인(§A-3): FirstRate 표시 허용 조항·Cboe §2b·QQQ 오버레이 — 소유자가 원문 캡처를 DECISIONS 12-8 형식으로 기록 후 진행.

### C-5 [보류 트랙] V12b 경로 생성기 — 폐기 아닌 파킹
- 재개 조건: 일중 데이터 확보 + 사전등록(블록 재표집 ℓ_z / AR(1) φ, ℓ_z=1·φ=0 = E0 항등) + **건전 y-블록 귀무**(T-A 무관) + CRPS 게이트 무손상 제약. 기대 이득은 VR(5)=0.874 기준 소폭 — 우선순위 낮음.

## D. 거버넌스 권고 (신규 4건)
1. **홀드아웃 소모 절차 명문화**: 사전등록 커밋 → 사용자 승인 로그 → 1회 채점 → 결과 무관 원장 append. 자동화 밖 유지.
2. **"자명 기준선" 규칙**: 지속 계열 표적(변동성·금리 등)은 기후 외에 **당일 수준 단독 기준선**을 계약에 필수 등록 — "기후 대비 통과"만으로 champion 선언 금지.
3. **V13 계약 개정 시점**: 홀드아웃을 보기 전인 지금이 사후 완화 없이 임계·기준선을 고칠 마지막 시점(V12-D2와 같은 논리).
4. **main 잠금 우회 금지 규칙**: 워크트리 잠금이 걸린 main에는 리프스펙 FF 푸시 포함 어떤 우회도 금지 — 잠금 소유자 해제 또는 명시 인계 후에만. 이번 우회는 DECISIONS에 사후 기록.
