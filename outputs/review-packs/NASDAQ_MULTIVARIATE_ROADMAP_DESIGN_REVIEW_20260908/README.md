## 이 팩이 만들어진 방법 (투명성)

본문은 단일 저자가 아니라 다중 에이전트 합성이다: 저장소 원문을 읽는 리더 4명(상태·데이터·방법론·반증) → 서로 다른 렌즈의
설계자 3명(고전 계량 / 현대 ML·DL / 정보집합 확장·이벤트 확률) → 방향마다 회의론자 2명(기반증·거버넌스 / 데이터·문헌) →
심판 1명(채점·단계 지도) → 작성자 → 완전성 비평 → 수정 1회. 인용은 에이전트 지식 기반이며 `[미검증]` 표시가 있는 항목은
검토관이 실재 여부를 확인해야 한다. 저장소 수치는 원문 파일(A~F)에서 재계산 가능해야 한다 — 불일치가 있으면 팩 원문이 정본.
