# 외부 검증 요청 — V10 동결 결정에 대한 적대적 재검토

당신은 NASDAQ 다변량 시계열 게이트 캠페인의 **독립 검증관**이다. 아래 결정이 옳은지,
특히 **비가역 홀드아웃 슬롯을 소모하지 않기로 한 판단(FREEZE_V10)** 이 정당한지를
적대적으로 재검토하라. 결론을 그대로 승인하지 말고, 반대 입장(홀드아웃을 소모했어야 한다)을
최대한 강하게 세운 뒤 그것이 증거에 의해 반박되는지 확인하라.

## 배경 (3세대 캠페인의 종결점)

- **V8**: 봉인 GATE PASS·라이브 배포 완결 = 현행 프로덕션 챔피언. V2 엔진(정상 블록 부트스트랩
  잔차 × EWMA devol/revol) + B3~B5 계층.
- **V9**: V8 위에 외생 변수 열 추가(M2SL 유동성·TOTCI/TOTLL 신용·WRMFNS MMF·VXN/VIX 스프레드)
  6종 전부 무효익 → 동결.
- **V10**: 분포 계층 자체를 재설계. V8 model/backtest를 포크해 5개 축을 사전등록:
  - W1 상태조건부 재표집 FHS (κ 가중), W2 K성분 혼합, W3 상태의존 블렌드 가중 (γ),
    W4 재보정 고도화 (isotonic/2계층), W5 단기 수평선 FHS 확장.
  - E0 = γ/κ 등 전부 비활성 = V8과 **비트 동일** 항등 기준선(대조군).

## V10 실측 결과 (design 창 2007-2014, 417 origin)

단독 격자 12개 실행 후 계약 stop-loss(12회 소진·최고 <+1%) 작동. **유일 챔피언 = W3 γ=−0.10**:
- E0 대비 쌍대(정상 블록 부트스트랩 ℓ=13, B=2000): **+0.000277, CI90 [+0.000016, +0.000679]
  = 상대 +0.64%** (h63 +0.71%, h21 +0.50%; h1/h5 무변화).
- 프록시 전 항목 PASS. h63 커버리지 상한 마진 +0.0007 → +0.0175.
- γ=−0.20은 평균 동일(+0.000278), CI 하한 −0.000001 (평탄부).
- 나머지 축(W1·W2·W4·W5)은 전부 0/음 또는 커버리지 대역 이탈로 폐기.

## 내려진 결정 = FREEZE_V10 (검증 대상)

6개 독립 렌즈의 적대적 검증(`reports/CHAMPION_ADVERSARIAL_VERIFY_20260903.json`) 결과:
- **3 robust = 무결성 렌즈**: 헤드라인이 소수 9자리까지 정직하게 계산됨(재현·E0 항등·커버리지-CRPS
  동시개선 정합). 조작·오염 없음. 그러나 **일반화는 보장하지 않음**.
- **3 fragile = 일반화 렌즈**, 전부 동일 결론으로 수렴:
  1. 하위기간: GFC 78원점(18.7%)이 총델타 **83.8%** 견인. GFC 제거 시 +0.64% → **+0.13% (5배 붕괴)**.
     2007-2010 반기 CI가 0 관통.
  2. 원점 집중: 상위 5% 원점 제거만으로 mean **부호 반전**(−0.0000115). h21은 사실상 노이즈.
  3. γ 용량반응: γ=−0.10=−0.20 동일성은 매끄러운 용량반응이 아니라 2008-10~12 GFC 정점
     **7주의 0.5하한 클립 포화가 엣지 58%** 운반. 내부 비클립 구간 이득은 0~음.
- 판정: 이득은 **실재하나 소수 GFC 위기원점 의존 인공물**. 홀드아웃 창(2015-2018)엔 그 위기가
  없어 메커니즘 미발화. 홀드아웃 게이트(베이스라인 대비 +2% AND paired CI 상한 ≤0) 통과확률 <2% 추정.
- 따라서 **비가역 결선 슬롯(3개 중 1개)을 거의 확실한 실패에 소모하지 않고 동결**, 슬롯 3/3 보존.

## 당신이 검증할 것 (독립 재계산 자료 첨부)

첨부 `data/runs/`에 챔피언·E0·γ=−0.20 런의 원본 스코어(각 원소: date·horizon·model_crps 등)가 있다.
쌍대 레시피: 각 origin에서 h∈{21,63}의 (E0 model_crps − champion model_crps) 평균 → origin별 평균
→ 정상 블록 부트스트랩(ℓ=13, seed=20260902, B=2000)으로 CI. 다음을 스스로 재계산·판정하라.

1. **FREEZE가 옳은가?** 홀드아웃을 소모했어야 한다는 반대 논거를 최강으로 세워라. 예: 무결성
   렌즈가 robust하고 프록시가 전부 PASS인데 왜 표본외 시험 기회를 포기하나? 이 반론이 fragile
   렌즈 3종의 GFC-집중 증거에 의해 실제로 반박되는지 확인하라.
2. **GFC 인공물 진단이 견고한가?** 상위 5% 제거 시 부호 반전, GFC 제거 시 5배 붕괴, 클립 포화
   7주가 엣지 58% — 이 수치들을 첨부 데이터로 독립 재현하라. 하위기간 분할·leave-out 방식이
   결론을 부당하게 몰지 않았는지(예: GFC 창 경계 선택 민감도) 점검하라.
3. **홀드아웃 재현확률 <2% 추정이 방어 가능한가?** 2015-2018에 클립 포화를 촉발할 국소 vol
   스파이크(예: 2015-08 위안화·2018-02 volmageddon·2018-12 급락)가 실제로 얼마나 있는지,
   그것이 GFC급 엣지를 재현할 수 있는지 논증하라. 추정이 과도하게 낙관/비관인지 판정하라.
4. **놓친 대안이 있는가?** 동결 대신 (a) 조합 격자(W3+다른 축), (b) stop-loss 면제 후 W5_h1_h5,
   (c) γ 중간값(−0.05/−0.15) 추가 — 각각이 GFC 의존을 피하면서 이득을 낼 수 있는지, 아니면
   같은 인공물을 재생산할 뿐인지 평가하라. (계약상 이들은 미등록이므로 새 사전등록 필요.)
5. **차세대 방향 제언**: 동결 문서 §5는 "위기국면이 아닌 평시에도 정보를 갖는 상태신호 재정의"를
   유일 잔여 여지로 제시한다. 이 방향이 타당한지, 구체적으로 어떤 상태 프록시(vol 수준이 아닌
   vol의 예측가능한 구조 변화 등)가 GFC 의존 없이 h63 CRPS를 낮출 수 있을지 설계 수준에서 제언하라.

## 거버넌스 제약 (반드시 준수)

- 홀드아웃·봉인 평가는 **비가역**이며 사용자 명시 승인 문자열 없이 실행 불가. 당신은 재계산·판정만
  하고 어떤 홀드아웃/봉인도 실행하지 말 것.
- V8/V2 봉인 파일(해시 e3ff2fdb…) 무수정. 원장·예측 파일 무수정. 그리드 밖 조합 실행 금지.
- 산출: 위 5개 질문에 대한 판정과 근거 수치, 그리고 FREEZE **유지/번복** 최종 권고 1건.
