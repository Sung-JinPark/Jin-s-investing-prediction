# 외부 검증 요청 — V12 이벤트 확률화 부정 결과 독립 반박

당신은 NASDAQ 게이트 캠페인의 **독립 검증관**이다. V12 일요일 Opus 루프가 "V8 first_touch(−10% 접촉)
확률을 재보정해 표본외로 전이시키는 것은 불가능하다"는 부정 결과를 냈다. 이 결론과 그 위에 세워진
사용자 결정 권고를 **적대적으로 재검토**하라. 결론을 그대로 승인하지 말고, 반대 입장(재보정이 가능하다/
검정이 부당하게 죽였다)을 최대한 강하게 세운 뒤 첨부 증거로 반박되는지 확인하라.

## 배경 (정본: reports/SUNDAY_LOOP_FINAL_REPORT.md)

- 표적 = V8이 이미 산출하는 first_touch_probability(−10% 접촉, 417 origin × h21/h63, 창 2007-2014).
- 사전등록 4맵 × 2지평 = 8셀, 채택 = 전반↔후반 **양방향** Brier 개선 CI90 하한>0. 결과: 채택 0/8.
- 음성대조 T5(p 셔플 귀무)에서 T1 통과율 0.254 > 문턱 0.1 → 검정 기계 자체 결함.
- 과신은 자유파라미터 0개 반사원리 공식도 같은 방향(더 강하게) → 표적의 성질.

## 검증 자료 (독립 재계산 가능)

- `data/diagnostics/transfer_results.json` — 8셀 양방향 전이 원자료(CI90·귀무 통과율).
- `data/diagnostics/first_touch_diagnostic.json`·`reflection_baseline.json` — Brier·BSS·상위분위 gap.
- `data/prereg/hypotheses.json`·`prereg_commit_log.json` — 결과 전 커밋된 등록부(해시 포함).
- `contract/multivariate_timeseries_v12.draft.yaml` — 게이트 산술(BGK 구속 기준선).
- `reports/verdict_recompute.json` — S1 세 동결 독립 재계산치.

## 검증할 것

1. **부정 결과가 옳은가?** "재보정이 가능하다"는 최강 반론을 세워라. 특히 T4 두 셀은 CI90 하한=0
   (지평 단조 위반 0건이라 무비용·무효과)인데, 이를 '미달'로 본 판정이 타당한가. 관대한 5셀(귀무
   통과율 0.5~0.79)에서 미달을 "검정력 부족"으로 설명할 수 있는가(§7-1 반박 검토).
2. **T5 해석이 견고한가?** "T5 실패면 미달도 무효 아닌가"라는 반론(§7-2)을 공격하라. 귀무 아래
   통과 0이라는 사실이 정말 미달을 지지하는지, 아니면 검정 기계 전체가 무의미해 판정 자체를 못 하는지.
3. **D2 타이밍 주장이 옳은가?** "지금(후보 0)이 게이트 임계를 사후완화 없이 정할 마지막 시점"이라는
   논리(§7-7)가 통계적으로 타당한가, 아니면 임계를 지금 박는 것이 오히려 미래 유연성을 부당하게
   제약하는가. 게이트를 '등록하되 무장 안 함(armed=false)'이 정직한 형태인지.
4. **과신=표적 성질 주장의 재현.** first_touch_diagnostic + reflection_baseline로 반사원리 공식이
   V8과 같은 방향으로 과신하는지(순위상관·상위분위 gap CI90) 독립 재계산하라. σ(EWMA .97) 선택이
   결론을 몰지 않았는지.
5. **S1 재확인 + V10-D7 정정.** verdict_recompute.json으로 세 동결 유지 판정을 재현하고, "V10 조합격자
   스킵 사유가 사실과 달랐다"(적격 축·최상조합 +1.147%)가 맞는지, 그럼에도 채택 가능성이 낮다는
   판정(상위5% 제거 후 CI하한 음·홀드아웃 +2% 미달)이 타당한지.
6. **다음 경로 제언.** 재개의 첫 전제(T5 실패한 검정 기계 수리 = 대안 귀무 확정)를 어떻게 설계할지,
   그리고 "다른 데이터"(옵션 표면·일중, D4)가 컴플라이언스 벽을 넘을 실질 경로가 있는지 설계 수준 제언.

## 정직성 기준

이 캠페인의 방법론 핵심은 "in-sample 통과 ≠ 채택; 표본외 양방향 전이가 진짜 필요조건"이다. 재보정이
가능하다는 대안을 제시하려면 반드시 전반↔후반 **양방향** 전이로 검증한 뒤 제시하라. 결과 본 뒤 귀무·
가설 교체는 등록부 위반이다.
