# NASDAQ 다변량 게이트 — 세 트랙(V9·V10·V11) 동결 종합 (2026-09-04)

## 0. 한 줄 결론

V8 봉인 승자 위에서 개선을 시도한 **세 트랙이 모두 동결**됐다. 서로 다른 세 각도 — 외생 변수 추가(V9),
분포 계층 재설계(V10), 평시 직교 상태 신호(V11) — 가 전부 같은 벽에 도달했다: **일간 NASDAQ 분포에는
V8이 이미 포착하지 못한, 표본외로 전이되는 개선 여지가 없다.** 효율적 시장 사전(prior)이 세 번 독립적으로
확인됐다. 프로덕션 챔피언은 V8 그대로 유지된다.

## 1. 공통 기준선과 거버넌스

- **프로덕션 = V8** (봉인 GATE PASS·라이브 배포 완결). V2 엔진(정상 블록 부트스트랩 잔차 × EWMA
  devol/revol) + B3~B5 계층(FHS·정적 블렌드·PIT 재보정).
- 세 트랙 공통: V8/V2 봉인 파일 무수정(해시 `e3ff2fdb64ac71c0…`), forecasts/·calibration/ 무접촉,
  main 직접 커밋 0, 시크릿 미로드, 홀드아웃/봉인은 명시 승인 없이 미실행. design 창 2007-2014.
- 공통 개선 척도: **E0 대비 쌍대 CRPS** (E0 = 신규 요소 전부 비활성 = V8과 비트 동일 항등 기준선),
  정상 블록 부트스트랩(ℓ=13, B=2000) CI90. 게이트 결정 지평 = h21·h63.

## 2. V9 — 외생 변수 추가 (동결)

**가설**: V8 위에 거시·신용·유동성 열을 더하면 일간 분포가 날카로워진다.
**실행**: 단독 ablation 6종 (예산 7/24), 신규 피처는 first-release ALFRED vintage로 PIT 정렬.

| 실험 | 채널 | E0 대비 장기 쌍대 | CI90 | 판정 |
|---|---|---|---|---|
| E1 | M2SL 월간 유동성 | +0.000014 | [−0.000000, +0.000028] | 무효익 |
| E2 | TOTCI 주간 C&I 신용 | +0.000043 | [+0.000019, +0.000074] | **유의 악화** |
| E3 | TOTLL 주간 총여신 | +0.000004 | [−0.000002, +0.000009] | 무효익 |
| E4 | WRMFNS 주간 소매 MMF | +0.000003 | [−0.000016, +0.000022] | 무효익 |
| E5/E6 | VXN/VIX 스프레드(서브창) | 장기 +0.019% (CI 0 포함) · 단기 **+1.65% 악화** | | **채널 폐기** |

**결론**: 전부 무효익 또는 악화. VXN 스프레드는 |ρ|=0.011로 기존 exog와 직교인데도 무효익 —
정보 중복이 아니라 **순수 노이즈 주입**. 사전등록 분기(R9-A)대로 대안 D = 동결. finalist 3/3 보존.

## 3. V10 — 분포 계층 재설계 (동결)

**가설**: 상태 조건부로 분포 계층(재표집·혼합·블렌드·재보정·단기)을 바꾸면 개선된다.
**실행**: V8 model/backtest 포크(E0 비트 항등 검증) + W1~W5 5축, 사전등록 단독 13개 중 12개 실행(마지막 1개는 stop-loss로 미실행), 계약 stop-loss
(12회·최고<+1%) 작동. **유일 챔피언 W3 γ=−0.10** (상태의존 블렌드): E0 대비 +0.000277
CI90 [+0.000016, +0.000679] = **+0.64%**, 프록시 전 항목 PASS.

**6렌즈 적대적 검증 → GFC 위기원점 인공물**:
- GFC 78원점(18.7%)이 총델타의 **83.8%** 견인. GFC 제거 시 +0.64% → +0.13% (5배 붕괴).
- 상위 5% 원점 제거만으로 mean **부호 반전**.
- 양의 엣지 58%는 2008-10~12 GFC 정점 7주의 0.5하한 **클립 포화**가 운반(매끄러운 용량반응 아님).
- 홀드아웃 창 2015-2018엔 그 위기 부재 → 메커니즘 미발화. 게이트(+2%) 통과확률 <2% 추정.

**결론**: 이득이 소수 위기원점 의존 인공물. **홀드아웃 소모 기각·동결**, 결선 슬롯 3/3 보존.

## 4. V11 — 평시 직교 상태 신호 (동결)

**가설**: V10 실패 원인은 상태 신호가 위기에만 반응한 것 → 평시에도 직교 정보를 갖는 상태 신호면 개선.
**실행**: **값싼 직교 진단**(기존 E0 데이터, 백테스트 0회)으로 포크 이전에 필요조건 스크린. 9 후보 프록시 ×
3 결함지표 × 2 수평선, calm=비위기 하위 80%. 사전등록 프로토콜 결과 보기 전 고정.

**진단**: 4검정 통과 — P1 21일 모멘텀→PIT 위치(h21) Δ=−0.12 CI[−0.192,−0.035] ρ=−0.19(vol직교);
P7 growth→CRPS. P9 음성 대조군 미통과(위양성 통제 정상).

**6렌즈 적대적 검증 → 두 독립 사망 조건**:
- **Exploitability 실패(결정타)**: P1은 in-sample real·vol직교·leave-out/GFC 강건(V10 킬러 통과)이나,
  표본외(2007-10 적합→2011-14 적용) CRPS **+0.97% 악화**(부트 96% 신뢰)·역방향 +1.49%·상수 recenter도
  손해. 관계가 2013-14 저변동 tail에만 집중, 다른 국면 부재 → 전이 원천 불가. **V10식 '커버리지-only'
  함정 재현.**
- **다중검정 위양성**: 4통과 = 순열 귀무 68~75퍼센타일, P(≥4)=0.25~0.32. 우연 수준. 유효 독립신호 2개뿐.

**결론**: real+exploitable 후보 0 → 동결. **값싼 진단이 25~30분×N 백테스트 격자 + 홀드아웃 소모를
사전 차단**했다.

## 5. 세 트랙을 관통하는 판정 논리 — 왜 셋 다 동결이 옳은가

| 축 | V9 | V10 | V11 |
|---|---|---|---|
| 무엇을 추가/바꿨나 | exog 열 | 분포 계층 상태조건화 | 평시 직교 상태 프록시 |
| in-sample 개선 | 없음(무효익) | +0.64%(있음) | 있음(PIT Δ=−0.12) |
| 실패 지점 | 애초에 신호 없음 | 이득이 **GFC 인공물** | 이득이 **표본외 전이 실패** |
| 되돌릴 수 없는 비용 소모 | 0 (동결) | 0 (홀드아웃 미소모) | 0 (백테스트 0회) |

**핵심 방법론 교훈**: in-sample 재현·vol직교·leave-out 강건('무결성'+'강건성' 렌즈)이 곧 채택 근거가
아니다. **진짜 필요조건은 표본외 전이 가능성(exploitability)**이고, 그것은 (a) 홀드아웃 소모 전 값싼
반사실(전반부 적합→후반부 적용, CRPS 부호까지)로, (b) 다중검정 귀무로 먼저 걸러야 한다. V10은 홀드아웃
소모 직전에, V11은 포크 착수 직전에 각각 이 원리로 값싸게 멈췄다.

## 6. 캠페인 함의와 잔여 여지

- 세 각도(외생 변수·분포 계층·평시 상태)가 독립적으로 같은 벽에 도달 → **일간 NASDAQ 수익률 분포에는
  V8이 못 잡는 안정적·전이가능한 조건부 구조가 없다.** 효율적 시장 사전의 강한 확인.
- V8~V11 계보의 미세조정 경로는 **소진**. 잔여 여지는 계보 밖:
  1. **다른 데이터**: 일중·틱·옵션 표면(암시 변동성 표면의 형태 정보) — 일간 종가로는 안 보이는 구조.
  2. **다른 표적**: 일간 분포 예측이 아니라 **프로젝트 1차 목표인 이벤트 확률화**(포트폴리오 EXIT 트리거의
     기한·임계값 해소가능 질문) — CLAUDE.md 목표 서열 1차. 다변량 시계열은 그 base rate 공급 부품이지
     목표 자체가 아니다.
  - 둘 다 새 트랙·사용자 결정 영역. 현 계보의 추가 미세조정은 권고하지 않는다.
