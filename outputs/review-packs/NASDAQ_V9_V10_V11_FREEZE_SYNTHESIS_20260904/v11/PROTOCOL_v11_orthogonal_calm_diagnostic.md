# V11 트랙 — 값싼 직교 진단 프로토콜 (사전등록, 2026-09-03)

## 0. 목적과 정직한 한계

V10은 유일 챔피언(W3 γ=−0.10)이 **GFC 위기원점 인공물**로 판정돼 동결됐다. 원인: V10 상태 신호
(EWMA 분산비)는 극단 변동성에서만 baseline과 달라지고 평시엔 s≈1 → V8과 동일. 이득이 위기에만 몰림.

**V11 가설**: 평시(비위기) 구간에서도 V8 예측의 남은 구조를 포착하는 **직교 상태 프록시**가 존재하면,
홀드아웃·미래가 사는 평시 구간을 개선할 수 있다.

**이 진단이 할 수 있는 것과 없는 것 (명문화)**:
- 이 진단은 **필요조건 스크린**이다 — 평시에 in-sample 직교 신호조차 없으면 표본외 이득은 확실히 없다.
  그런 경우 V11을 **값싸게 중단**(포크·격자 25~30분×N 회피)한다.
- 이 진단은 **충분조건이 아니다** — 통과해도 표본외 이득을 보장하지 않는다. 통과 = "더 비싼 시험
  (포크+홀드아웃)을 할 자격"일 뿐. V10의 in-sample +0.64%도 결국 인공물이었음을 기억한다.
- 5원칙 5번(백테스트 금지)의 **명문화된 예외**(결정론 수치 모델의 과거 적합) 적용. Caveat: 후보
  프록시 목록·계산창·컷오프 선택이 정점 지식을 간접 내포할 수 있음. 이 진단은 캘리브레이션 표본이
  아니라 설계 참조다. LLM 개입 평가에는 이 예외를 적용하지 않는다.

## 1. 창·데이터 (design 창에서만, 홀드아웃·봉인 무접촉)

- 진단 창 = V8/V10 **design 창(2007-01~2014-12)** origin만. 홀드아웃(2015-2018)·봉인(2019+) 절대 미열람.
- 원본: E0(=V8 항등) design run 스코어 `data/timeseries_v10/runs/dev_tsv10-exp-a38c2154e2e9bc1705b5.json`
  — origin별 h∈{21,63}의 actual_log_return·p10/p25/median/p75/p90·model_crps.
- 상태 재료: V8 `_development_bundle` 5 내생(nasdaq_return, vix_change, dgs2_change_bps,
  curve_change_bps, dollar_change) + 3 외생(growth_factor, inflation_factor, dfm_age_since_release).
  모든 프록시는 **trailing-only**(자기 시점까지) — PIT 안전.

## 2. 예측 결함 신호 (origin별, h=21·63)

E0 5분위로 예측 CDF를 구성(구간 선형보간·꼬리 선형)해 각 origin에서:
- **PIT** u = F̂(actual) ∈ (0,1). 잘 보정됐으면 u~Uniform. u−0.5 = 위치 미보정, |u−0.5| = 꼬리 편중.
- **위치 오차 부호** sign(actual − median).
- **IQR 표준화 잔차** (actual − median)/(p75−p25) — 척도 검정.

## 4. 평시(calm) 정의 — 직교의 핵심

- 위기 상태 프록시 = V10 primary(EWMA97 분산비). design 창에서 그 **상위 20% origin = 위기**로 제외.
- 진단은 **하위 80% calm origin에서만** 수행 — V10 상태가 아무것도 하지 않는 구간에서 신호를 찾는다.

## 5. 검정·유의성

각 프록시 P_k에 대해 calm origin에서:
1. **단조 gradient**: calm origin을 P_k 3분위로 나눠 (a) 평균 PIT(u−0.5), (b) 평균 CRPS, (c) 평균
   |u−0.5|의 3분위 간 차를 본다. 상·하 3분위 차 Δ.
2. **유의성**: origin은 자기상관 → **정상 블록 부트스트랩**(ℓ=13, B=2000)으로 Δ의 CI90. 0 배제 시 유의.
3. **직교성**: calm origin에서 |Spearman(P_k, V10 primary)| < 0.30 요구.
4. **하위기간 안정성**: 2007-2010·2011-2014 각 반기에서 Δ 부호 동일 요구.

## 6. 사전등록 통과 기준 (PASS bar) — 결과 보기 전 확정

프록시 P_k가 **통과**하려면 calm design origin에서 4조건 **모두** 충족:
- (a) PIT-위치(u−0.5) 또는 CRPS에 대한 상·하 3분위 Δ의 블록부트 CI90가 **0 배제**,
- (b) |Δ|가 사전 바닥 초과 — PIT-위치는 |Δ(u)| ≥ 0.03, CRPS는 상대 |Δ| ≥ 0.5%(E0 장기 CRPS 대비),
- (c) |Spearman(P_k, V10 primary)| < 0.30 (직교),
- (d) 2007-2010·2011-2014 부호 동일.
- P9(음성 대조군)가 통과하면 진단 자체를 의심(다중검정 위양성) — 재점검 트리거.

**판정**:
- **≥1 프록시 통과** → V11 진행 자격. 통과 프록시를 대상으로 적대적 검증(직교·하위기간·leave-out·
  vol-state 재포장 여부) 후, 살아남으면 그 프록시를 V11 포크 상태 신호로 **사전등록**하고 격자 설계.
- **0 통과** → V11 **값싸게 중단**(평시 직교 신호 부재 = V9·V10류 무효익 재현 확실). 동결 문서화.

## 7. 다중검정·위생

- 9개 프록시 × 3개 결함지표 = 최대 27개 검정. 위양성 억제: 통과 기준을 4중(유의+효과크기+직교+안정)으로
  걸고, P9 음성 대조군을 심는다. 통과 프록시는 별도 적대적 검증(워크플로)으로 재확인 — in-sample
  통과가 곧 채택이 아니다.
- 원장·예측·봉인 파일 무수정. 홀드아웃·봉인 미열람. main 직접 커밋 0. 시크릿 미로드.
- 산출: `data/timeseries_v11/diagnostics/orthogonal_calm_screen.json`(전 프록시 수치) + 판정 리포트.

## 8. 이 문서의 지위

이 프로토콜은 **결과를 보기 전에** 커밋된다(V9 챔피언 규칙·V10 큐 사전등록과 동일 위생). 커밋 이후
후보 목록·calm 정의·통과 기준을 변경하지 않는다. 변경이 필요하면 이 트랙을 void하고 새 프로토콜을 연다.
