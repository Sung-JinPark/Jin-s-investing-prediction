## 2. 신규 DB 레이어 감사 — 02 설계서 §1 전제의 실측 결과

**전제("소스가 이번 세션에 실제 수집·정제되었다")는 대부분 성립하지 않는다.**

|---|---|---|
| 신용 TOTCI·TOTLL | 저장소 어디에도 미수집 | 불가 — ALFRED vintage 수집 트랙 선행 필요 |
| 예대율 (TOTLL÷예금) | 분자·분모 모두 미수집 | 불가 |
| MMF 주간 WRMFNS | 미수집 | 불가 |
| MMF 분기 MMMFFAQ027S | 통계 스토어에 있으나 **전량 current-vintage** (1995년 관측의 available_at=2026-08-18) | 불가 — 설계창 PIT 위반 |
| 변동성 VIXCLS | V1 정본 스토어에 있음 — 단 VIX(CBOE)가 이미 V2 번들에 존재 | 신규성 없음 |
| 변동성 VXNCLS·VRP | 미수집/미구현 | 불가 |
