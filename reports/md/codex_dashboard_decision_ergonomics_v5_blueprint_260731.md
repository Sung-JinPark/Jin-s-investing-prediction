# Dashboard Decision Ergonomics v5

작성일: 2026-07-31

대상: GitHub Pages 운영 대시보드

범위: 데이터·예측 로직은 유지하고 UI와 부가기능만 개선

## 1. 감사 결론

현재 대시보드는 브리핑, 질문 비교, MY RADAR, 로컬 메모, 시점 리플레이,
캘린더 저장, 데이터 상태 확인까지 이미 갖추고 있다. 따라서 새 메뉴를 계속
추가하면 제품의 정보 구조만 무거워질 가능성이 크다.

이번 단계의 목표는 기능 수가 아니라 다음 세 가지 사용 흐름을 개선하는 것이다.

1. 첫 화면에서 숫자를 눌렀을 때 무엇이 강조되었는지 바로 이해한다.
2. 예측 목록에서 지금 검토할 질문을 더 빨리 찾고, 다시 방문해도 보던 기준을 유지한다.
3. 시장 경로 그래프를 마우스뿐 아니라 터치와 키보드로도 탐색한다.

## 2. 구현 블루프린트

### A. 홈 Signal Lens

- 네 개의 핵심 신호와 해석 패널을 하나의 콘솔로 묶는다.
- 신호를 선택하면 관련 카드 강조와 함께 `무엇을 뜻하는지`를 한 문장으로 갱신한다.
- 시나리오 확률과 질문별 예측 확률이 서로 다른 체계라는 설명을 기본 상태에 유지한다.
- 결과 영역은 `aria-live`로 제공해 키보드·보조기기 사용자도 변화를 알 수 있게 한다.

성공 기준:

- 버튼을 누른 뒤 강조된 카드가 없어도 이유를 이해할 수 있다.
- MY RADAR가 비어 있을 때도 빈 상태의 의미가 명확하다.
- 첫 화면 높이를 과도하게 늘리지 않는다.

### B. Research Queue Controls

- 예측 목록 상단에 다음 프리셋을 추가한다.
  - 전체
  - 우선 검토
  - 확률 이동
  - 30일 내 판정
  - MY RADAR
- 다음 정렬 기준을 추가한다.
  - 검토 우선순위
  - 판정일
  - 확률 높은 순
  - 변동 큰 순
  - 최신 회차
- 프리셋·정렬·분야·테마·상태는 현재 기기에 저장한다.
- 자유 검색어는 개인정보 성격의 입력이 될 수 있으므로 저장하지 않는다.
- 기존 데스크톱 표와 모바일 카드가 동일한 결과 순서를 사용한다.

우선순위 점수는 판정 임박, 확률 변화 폭, MY RADAR 고정 여부, 활성 상태만으로
계산한다. 새로운 예측값을 만들거나 기존 확률을 변형하지 않는다.

### C. Scenario Chart Scrubber

- 시장 경로 SVG에 포커스와 접근 가능한 설명을 추가한다.
- 포인터 이동·터치·좌우 화살표·Home·End로 주차를 이동한다.
- 선택 주차의 세 경로 값과 변동성 상태를 그래프 아래에 고정 표시한다.
- 차트 강조 필터를 바꾸어도 탐색기가 새 그래프에 맞게 다시 생성된다.
- 기존 hover tooltip은 빠른 확인 수단으로 유지한다.

## 3. 반응형 원칙

- 1280px 이상: 신호 버튼 4개와 해석 패널을 한 줄에 배치한다.
- 태블릿: 신호 콘솔을 위아래로 분리한다.
- 모바일: 프리셋은 가로 스크롤, 정렬은 전체 너비, 차트 판독값은 세로 카드로 표시한다.
- 모든 터치 대상은 최소 44px에 가깝게 유지한다.
- `prefers-reduced-motion`과 기존 움직임 최소화 설정을 그대로 존중한다.

## 4. 검증 계획

- 자기완결 HTML과 용량 예산 테스트
- UI 계약 테스트에 v5 요소와 동작 이름 추가
- 전체 Python 테스트
- 운영 데이터로 대시보드 재생성
- 데스크톱과 모바일 화면에서 프리셋, 정렬, 신호 렌즈, 차트 키보드 탐색 확인
- 콘솔 오류 및 기존 비교·브리핑 기능 회귀 확인

## 5. 다음 단계 후보

이번 구현 이후에도 가치가 남는 후보만 백로그로 유지한다.

1. 과거 혁신 사이클 그래프에도 동일한 고정 판독기 적용
2. 질문 상세의 근거 변화를 회차별 diff로 보여주는 `Evidence Delta`
3. MY RADAR 질문만 묶은 공유용 읽기 전용 뷰
4. 캘리브레이션 표의 기간·분야 드릴다운
5. 데이터 자동 갱신이 연결된 뒤 `지난 갱신 대비 변경 요약` 강화

PWA, 계정 시스템, 서버 저장 메모, 테마 추가는 현재 제품 규모 대비 복잡도가
크므로 우선순위에서 제외한다.
