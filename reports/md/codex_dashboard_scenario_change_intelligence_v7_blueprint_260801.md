# Dashboard Scenario Change Intelligence v7

작성일: 2026-08-01

대상: Jin's Investing Prediction Solution

범위: 기존 예측 산식이나 질문별 확률을 바꾸지 않고, 일별 시장 시나리오 아카이브를
사용자에게 이해 가능한 변화 추적으로 연결한다.

## 1. 감사 결론

현재 사이트는 최신 시나리오 기준일과 세 경로 확률을 명확하게 보여준다. 그러나
7/30과 7/31처럼 스냅샷이 연속으로 쌓여도 사용자는 다음을 직접 계산해야 한다.

- 지수 앵커가 얼마나 움직였는가
- 연말 중앙값과 확률 밴드가 얼마나 달라졌는가
- S1/S2/S3의 무게가 어느 방향으로 이동했는가
- 현재 값이 어떤 과거 스냅샷과 비교된 것인가

새 페이지나 예측 기능보다 `현재값의 변화 맥락`을 기존 홈과 시장 맵에 추가하는 것이
정보 밀도와 학습 비용의 균형이 가장 좋다.

## 2. 벤치마크 원칙

### TradingView

- 참고: https://www.tradingview.com/support/solutions/43000653369-how-are-change-and-change-calculated-in-the-watchlist/
- 변화값은 모호한 실시간 기준이 아니라 직전 일봉처럼 명시된 기준점과 비교한다.
- 적용: 기본 비교 기준을 직전 저장 시나리오로 고정하고 기준일을 항상 표시한다.

### Koyfin

- 참고: https://www.koyfin.com/help/release-notes/v3-67-historic-data-in-watchlist-screener/
- 현재 지표와 과거 지표를 같은 화면에 놓아 일회성 변화와 추세를 구분한다.
- 적용: 최근 스냅샷을 압축된 감사 이력으로 제공하고 사용자가 비교 기준을 선택한다.

### Mercury Insights

- 참고: https://mercury.com/blog/introducing-insights
- 전체 데이터를 반복 나열하지 않고 눈에 띄는 변화와 비교 기간을 먼저 보여준다.
- 적용: S1, S3, 앵커, 연말 중앙값의 변화만 우선 노출한다.

### Linear Audit Log

- 참고: https://linear.app/docs/audit-log
- 변경 이력을 시간순으로 보존하고 최근 이벤트를 탐색 가능하게 한다.
- 적용: 날짜별 시나리오 파일은 정본으로 유지하고 대시보드에는 최대 12개 요약만 싣는다.

### Perplexity Finance

- 참고: https://www.perplexity.ai/finance?tab=markets
- 시장 요약, 주요 변화, 워치리스트를 한 화면에서 계층적으로 연결한다.
- 적용: 독립 메뉴를 만들지 않고 홈 요약과 시장 맵 분석 흐름 안에 변화 모듈을 삽입한다.

## 3. 구현 설계

### A. 압축된 시나리오 감사 이력

`data/scenarios/archive/*.json`에서 최신 12개만 읽어 다음 필드로 축약한다.

- 기준일과 생성시각
- 앵커
- 연말 중앙값·50%·80% 범위
- S1/S2/S3 확률과 대표 종점
- 생성 방법 식별자

전체 경로 배열, 이벤트, 아날로그 값은 반복 임베드하지 않는다. 아카이브가 늘어나도
정적 HTML 용량이 선형으로 커지지 않게 상한을 둔다.

`latest.json`이 손상되거나 사라지면 가장 최근의 유효한 아카이브를 먼저 복구값으로
사용하고, 유효한 아카이브도 없을 때만 7/14 감사용 수동 vintage로 후퇴한다.

### B. Scenario Change 모듈

홈에서는 직전 스냅샷 대비 변화만 간결하게 보여준다.

- 앵커 변화: 절대값과 퍼센트
- 연말 중앙값 변화
- S1 ATH 돌파 경로 변화 `%p`
- S3 조정·횡보 경로 변화 `%p`
- 이전/현재 3경로 분포를 동일한 100% 누적 막대로 비교

시장 맵에서는 최근 최대 11개 과거 기준일 중 하나를 선택해 최신값과 비교한다.

### C. 숫자 기반 해석

자동 문구는 인과관계를 만들지 않고 수치 이동만 요약한다.

- S1 +3%p 이상: `상방 돌파 경로가 확대됐습니다.`
- S3 +3%p 이상: `조정·횡보 경로가 확대됐습니다.`
- 연말 중앙값 절대 변화 250 이상: `연말 가격 중심이 이동했습니다.`
- 그 외: `경로 분포는 큰 변화 없이 유지됐습니다.`

문구 하단에 `저장된 수치 차이 요약이며 원인을 추론하지 않음`을 명시한다.

### D. Model Receipt

시장 맵 변화 모듈 하단에 접을 수 있는 산식 영수증을 둔다.

- 생성 방법
- lookback
- 경로 수와 seed
- 데이터 출처
- fat tail·정책·실적 이벤트 한계

기본은 접힌 상태로 유지해 화면을 복잡하게 만들지 않는다.

## 4. 시각 설계

- 기존 warm white, ink, orange, amber, crimson, teal만 사용한다.
- 카드 상단 6px orange rule로 예측 질문 카드와 구분한다.
- 이전값은 muted, 현재값은 ink, 증가는 orange, 조정 확대는 crimson으로 표현한다.
- 텍스트 크기는 최소 10px 이상, 핵심 변화는 20px 이상을 유지한다.
- 모바일에서는 4개 변화 지표를 2열로 재배치하고 날짜 버튼은 가로 스크롤한다.
- 움직임 최소화 설정에서는 새 애니메이션을 만들지 않는다.

## 5. 비범위

- 뉴스나 이벤트를 변화의 원인으로 자동 귀속하지 않는다.
- 과거 시나리오를 사용해 새 예측 확률을 계산하지 않는다.
- 서버 계정, 알림, 클라우드 상태를 추가하지 않는다.
- 전체 아카이브 원문을 HTML에 임베드하지 않는다.

## 6. 완료 기준

1. 최신과 직전 시나리오의 차이를 5초 안에 읽을 수 있다.
2. 시장 맵에서 비교 기준일을 바꾸면 모든 변화값과 막대가 즉시 갱신된다.
3. 아카이브가 12개를 넘어도 HTML에는 최신 12개 요약만 포함된다.
4. 단일 스냅샷 또는 손상된 아카이브에서는 모듈만 생략되고 대시보드는 유지된다.
5. 전체 테스트, HTML 크기 예산, 데스크톱·모바일 브라우저 검증을 통과한다.
