# Forecast Lookup 구현 보고서

작성일: 2026-08-04 KST

## 결과

01 나스닥 시나리오 탭에 서버 없는 날짜별 분포 조회를 L1→L2→L3 순서로 구현했다.
점 숫자를 답으로 제시하지 않고 p10–p90 및 p25–p75 구간을 먼저 표시한다.

## L1 — 데이터와 팬차트

- 기존 S1/S2/S3 연말 분류는 유지한다.
- 같은 `20,000`개 GBM 경로와 `seed 42`를 한 번만 생성한다.
- 동일 경로에서 D+1~D+252 거래일의 p05/p10/p25/p50/p75/p90/p95,
  기준 종가·ATH 상회 비율, S1/S2/S3 조건부 중앙값을 직렬화한다.
- `data/contracts/nyse_holidays.yaml`의 사전 등록 NYSE 규칙으로 미래 거래일을 만든다.
- 팬차트는 p10–p90, p25–p75, p50을 표시한다.
- 2026-08-03 스냅샷 기준 정적 `data.json` 증가분은 23,425 bytes로
  30KB 예산 안이다.

## L2 — 정적 조회 위젯

- 달력 입력과 1주·1개월·3개월·연말 빠른 날짜를 제공한다.
- 휴장일은 직전 산출 거래일로 매핑하고, 보간하지 않는다.
- 최대 일자 밖 입력은 거절한다.
- `#lookup=YYYY-MM-DD` 딥링크를 지원한다.
- 조회한 산출일은 팬차트의 파란 세로선으로 연결한다.
- 조회 이력을 브라우저 저장소에 기록하지 않는다.

## L3 — 규칙 파서와 질문 등록부

- `8/30`, `8월 30일`, `3개월 뒤`, `연말`만 결정적 규칙으로 해석한다.
- LLM, 외부 API, 서버 요청을 사용하지 않는다.
- 입력일과 등록 질문의 마감일이 같으면 `physical_event` 확률을 별도 보라색
  박스에 표시하며 `scenario_conditional` 분포와 결합하지 않는다.

## 고지와 검증

모든 결과 카드에는 as_of, seed, 경로 수, 확률 공간과 다음 고지를 유지한다.

> GBM 고정 가정의 조건부 분포입니다. 목표가·사건확률·투자자문이 아닙니다.

휴장일·범위·파서·분위수 단조성·결정성·불변 archive·UI 문자열을 자동 테스트하며,
정적 빌드와 브라우저에서 딥링크·규칙 파서·확률 공간 분리를 확인한다.
