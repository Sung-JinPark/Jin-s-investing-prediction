# UI 가독성 감사 — 변경 전 기준선

- 감사일: 2026-08-01 KST
- 대상: `https://sung-jinpark.github.io/Jin-s-investing-prediction/`
- 뷰포트: 1440×900, 390×844
- 성격: Grand Blueprint Phase 4 변경 전 읽기 전용 감사
- 코드 변경: 없음

## 결론

현재 UI는 Mistral 계열의 밝은 편집 디자인, 일관된 사이드 내비게이션, 정보가 많은 정적 대시보드 구조를 안정적으로 유지한다. 모든 핵심 라우트에서 가로 넘침은 발견되지 않았다. 그러나 본문 의사결정 정보와 조작 요소에 10–11px 텍스트 및 44px 미만 터치 타깃이 반복되고, 시장 확률 경로와 과거 유사 사이클이 한 흐름에 연속 배치돼 서로 다른 확률 공간이 시각적으로 충분히 분리되지 않는다.

우선순위는 P0 없음, P1 4건, P2 4건이다. Phase 4에서는 새 장식보다 최소 글자 크기, 대비, 터치 타깃, 확률 공간 라벨과 탭 분리를 먼저 해결해야 한다.

## 보존해야 할 강점

1. 왼쪽 사이드바의 5개 핵심 라우트와 현재 시장 요약 구조
2. 크림색 바탕, 검정 본문, 적색·주황·녹색의 제한된 강조 팔레트
3. 첫 화면의 핵심 판단 → 시나리오 변화 → 질문 카드 순서
4. 질문 레지스트리의 테이블/카드 전환, 필터, 정렬, Radar 기능
5. As-of 타임머신의 당시 값과 현재 값 비교 구조
6. 트랙레코드의 표본 수, Brier, 신뢰도 곡선, 분야별 정확도 공개
7. 확정 시나리오 기준일과 자동 생성 여부를 표시하는 vintage 영수증
8. 데스크톱과 모바일 전 라우트에서 가로 스크롤이 발생하지 않는 반응형 골격

## 발견 사항

### P1-01 — 핵심 보조 정보가 10–11px에 집중됨

- 위치: 모든 화면의 eyebrow, 테이블 헤더, 질문 ID, 상태, 모델 영수증, 통계 라벨
- 영향: 데이터 밀도가 높은 표에서 질문명보다 분류·상태·회차를 읽는 비용이 커진다. 모바일에서는 예측 연구 화면에서 12px 미만 텍스트 노드가 402개였다.
- 수정 기준: 일반 보조 텍스트 12px 이상, 표 헤더·필터·영수증 12px 이상, 핵심 본문 14px 이상. 글자 간격을 줄여 크기 증가에 따른 폭 증가를 보완한다.

### P1-02 — 터치 및 키보드 조작 대상이 44px보다 작음

- 위치: 별표/비교 30×28, 카드 상세 화살표 16×18, 캘린더 67×36, 모바일 헤더 40px 높이, 시장 맵 필터 34–36px 높이
- 영향: 모바일 오조작 가능성과 키보드 포커스 식별 비용이 높다.
- 수정 기준: 실제 클릭 영역을 최소 44×44px로 확장하되 시각 아이콘 크기는 유지한다. 조밀한 표 안에서는 행 전체 클릭과 명시적 `aria-label`을 함께 제공한다.

### P1-03 — 확률 경로와 역사적 유사 사이클의 확률 공간 분리가 약함

- 위치: 시장 맵의 주간 시나리오 바로 아래 `5년 build-up · 시작월 = 100 · 로그 스케일`
- 영향: S1/S2/S3의 조건부 확률과 역사 정규화 지수를 같은 종류의 예측으로 오인할 수 있다.
- 수정 기준: `미래 분포`와 `역사 정렬` 탭으로 분리한다. 역사 탭에는 `REFERENCE ONLY · 확률 아님 · log10(index/100)`을 상시 표시하고 모델 합성 입력에서 제외됨을 명시한다.

### P1-04 — 작은 강조색의 명암 대비 부족

- 위치: 흰 카드 위 주황 아이콘 및 일부 수치, 회색 `LATEST` 라벨
- 영향: 색각·저시력 환경에서 상태와 이동 방향의 식별력이 떨어진다.
- 수정 기준: 작은 주황 텍스트는 더 어두운 적갈/주황으로 전환하거나 굵기와 비색상 표식을 추가한다. 일반 텍스트는 WCAG AA 4.5:1, 24px 이상 또는 18.66px bold는 3:1을 목표로 한다.

### P2-01 — 첫 화면 헤드라인이 지나치게 큰 비중을 차지함

- 위치: 1440px에서 약 59px의 3행 헤드라인
- 영향: 즉시 판단에는 유효하지만 시나리오 변화와 실행 항목이 첫 화면 아래로 밀린다.
- 수정 기준: 데스크톱 clamp 상한을 약 52px로 낮추고 행간을 다듬는다. 문구와 위계는 유지한다.

### P2-02 — 시장 맵 범례가 분포의 의미를 충분히 설명하지 않음

- 위치: S1/S2/S3 범례와 `과거 유사 사이클`
- 영향: 선은 보이지만 중앙 경로, 구간 범위, 조건부 확률, 참고용 선의 차이를 범례만으로 해석하기 어렵다.
- 수정 기준: 중앙값, 예측 구간, 조건부 시나리오, reference-only를 각각 텍스트로 병기한다.

### P2-03 — `산출 전`과 데이터 부재의 원인이 구분되지 않음

- 위치: 질문 레지스트리의 현재 확률·회차
- 영향: 아직 미실행, 입력 부족, 검증 실패를 모두 같은 상태로 받아들일 수 있다.
- 수정 기준: `대기`, `입력 부족`, `검증 보류`처럼 상태 원인을 사용자 언어로 노출하고 원시 null은 표시하지 않는다.

### P2-04 — As-of 초기 날짜에서 변화가 모두 0으로 보여 효용이 약함

- 위치: As-of 타임머신 기본 선택 2026-07-20
- 영향: 기능이 고장난 것처럼 보일 수 있다.
- 수정 기준: 변화가 있는 가장 최근 비교 시점을 기본값으로 선택하거나 `이 날짜 이후 신규 회차 없음`을 명시한다.

## 화면별 메모

- 오늘의 판단: 콘텐츠 위계는 좋다. 헤드라인 상한과 작은 액션 타깃만 조정한다.
- 시장 맵: 시나리오 기준일은 2026-07-31로 최신 상태다. 탭 분리와 확률 공간 라벨이 최우선이다.
- 예측 연구: 38건을 한 번에 담는 테이블은 강력하지만 가장 작은 글자가 집중된다. 모바일은 카드 기본 전환이 더 안전하다.
- 질문 상세: 근거와 회차 이력의 구조는 유지한다. 영수증 글자 크기와 provider/model provenance를 보강한다.
- As-of: append-only 기록의 강점을 가장 잘 보여준다. 빈 변화 상태의 설명을 개선한다.
- 트랙레코드: 표본 부족을 숨기지 않는 문구가 좋다. 신뢰구간과 모델/공식 producer 구분을 추가할 자리가 필요하다.

## 키보드·모션·지원 상태

- DOM상 본문 건너뛰기 링크와 명시적 버튼 요소가 존재한다.
- 명령 팔레트와 좌우 화살표 차트 탐색 안내가 제공된다.
- 이번 기준선 자동 감사에서는 OS 수준 `prefers-reduced-motion` 에뮬레이션을 사용할 수 없어 실제 전환 애니메이션 억제 여부를 확정하지 않았다. 변경 후 코드 미디어쿼리와 브라우저 동작을 함께 재검증한다.

## Phase 4 수용 기준

1. 핵심 본문·표·필터에서 12px 미만 텍스트 0건(장식성 눈금은 예외로 문서화)
2. 사용자 조작 대상 44×44px 이상 또는 동일 면적의 행 클릭 대체 제공
3. 일반 텍스트 대비 4.5:1 이상, 큰 텍스트 3:1 이상
4. 390px와 1440px에서 가로 넘침 0px 유지
5. 미래 분포와 역사 정렬을 탭 및 명시적 확률 공간 라벨로 분리
6. `null` 대신 사용자 상태 문구를 표시
7. 첫 화면의 기존 판단·변화·질문 위계를 보존
