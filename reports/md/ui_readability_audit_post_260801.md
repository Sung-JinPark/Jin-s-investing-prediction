# UI 가독성 감사 — Phase 4 변경 후

- 감사일: 2026-08-01 KST
- 대상: 로컬 Pages 최종 빌드 (`419,800 bytes`)
- 뷰포트: 1440×900, 1080×800, 390×844
- 비교 기준: `ui_readability_audit_260801.md`
- 방식: 실제 브라우저 렌더링, 화면별 DOM 측정, 키보드·동적 기능과 시각 캡처 확인

## 결론

변경 전 P1 4건은 모두 해소됐다. 390px 핵심 5개 화면과 1080/1440px 표본에서 수평 넘침, 12px 미만 가시 텍스트, 44px 미만 조작 영역이 모두 0건이었다. 미래 시나리오와 역사적 사이클은 별도 탭으로 분리됐고 역사 탭은 `REFERENCE ONLY · 확률 아님 · log10(index/100)`을 상시 표시한다.

일반 HTML 텍스트 112개를 최종 1440px 시장 지도에서 실측한 결과 WCAG AA 대비 실패는 0건이었다. SVG 눈금·종점 라벨도 12px 이상과 짙은 전용 라벨 색을 사용하고, 고변동성 밴드는 더 진한 배경과 흰색 굵은 글자를 사용한다.

## 동적·접근성 확인

- 시장 지도: `미래 분포`와 `사이클 비교`를 실제 클릭해 `aria-selected`와 `hidden`이 서로 반전됨을 확인했다.
- 역사 탭: 8개 사이클이 서로 다른 색을 사용하고, 크립토는 `2019 시작`으로 명시한다. 한계 문구는 결과를 아는 hindsight, 한 자릿수 독립 표본, 확률과의 산술 결합 금지를 공개한다.
- 명령 팔레트: 열기, 18개 결과 렌더링, `Esc` 닫기를 확인했다.
- 3단계 브리핑: `01 / 03`, 이전/다음 컨트롤, `Esc` 닫기를 확인했다.
- 차트: 좌우 화살표 탐색용 포커스 가능한 SVG와 선택 주차 readout을 유지한다.
- 모션: `prefers-reduced-motion`과 제품 내 모션 축소 클래스가 애니메이션·전환을 억제한다.

## 보존한 자산과 잔여 한계

사이드바, 밝은 편집 디자인, 시나리오 변화 카드, 질문 탐색, As-of 타임머신, Trust Center와 트랙레코드를 유지했다. 역사적 유사도 순위는 참고용으로만 제공하며 ±3개월 재앵커링 거리 산출물이 아직 append-only로 보존되지 않아 `not_computed` 상태를 정직하게 노출한다. 이 한계는 UI 결함이 아니라 데이터 계보의 다음 단계다.
