# 중국 2005–2008년 비교자료

공식 공개 문서 19건의 원본, 취득시각, SHA-256과 25개 증거 및 17개 정책사건을 보관한다. 투자 판단을 위한 설명자료이며 공식 예측·확률·모델 입력을 생성하지 않는다.

## 핵심 파일

- `evidence.json`: 주장 상태, 원단위, 명시적 분수 변환, 발표일과 관측기간, 사후정보 여부, 출처 페이지.
- `source_manifest.json`: 원문 URL, 실제 최종 URL, 발표일, 취득 UTC 시각, 원본 해시와 파생 텍스트·이미지 해시.
- `daily_indices_2005_2008.csv`: 상해종합과 상해 A주 각각 971거래일, 총 1,942행. 2005/2006/2007/2008년 각각 242/241/242/246일.
- `daily_indices_2006_2008.csv`: 먼저 제공한 핵심기간 하위집합 1,458행. 전체 CSV의 동일 기간과 정확히 일치한다.
- `daily_extraction_audit_2005_2008.json`: 표의 행·열 수, 거래일 수, 시작·종료값, 원본 대시 처리와 추출 검증.

원본 PDF의 텍스트층에서 하루 12개월 열을 읽어 숫자만 전사했다. 원본의 `- - -`는 관측치로 만들지 않았으며 가격이나 거래일을 보간하지 않았다. 원문 숫자표와 생성된 수익률·통계는 구별한다. 종가는 배당을 포함하지 않은 원래 지수 단위이다. CSV 각 행에 원본 PDF, 해시, 1부터 시작하는 PDF 페이지, 인쇄 페이지, 일자 행·월 열을 기록했다.

## 해석에 중요한 구분

- 2007년 10월 16일 장중 고점은 상해종합 6,124.04와 상해 A주 6,429.68로 다르다. 종가 고점과도 구별한다.
- SSE의 2007년 전체 실적 증가율 47.5%와 가중 EPS 0.42위안은 2008년 6월 2일 요약 발표다. 2007년 당시 확정정보나 같은 구성종목 기준 지수 EPS 증가율로 사용할 수 없다. 글로벌 증가율 1위는 미검증이다.
- 역사적 PER는 전년 연간 세후 EPS를 분모로 한다. 2007년 말 평균 PER 59.24배를 TTM 또는 선행 PER와 직접 비교하지 않는다. 평균은 개별 PER의 산술평균도 아니다.
- 2007년 자연인 거래비중 86.01%, 연간 순매수 2,854.45억 위안은 개인 열풍의 증거다. 계좌 수는 고유 투자자 수가 아니며, SSE 월별 신규계좌 표는 YTD 누계다. 계좌 정비와 휴면계좌 분리는 측정 단절 가능성을 만든다.
- 연말 시총 상위 10개 51.87%는 연말 전체 발행시총 기준이며 10월 고점의 지수 구성·유동시총 비중·수익률 기여도가 아니다.
- A주 자금조달 6,701.33억 위안은 거래소 표의 전체 자금조달 항목이다. IPO만의 금액이라고 부르지 않는다.
- 비유통주 개혁은 정부의 시장제도 육성 사례다. 2007년 지준율 10회·금리 6회 인상과 인지세 조정, 위험교육도 함께 기록한다. 정부 정책을 일관된 주가부양으로 단순화할 수 없다.

## 시점과 재현

연감은 과거 관측을 보존한 사후 발간 자료다. 원래 일별 공표시각과 연감의 정확한 최초 발간일을 확보하지 못한 경우 `available_at` 또는 `published_at`은 null로 유지했다. 과거 판단 재현에 자동으로 사용할 수 없다. 인지세 공고는 원 공고일 2007년 5월 30일과 보관한 재게시일 7월 4일을 구별했다. 정책 사건의 날짜만으로 장중 공표시각을 추정하지 않는다.

기존 원본에서 오프라인 재현:

```text
python -X utf8 extract_daily.py
python -X utf8 build_evidence.py
python -X utf8 validate_china.py
```

`collect_sources.py`는 원문을 새로 취득하는 별도 네트워크 작업이다. Python urllib 인증서 검증이 실패한 사이트는 인증 검증을 유지하는 Windows curl/Schannel로 취득했다. 인증 우회, 키, 유료·실시간 증권 API 또는 브로커 API를 사용하지 않았다. 의존성 설치도 하지 않았다.
