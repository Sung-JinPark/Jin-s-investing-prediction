# 첨부 이미지의 노란 박스를 기준으로 한 지수 중첩

사용자가 표시한 중간 조정 박스를 기준으로 다시 그렸다. 이미지의 중국 지수는 장중 최고 6,429.68인 **상해 A주지수 SSE_A / 000002.SS**다.

| 시장 | 박스 시작 | 종가 최저점 | 시작 종가 첫 회복 | 거래일 간격 |
| --- | --- | --- | --- | ---: |
| 코스피 | 2026-02-26 / 6,307.27 | 03-31 / 5,052.46 | 04-21 / 6,388.47 | 37 |
| 상해 A주 | 2007-05-29 / 4,544.48 | 07-05 / 3,794.38 | 07-26 / 4,558.54 | 42 |

손그림의 픽셀 경계 대신 해당 박스에 대응하는 실제 종가의 완결 조정 구간을 사용한다. 시작점은 조정 전 최고 종가, 끝점은 그 종가를 처음 회복한 거래일이다. 장중 최고와 종가 최고는 다르다.

- `overlay_box_matched.png/svg`: **박스 시작·끝을 맞춘 메인 중첩**. 코스피 실제 거래일 축을 기준으로 중국 시간축 전체에 37/42를 곱해 11.90% 압축한다. 박스 밖에도 같은 변환을 적용한다.
- `overlay_box_zoom.png/svg`: 같은 변환의 노란 박스 확대.
- `overlay_actual_days.png/svg`: 시작만 맞추고 실제 거래일 간격을 유지. 박스의 5거래일 차이를 보존한다.
- `overlay_series.csv`: 날짜·실제 종가·출발점 이후 실제 거래일·변환 x값·시작 종가=100 값.
- `chart_contract.json`: 지수 식별자, 원본 첨부 해시, 가격 출처 해시, 앵커·수식·표시 종료일.
- `validation.json`, `previous_studies_before.json`: 첫 회복 경계·기존 연구 파일 보존 검증.

세로축은 각 박스 시작 종가를 100으로 환산한다. 최저점·전체 고점을 별도로 맞추지 않으므로 실제 낙폭 차이가 남는다. 고점이나 하락 구간을 맞추기 위한 추가 피팅도 없다.

코스피 실선은 이미지 상단 날짜에 맞춘 2026-10-14까지다. 10-15 종가는 점선·빈 점으로 구분한 **추가 실측값**이다. 중국은 동일한 비교축 범위에 들어오는 역사 종가만 표시한다. 시간 변환을 택하면 같은 x에 대응하는 중국 날짜도 달라지므로 미래 경로 예측이나 단일 날짜 유사도 판정으로 사용하지 않는다.
