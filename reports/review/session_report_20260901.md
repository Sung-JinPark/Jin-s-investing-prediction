## 8. 사건과 교훈 (정직 고지)

1. **머지+삭제 체이닝 2회 재발** — `gh pr merge && git push --delete`에서 머지가 충돌로
   실패해도 삭제가 실행돼 열린 PR의 브랜치를 지움(#88, #114). 1분 내 복구
   (`refs/pull/N/head`에서 재푸시 + reopen)했고 손실 0. **규칙을 메모리에 영구 기록**:
   삭제는 `state=MERGED` 확인 후 별도 명령.
2. **예외 삼킴 가드** (#113) — 실제 원인에서 두 단계 떨어진 곳에서 죽게 만드는 구조.
   "가드는 삼키기로 한 것만 삼킨다"로 교정.
3. **영수증-전송 불일치** (#107) — 이관 시 전송만 바꾸면 기록이 거짓이 된다.
   배포 검증(실행→로그→커밋 대조)이 잡아냈다.
4. **"기록에 없는 결정"** (#106) — 코드·테스트가 인용하던 12-6이 문서에 없었음.
   결정 기록 없이 나간 전환의 소급 기록.
5. 셸 heredoc 이스케이프 함정 — 한국어+중첩 따옴표 패치는 스크래치패드 스크립트로.
