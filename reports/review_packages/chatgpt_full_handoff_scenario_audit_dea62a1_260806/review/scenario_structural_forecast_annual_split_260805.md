# NASDAQ 연도별 DB 조건부 구조 경로 구현 기록

작성일: 2026-08-05 KST
대상: `data/scenarios/nasdaq_latest.json` 2026-08-03 r3 → additive r4
수정 원장: `CORR-260805-014`

## 1. 수정 이유

기존 S1/S2/S3 굵은 선은 20,000개 GBM 경로를 시나리오로 분류한 뒤 각 날짜의
횡단면 중앙값을 연결했다. 개별 경로의 조정은 `path_realism`에서 관측되지만 서로 다른
경로의 상승·하락이 중앙값에서 상쇄되므로 굵은 선은 거의 단조 상승 또는 완만한 하락으로
보였다. 얇은 모의 표본을 겹치는 방식은 변동성을 보여 주지만, 표본의 우연한 굴곡 날짜가
예측일처럼 읽히는 문제가 남았다.

이번 수정은 모의 표본을 대표 예측선으로 승격하지 않는다. 기존 분포·분위수·S1/S2/S3
비중과 연도 구간 종점은 그대로 보존하고, 커밋된 역사 DB가 주는 월별 굴곡만 별도의
`structural_forecast`에 직렬화한다.

## 2. 사용한 DB와 사용 규율

| 층 | 실측 입력 | 수치 사용 | 규율 |
|---|---:|---:|---|
| 혁신사이클 context | AI 현재 M+42, 선택 시대 `biotech2015/dotcom/japan1989` | 예 | 세 시대의 같은 미래 위상 값을 매월 중앙 집계 |
| 다중시대 조정 DB | pool 5개 시대, 조정 깊이 중앙값 −12.19% | 예 | 2026 S1 연중 최대낙폭의 진폭 보정 목표 |
| 닷컴↔AI 에피소드 | 닷컴 6회 −12.3%, AI 5회 −10.4% | 근거 표시 | 독립 표본으로 오인하지 않으며 추가 가중치 없음 |
| 등록 질문 | 2026-08-01~10-31, `physical_event` 57% [44,70] | 아니오 | 별도 박스에만 표시, 시나리오 확률과 결합 금지 |
| Scenario Tracker | 7/9 입력, 상태 개수만 등록 | 아니오 | 규칙상 가중 점수·확률 변환 금지 |
| 유동성 | neutral, 4주 −0.29% | 아니오 | 방향 참고만, 경로 날짜를 식별하지 못함 |
| AI 자본사이클 | coverage 0.0, blocked | 아니오 | coverage 0.6 전에는 경로 입력 금지 |

## 3. 산식

1. 현재 AI 위상은 `len(overlay.ai)-1`로 계산한다.
2. 각 미래 주차를 30.4375일/월로 월 위상에 매핑하고 선택된 세 시대를 선형 보간한다.
3. 각 위상에서 세 시대의 현재 대비 지수 비율 중앙값을 구한다.
4. 2026과 2027을 각각 분리하고, 각 연도 구간의 시작·끝을 잇는 기하 추세를 제거해
   역사 DB의 중간 굴곡만 남긴다.
5. 각 S 경로의 기존 연도 시작·끝 종점을 잇는 기하 경로에 이 잔차를 곱한다.
6. 잔차 강도는 2026 S1 최대낙폭이 커밋된 다중시대 조정 중앙값 12.19%와 일치하도록
   결정론적 이분 탐색한다. 같은 강도를 S2/S3와 2027에 재사용한다.

이 방식은 특정 날짜에 손으로 하락 펄스를 넣지 않는다. 굴곡 위치는 혁신사이클 DB,
진폭은 조정 에피소드 DB, 종점은 기존 조건부 분포가 각각 담당한다.

## 4. 산출 진단

| 표시 연도 | DB가 가리키는 월 단위 위험창 | S1 최대낙폭 | S2 최대낙폭 | S3 최대낙폭 |
|---|---|---:|---:|---:|
| 2026-08-03~12-31 | 2026-08-31~11-24, 중심월 10월 | −12.2% | −16.0% | −20.4% |
| 2027-01-08~08-04 | 2027-06-25~07-19, 중심월 7월 | −7.8% | −8.0% | −8.0% |

위 날짜는 주간 차트 샘플 위치다. 데이터 해상도가 월 단위이므로 “10월 20일 저점”이나
“7월 2일 조정”처럼 특정 거래일을 예측하지 않는다. UI에는 연도별 차트와 위험창만
표시한다. 2027년은 현 252거래일 지평이 끝나는 8월 4일까지이며 9~12월은 만들지 않는다.

## 5. 의미와 한계

- 굵은 선: `DB 조건부 구조 경로`, 무작위 모의 표본이 아니다.
- 팬 밴드와 S1/S2/S3 비중: 기존 GBM 조건부 분포이며 변경하지 않는다.
- 혁신사이클: 결과를 이미 아는 소표본 역사 자료다. 형태 유사성이 미래 사건을 보장하지 않는다.
- 2026년 57%: 8~10월 −10% 종가 발생 여부의 `physical_event` 확률이며 구조 경로의
  12.19% 진폭과 산술 결합하지 않는다.
- AI 버블 붕괴일: 이 경로로 판정하지 않는다. 현재 LPPL은 경계 아티팩트 때문에 보정
  시점이 비활성화되어 있고 AI 레짐 DB도 blocked다.
