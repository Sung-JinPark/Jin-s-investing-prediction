# REVIEW-260805 · G-1/G-2 사용자 결정 초안

작성일: 2026-08-06 KST  
상태: **등록 보류 — 사용자 승인 전 registry/forecast ledger 변경 금지**  
확률공간: 아래 두 안 모두 `physical_event`; NASDAQ 시나리오 비중과 결합 금지

## 1. G-1 — 연준 대응 여력 질문

논쟁을 검증 가능한 한 문장으로 바꾸면 다음과 같다.

> NASDAQ Composite가 직전 252거래일 최고 종가 대비 15% 이하로 마감한 최초 거래일 이후, 예정된 다음 두 번의 FOMC 결정까지 연방기금금리 목표범위 상단이 누적 50bp 이상 인하되는가?

### 권고 등록안

| 항목 | 초안 |
|---|---|
| question_id | `fed-response-after-nasdaq-dd15` |
| 확률공간 | `physical_event` |
| 가격 트리거 | `^IXIC close <= rolling_252d_high × 0.85` |
| 정책 사건 | 트리거 이후 다음 두 예정 FOMC에서 목표범위 상단 누적 변화 `<= -50bp` |
| 판정 시작 | 가격 트리거가 처음 확정된 거래일 |
| 판정 종료 | 두 번째 예정 FOMC 성명 발표일 |
| 가격 출처 | 거래소 공식 종가, Yahoo 교차 확인 |
| 정책 출처 | Federal Reserve 공식 FOMC 성명 |
| 동시성 | 트리거 당일 이전 인하는 계산하지 않음 |
| 재트리거 | 최초 트리거만 사용; 질문 해소 전 재설정 금지 |

`−15%`는 REIT 전이 논리를 시험할 만큼 의미 있는 충격이면서 `−20%`보다 표본을 덜 잃는 권고안이다. 다만 사용자가 “버블 붕괴”만을 엄격히 시험하려면 별도 질문으로 `−20%`를 선택해야 한다. 두 임계값을 한 질문에서 OR로 섞지 않는다.

### 승인에 필요한 사용자 결정

1. 가격 트리거: `−15%` 또는 `−20%`
2. 인하 창: 다음 `2회 FOMC` 또는 `90일`
3. 누적 인하: `−50bp` 유지 여부

승인 전에는 확률을 만들지 않으며 질문 registry에도 행을 추가하지 않는다.

## 2. G-2 — 사용자 견해 human forecast

등록 대상 문장은 다음처럼 고정하는 것이 가장 덜 모호하다.

> 2026년 최종 거래일 NASDAQ Composite 종가는 2026-08-03 종가 25,913.90을 초과한다.

기존 `nasdaq-eoy-above-jul9-2026`은 임계가 26,206.89라 명제가 다르다. 기존 질문에 작성자만 추가하면 판정 임계가 섞이므로, 같은 임계를 쓸지 새 질문을 만들지 먼저 정해야 한다.

### 등록 템플릿

| 필드 | 사용자 입력 필요 |
|---|---|
| author | `human:Sung-Jin Park` |
| question_id | 기존 `nasdaq-eoy-above-jul9-2026` 또는 신규 고정 임계 질문 |
| probability | 0–100 정수 |
| ci80 | 하한·상한 정수 |
| timestamp | 실제 등록 시각 |
| rationale | “이번 변동성 장 이후 반등, 반도체 하락 명분·포지션 청산 이후 회복” |
| model influence | `none` — 모델 튜닝 입력 금지 |
| scoring | 다른 physical-event 예측과 같은 해소 원장에서 Brier 채점 |

사용자 확률·80% 구간을 임의 추정하지 않는다. 값이 확정되기 전까지 human forecast 원장에는 아무 행도 쓰지 않는다.

## 3. 결정 후 실행 순서

1. 질문 문안과 임계를 registry에 먼저 사전 등록한다.
2. registry sync로 src hash와 deadline을 고정한다.
3. G-1 모델/LLM forecast와 G-2 human forecast를 서로 다른 작성자 행으로 append한다.
4. UI에는 `MODEL`과 `HUMAN`을 나란히 표시하되 평균·재가중하지 않는다.
5. 해소 후 동일 판정 근거로 각각 채점한다.
